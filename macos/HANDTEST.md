# 手测清单

> 2026-11-01（第四轮体检 W1）起：发版前走下面的「真机回归清单」，它代替原来的「发版冒烟清单」。到 2026-10-30 为止的全部手测（发版冒烟清单 53 步 + 各批手测，编号不变）原样归档在 `macos/docs/archive/HANDTEST-2026-10.md`；代码注释和规则里「HANDTEST X 第 N 条」「PLAN §12 第 N 条」「§12「X」第 N 条」这类引用都去那里找。
>
> **怎么走**：用要发的那个 Release 包（`macos/build-dmg.sh` 出的 DMG）从头走一遍，约一个半小时（要两台 Mac 的同步那两条另算）。每条「做什么 → 期望」，最后「→」后面是细节在哪：「冒烟 N」= 归档里「发版冒烟清单」第 N 步，「X N」= 归档里小节 X 的第 N 条，「四 N」= 本文件「第四轮体检手测（0.7.1）」第 N 条。写着「只在 Dev 版」的会动数据，别在正式版上做。每次发版重走一遍，上一次的勾发版后清掉。
>
> **怎么加**：新一轮功能 / 体检要真机验收的，在本文件末尾另起一节（节名写清是哪一轮、哪一版），节里从 1 编号，条目前写拍板条目号（如「（E3）」），一条一行「做什么 → 期望」。那一版发布、真机走完后，把以后每次发版都该再看的（最容易坏、自动测不到的）并进真机回归清单，整节挪进归档。回归清单用 R 编号：新条目取下一个没用过的号、放进它那一组（组里不必按号码排），删掉的号不复用；细节指到归档或那一节，不在清单里展开；清单保持 40 条上下，加一条先想想能不能并掉一条。

- [ ] 57.（复查）下载来的脚本里一行写「\u200B# 旧版本 ; echo 被骗了」（行首一个零宽空格，用 printf 写进去）→ 看全文那一页标成「⟦U+200B⟧# …」、橙字说藏着看不见的字符、不让运行；「true\u00A0# …」（不换行空格）→ 标出来但能运行；脚本里写「print ⚠️」这类带 emoji 的不受影响。拖进一个 `x.template.sh` → 能导入，橙字说要填值、去掉 .template. 才列出来。看全文那一页刚出来的 1 秒里「运行」是灰的，之后变成粉色键帽。
- [ ] 58.（第三轮 A1）写一个 `@kitty.mode full` 的脚本：`for i in 1 2 3 4 5; do echo "第 $i 步"; sleep 1; done; echo 出错了 >&2` → ↩ 后那一页一秒多一行，小字「正在运行… 已 3 秒」在走；「出错了」接在最后（不是跑完才出现）；跑着时往上翻 → 不再跟着往下走，翻回底部又跟。
- [ ] 59.（第三轮 A2）脚本里 `printf '\033[1;32m成功\033[0m \033[31m失败\033[0m \033[38;5;208m橙\033[0m\n'`，再 `git -c color.ui=always status` → 全文那一页是绿色粗体「成功」、红「失败」、橙色；浅色里黄色看得清；粘贴、复制出去的是没有颜色码的纯文字。`curl -o /dev/null https://…`（带进度条）→ 只剩最后一帧，不是一屏的进度行。
- [ ] 60.（第三轮 A3）全文那一页跑完按 ⌘R（或点「重跑」）→ 用同样的参数再跑一次；在编辑器里改一下脚本再 ⌘R → 跑的是改过的；写了 confirm 的全文脚本底栏没有「重跑」、⌘R 只响提示音。出错的岛上点「看输出」→ 那一页 ⌘R 也能重跑、结果留在这一页上。
- [ ] 61.（第三轮 B1）列表脚本打印 `{"items": [{"title": "Kitty Tools", "url": "https://github.com/YyAdnBug/kitty-tools"}, {"title": "下载", "path": "~/Downloads"}]}` → 两行右侧写「网址」「文件」；第一行 ↩ 用浏览器打开、⌘C 复制网址；第二行 ↩ 在访达里打开下载文件夹、⌘↩ 在访达中显示、⌘Y 快速查看，图标是下载文件夹的图标。
- [ ] 62.（第三轮 B2）给每条写不同的 `"icon"`（emoji、SF 符号名、`{"type": "fileicon", "path": "/Applications/Safari.app"}`）→ 各行显示各自的图标；写 `"autocomplete": "子目录/"` 的那条按 ⇥ → 搜索框变成「关键词 子目录/」并重跑；写了 `"text": {"copy": "x"}` 的那条 ⌘C 复制的是 x、↩ 粘贴的仍是 arg。
- [ ] 63.（第三轮 B3）列表脚本加一行 `# @kitty.filter`、脚本里 `sleep 1` 再列几条中文标题 → 打「关键词 空格」等一秒出结果，接着打拼音首字母（如「mmgj」）马上筛出来、不再等一秒；Esc 收起再呼出重打 → 又等一秒（重跑了一次）。
- [ ] 64.（第三轮 C1）脚本参数写 `{"type": "dropdown", "placeholder": "设备", "data": [{"title": "耳机", "value": "headphones"}, {"title": "音箱", "value": "speakers"}]}`、脚本 `echo "$1"`：打「关键词 空格」→ 两个选项排在最前、右侧「选项」；打「er」→ 只剩耳机（拼音）；↩ → 搜索框变成「关键词 耳机」，再 ↩ → 岛上「headphones」。打「关键词 电视」→ 那一行写「「电视」不是「设备」能选的：耳机 / 音箱」，↩ 只响提示音。
- [ ] 65.（第三轮 C2）两个参数的脚本（如 `echo "$1|$2"`）：打 `关键词 "New York" London` → 岛上「New York|London」；中文引号 “纽 约” 也一样；只有一个参数的脚本带引号照原样交。
- [ ] 66.（第三轮 C3）参数写 `{"type": "password", "placeholder": "令牌"}`：打的时候选中那一行写「•••」；↩ 跑完再呼出启动器 → 搜索框是空的；`@kitty.mode full` 的跑着时搜索框也已经清空；打着密码没按 ↩ 就点外面收起，再呼出 → 搜索框是空的。设置 › 启动器「怎么写脚本」参数那一行写明搜索框里看得见。
- [ ] 67.（第三轮 D2）设置 › 启动器「新建脚本」→ 出小表单（名字、关键词、结果给谁、用什么写）；选 AppleScript + 列出几条结果来挑、关键词 demo → 「新建」后文件夹里多一个 demo.applescript 并在编辑器里打开，启动器里打「demo 空格」出两条；JavaScript、Python 各试一次。启动器里输「新建脚本」↩ → 设置窗打开到启动器页并盖上同一张表单。
- [ ] 68.（第三轮 D1）设置 › 启动器 › 命令和别名：每行多一个「快捷键」框；给「锁定屏幕」录 ⌃⌥⌘L → 在别的 App 里按 → 直接锁屏（不弹启动器）；给一个不要参数的岛上模式脚本录一个组合 → 按了岛上出结果、启动器不出来。
- [ ] 69.（第三轮 D1）给要参数的脚本（如查天气）录快捷键 → 按了打开启动器、搜索框是「tq 」；给写了 confirm 的脚本录 → 按了打开启动器、那一行已上膛（危险色那句），再按 ↩ 才跑；给「结束进程」录 → 打开启动器填好「kill 」。
- [ ] 70.（第三轮 D1）录一个已经给「剪贴板历史」用的组合（⌥C）→ 那一行下面橙字「和「剪贴板历史」重复」、没存上；反过来在 设置 › 快捷键 给某个动作录一个命令已经用了的组合 → 橙字「和启动器命令「x」重复」。⌘C 这类 → 拒绝；不带修饰键 → 提示要带。
- [ ] 71.（第三轮 D1）把设了快捷键的那条命令关掉 → 快捷键不再响应（按了没反应），再打开又响；把那个脚本移到废纸篓 → 不再响应；导出设置再在另一台（或 Dev 版）导入 → 快捷键跟着过去，那台上没有的脚本不注册。设置 › 通用「功能」关掉启动器 → 这些快捷键都不响应。

## 访达右键手测（下一版；2026-11-08 起，PLAN §10「访达右键」）

1. 设置 › 访达右键：打开「启用访达右键」，系统里扩展还没开时直接弹出 系统设置 › 通用 › 登录项与扩展；在那里打开 Kitty Tools，回到设置页那一行变成绿勾。
2. 访达里右键一个文件：第一层有「拷贝路径」「在“终端”中打开」，每一项都有图标、文字对齐，深色模式下看得清；「拷贝路径」后刘海岛说「已拷贝路径」、小字是 ~ 开头的路径，粘贴是完整路径，剪贴板历史里多一条。
3. 选中三个文件右键「拷贝路径」：粘出来三行，一个一行。
4. 文件夹窗口空白处右键：「拷贝路径」是这个文件夹的路径；「在“终端”中打开」：终端开在这个文件夹，终端到前台。先选中几个文件、再在空白处右键（图标、列表、分栏三种显示方式），对着的仍是这个文件夹；有选中时右键另一个没选中的文件，对着的是那一个。
5. 右键一个 .sh、.command、编译出来的可执行文件「在“终端”中打开」：终端开在它所在的文件夹，**不运行它**；同样的文件「在“Visual Studio Code”中打开」打开的是文件本身。选中三个不同文件夹里的文件「在“终端”中打开」：只开一个终端窗口（第一个的文件夹）；「在“Visual Studio Code”中打开」三个都开。名字带空格、中文、& 的文件夹也开得对。
6. 设置 › 访达右键「在 App 中打开」加上 VS Code（或别的编辑器）：右键一个项目文件夹多一项「在“Visual Studio Code”中打开」，点了在它里面打开、它到前台；移除后右键里没了。
7. 关掉「启用访达右键」：访达右键里这几项都没了（系统里扩展还开着也不出）；再打开立即回来。
8. 退出 Kitty Tools 后右键「拷贝路径」：Kitty Tools 被打开、路径照样拷上，不抢前台。
9. 在浏览器地址栏打开 `com.yy.kitty-tools.native://finder?do=copy&file=/etc/hosts`（没带凭证）：最多问一下要不要打开 Kitty Tools，剪贴板不变。
10. iCloud 云盘的文件夹里右键：没有这几项（系统不给，设置页写了）。
11. 新装时在欢迎引导第一屏勾上「访达右键」：走完引导刘海岛说「访达右键还要在系统设置里打开一次」，点「去打开」到 登录项与扩展。
12. 从测试包新装（带下载标记）、「仍要打开」放行后，扩展能在系统设置里打开、右键里出现；用 App 内更新换一次包，系统设置里扩展还开着、右键照常。
13. 文件夹窗口空白处右键「新建文件 ▸」：文本文件、Markdown、Word 文档、Excel 表格、PPT 演示文稿各建一个，名字对、日期是现在，建好后访达里选中它、名字处于可改状态（直接打字改名、回车确定；没给 Kitty Tools「辅助功能」授权时只选中）；Word / Excel / PPT 用 WPS 或 Office、Pages / Numbers / Keynote 打得开。再建一次同样的，叫「… 2」。
14. 「打开模板文件夹」：打开数据目录里的「新建文件模板」（没有就建）；往里放一个 .key 和一个文件夹，再右键「新建文件 ▸」里多这两项，建出来是拷贝。设置 › 访达右键「在访达中显示」开的是同一个文件夹。
15. 「自定义后缀…」：Kitty Tools 弹框、能直接打字（框在最前面），填「.yaml」建出「YAML 文件.yaml」；框关了前台回到访达；下次框里先填着 yaml；「以后列在「新建文件」里」勾着时菜单里多「YAML 文件」，再建一次 yaml 不会多放一个；填 md 不会往模板文件夹里放（自带的有）；填「a/b」响一声、不建。
16. 桌面、文稿、下载里第一次新建文件：系统问一次要不要让 Kitty Tools 访问这个文件夹，说明里写着「在访达右键里新建文件」；允许后建好。只读的盘（挂着的 DMG）里新建：响一声、什么都不建；~/Library 下面的文件夹里新建也只响一声。往模板文件夹里放一个替身（⌥⌘ 拖进去），菜单里点它：响一声、不建。
17. 设置 › 访达右键关掉「显示「新建文件」」：空白处右键里没有「新建文件」；关掉「显示「拷贝路径」」：两处都没有「拷贝路径」；再打开立即回来。
18. 右键一个文件「拷贝名称」：粘出来是带扩展名的名字；选三个是三行；刘海岛说「已拷贝名称」。空白处没有这一项。
19. 「移动到 ▸ 下载」：文件挪进下载、原处没了，刘海岛「已移到「下载」」带「在访达中显示」；下载里已有同名的，挪过去叫「… 2」，不覆盖。「复制到 ▸ 桌面」：原件还在。拷一个几 GB 的文件夹：1 秒后刘海岛「正在复制…」带「停止」，点停止后桌面上没有半截的那份。
20. 「移动到 ▸ 选择文件夹…」：弹出选文件夹的面板在最前面（Kitty Tools 不在前台时也是），选好就挪过去；取消什么都不动。设置 › 访达右键里加一个常用文件夹、删掉「文稿」：右键子菜单跟着变。
21. 「剪切」两个文件，到别的文件夹空白处右键：多一项「粘贴 2 项」，点了移过来、原处没了；剪切后在访达里直接按 ⌥⌘V 也能移过来。剪切后又拷了一段文字：空白处不再有「粘贴」。
22. 设置里打开「显示「发送替身到桌面」」：右键「发送替身到桌面」，桌面上多一个同名的替身，双击打开原件；原件挪到别处后替身照样打得开。
23. 用别的程序（比如终端里 open）打开 com.yy.kitty-tools.native://finder?do=copy&key=<偏好里的凭证>&file=/etc/hosts：什么都不发生（不是扩展发的）。
24. 右键一个文件夹「压缩为 ▸ ZIP」：旁边多「名字.zip」，重名叫「名字 2.zip」；拿到 Windows 电脑（或者 Windows 的虚拟机）上用自带的解压打开，中文名不乱码、没有 __MACOSX 和 .DS_Store。选三样「压缩为 ▸ 7Z」：叫「归档.7z」，双击能用系统的归档实用工具或别的解压软件打开。压一个几 GB 的文件夹：1 秒后刘海岛「正在压缩…」带「停止」，点了旁边不留半截的包。
25. 右键一个 App「压缩为 ▸ ZIP」，再在别的地方解开：App 照常打得开（签名没坏）。
26. 右键一个 zip / 7z / tar.gz「解压到这里」：里面只有一个文件夹的，那个文件夹直接出现在旁边；里面是一堆文件的，放进和包同名的文件夹。选中的不全是压缩包时没有这一项。从网上下载的包解出来的 App，第一次打开照样有系统的「来自互联网」提示。
27. 找一个中文 Windows 打的 zip（或者让 Windows 的朋友发一个）：访达双击解出来是乱码的，「解压到这里」名字都对。
28. 带密码的 zip「解压到这里」：刘海岛说「「名字.zip」有密码」带「输入密码…」，点了弹框、能直接打字；输错了刘海岛说「密码不对」，再点一次输入；框里点取消就停、刘海岛不挂着「正在解压」；输对了解开。
29. 访达双击解出乱码名字的那个包（或者名字是「ÖÐÎÄ.txt」「╓╨╬─.txt」的文件），右键有「修复乱码文件名」，点了改回中文，刘海岛「撤销」能改回去；正常的中文、英文、法语 / 德语带重音字母的名字右键里没有这一项。
30. 设置 › 访达右键打开「显示「切换隐藏文件」」：文件夹空白处右键点它，访达里隐藏的文件出现（变淡）、再点一次又藏起来，访达没有重启、正在拷的东西没断；没给辅助功能授权时刘海岛说一声、带「去授权」。确认一下：切换后终端里 `defaults read com.apple.finder AppleShowAllFiles` 变不变（变的话菜单可以改成按状态叫「显示隐藏文件」/「不显示」）。
31. 打开「显示「隐藏」和「隐藏扩展名」」：右键文件「隐藏」后访达里看不见了（⇧⌘. 后变淡地出现），再右键它是「取消隐藏」；「隐藏扩展名」后名字不带扩展名，再右键是「显示扩展名」；.env 这种点开头的右键里没有「取消隐藏」。
32. 打开「显示「拷贝哈希」」：右键一个安装包「拷贝哈希 ▸ SHA-256」，粘出来和终端 `shasum -a 256 <文件>` 的一样；选三个文件是三行「哈希值␣␣文件名」；选中的有文件夹时没有这一项；几 GB 的文件算的时候刘海岛能停。
33. 打开「显示「彻底删除…」」：右键「彻底删除…」先弹框，列着名字、写着不进废纸篓，回车是取消（不删）；点「彻底删除」才删，废纸篓里没有。选七个文件：框里列前五个和「一共 7 项」。Esc 关不掉这个框（只能点「取消」或按回车），这是故意的。删一个很大的文件夹时刘海岛「停止」能停住（已经删掉的找不回来）。
34. 右键菜单出来的速度和访达自己的菜单差不多，没有明显的停顿（第一次右键也是）；终端里跑 `log stream --level debug --predicate 'subsystem == "com.yy.kitty-tools.native" AND category == "finder"'` 再右键，「菜单搭好用了 N ms」在几毫秒以内。
35. 右键里我们的每一项是彩色方块里一个白色符号，颜色按类（拷贝蓝、新建绿、移动复制剪切橙、压缩解压棕、修复紫、哈希青、隐藏灰、替身靛、删除红），浅色 / 深色模式、鼠标停在那一行（蓝色高亮）时都看得清；方块和文字对齐，和「在“终端”中打开」的 App 图标一样大。
36. 设置 › 访达右键打开「收进一个子菜单」：右键第一层只多一项「Kitty Tools ▸」（粉色方块里白色爪印），我们的项都在它里面、点了照常；关掉立即回到平铺。
37. U 盘、挂着的磁盘映像、网络盘里右键文件和空白处：菜单照常出现。废纸篓窗口的空白处：没有「新建文件」「粘贴」。
38. 挂着新版的 DMG（还没拖进「应用程序」）时右键「拷贝路径」：照常拷上，不弹出主界面。剪切后退出 Kitty Tools：空白处右键不再有「粘贴」。
39. 「彻底删除…」的框点了取消或删完后，前台回到访达（直接按方向键能在访达里挪选中）。
40. 做不成时刘海岛说原因、不只响一声：「移动到」一个刚删掉的常用文件夹（说「不在了」，**不会把文件夹建回来**）、把文件移到它本来就在的文件夹（「已经在…里了」）、剪切后又拷了别的再粘贴（「剪切已经作废了」）、在资源库里新建（说为什么不建）、自定义后缀填「a/b」、一次选 2001 个文件右键（「一次最多 2000 项」）。
41. 桌面上空白处右键「新建文件 ▸ 文本文件」：桌面上多一个文件，**不另开一个「桌面」窗口**；别的文件夹里新建照旧选中并进入改名。
42. 「移动到 ▸」子菜单：选中的文件本来就在「下载」里时「下载」是灰的；删掉一个常用文件夹后它变灰；用「选择文件夹…」选过一个文件夹后，它出现在常用文件夹后面（最多 3 个）。
43. 设置 › 访达右键：常用文件夹和「在 App 中打开」两张列表能拖动排序，右键子菜单跟着变。「+」菜单里有「这台 Mac 上的终端和编辑器」，列出装着的（终端、VS Code 这类），已经加了的是灰的。
