# 手测清单

> 2026-11-01（第四轮体检 W1）起：发版前走下面的「真机回归清单」，它代替原来的「发版冒烟清单」。到 2026-10-30 为止的全部手测（发版冒烟清单 53 步 + 各批手测，编号不变）原样归档在 `macos/docs/archive/HANDTEST-2026-10.md`；代码注释和规则里「HANDTEST X 第 N 条」「PLAN §12 第 N 条」「§12「X」第 N 条」这类引用都去那里找。
>
> **怎么走**：用要发的那个 Release 包（`macos/build-dmg.sh` 出的 DMG）从头走一遍，约一个半小时（要两台 Mac 的同步那两条另算）。每条「做什么 → 期望」，最后「→」后面是细节在哪：「冒烟 N」= 归档里「发版冒烟清单」第 N 步，「X N」= 归档里小节 X 的第 N 条，「四 N」= 本文件「第四轮体检手测（0.7.1）」第 N 条。写着「只在 Dev 版」的会动数据，别在正式版上做。每次发版重走一遍，上一次的勾发版后清掉。
>
> **怎么加**：新一轮功能 / 体检要真机验收的，在本文件末尾另起一节（节名写清是哪一轮、哪一版），节里从 1 编号，条目前写拍板条目号（如「（E3）」），一条一行「做什么 → 期望」。那一版发布、真机走完后，把以后每次发版都该再看的（最容易坏、自动测不到的）并进真机回归清单，整节挪进归档。回归清单用 R 编号：新条目取下一个没用过的号、放进它那一组（组里不必按号码排），删掉的号不复用；细节指到归档或那一节，不在清单里展开；清单保持 40 条上下，加一条先想想能不能并掉一条。
