## 发版冒烟清单

按风险挑的 36 步，约半小时，不代替各批手测。用要发的那个 Release 包（`macos/build-dmg.sh` 出的 DMG）走；每步一行：做什么 → 期望，「→」后面是细节所在的条目。第 10、11 步动数据，**只在 Dev 版上做**。

**安装与更新**
- [ ] 1. 删掉「应用程序」里旧的 `Kitty Tools.app`，把 DMG 里的拖进去、双击 → 被系统拦下；系统设置 › 隐私与安全性 点「仍要打开」后能打开（只有第一次安装要）；`codesign -d -r- "/Applications/Kitty Tools.app"` 里有 `anchor apple generic` 和 `com.yy.kitty-tools.native`，不是 cdhash。
- [ ] 2. 菜单栏「关于 Kitty Tools」→ 版本号是这一版，更新日志最上面是这一版；逐条对一眼实际（按的键、设置项名字、文件名）。
- [ ] 3. `defaults write com.yy.kitty-tools.native lastSeenVersion 0.0.1`，退出再打开 → 不开设置窗、前台不变，刘海岛「已更新到 x」+ 摘要开头，菜单栏图标弹一下。→「体检第 1 批」3
- [ ] 4. `TEST_RUNNER_KITTY_UPDATE_ZIP=<这次的 _arm64.zip 绝对路径>` 跑 `UpdaterTests`（命令见 AGENTS.md）→ 全过。发布以后在装着上一版的机器上：设置 › 关于「检查更新」→「更新并重新打开」（或菜单栏最上面「更新到 x…」）→ 自己退出、换包、重开就是新版，不用再放行，授权都还在。

**授权**
- [ ] 5. 设置 › 通用「权限」：辅助功能、屏幕录制、麦克风、剪贴板访问几行的状态和系统设置里一致；没授权的点按钮 → 弹系统框或直达系统设置对应的页，改好切回设置窗那一行跟着变。
- [ ] 6. 辅助功能（新装，或 `tccutil reset Accessibility com.yy.kitty-tools.native` 后）：剪贴板面板里按 ↩ → 不粘，警告岛「已复制到剪贴板 · 授权辅助功能后才能直接粘贴」并弹系统授权框；授权后 ↩ 能粘回原 App（第 12 步）。
- [ ] 7. 屏幕录制（没授权时）：按 ⌥A → 弹一次系统授权框，刘海岛警告「需要「屏幕录制」授权」；授权（必要时重开 App）后再按能框选。→「待用户手测」截图翻译 1
- [ ] 8. 麦克风（没问过时）：⌥R 框好后在录制条上打开麦克风 → 框选时不弹框，按开始、遮罩收起后才弹系统框；点「不允许」→ 照样倒数开录，警告岛「没有麦克风授权 · 这段录屏不带麦克风」。→「录屏 / 录音手测」29
- [ ] 9. 完全磁盘访问：设置 › 启动器「浏览器书签与历史」打开 Safari → 橙字「需要完全磁盘访问权限」和「去授权…」；在系统设置里加上 Kitty Tools 后切回设置窗 →「已读到 N 条书签」，启动器搜得到 Safari 的书签。→「浏览器书签与历史」3–4

**数据（只在 Dev 版上）**
