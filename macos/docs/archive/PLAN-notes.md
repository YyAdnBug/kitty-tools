**便签（2026-10-12 立项，0.5.0）**

- 分批（一批一个提交；高风险 = 实现 + 两名评审，低风险 = 一个实现任务 + 主会话审查）：0 实测与做法（主会话）→ 1 数据层（高）→ 2 快速记一条、全部便签窗口、入口、设置页骨架（低；做完便签就能记、看、改、搜、删）→ 3 边缘那叠（高）→ 4 浮动便签（高）→ 5 任务、列表续行、查找、撤销（低）→ 6 Markdown 边打边变样（高）→ 7 行内图片（高，可晚一个小版本）→ 8 打通与 Markdown 文件夹导出导入（低）→ 9 收尾（主会话：版本号、更新日志、手测清单、规则、许可出处）。
- 第 0 批的结论（2026-10-12）：原想用小程序验的三件事里，要真实鼠标键盘的两件（被截图遮罩盖住 / 别的 App 全屏 / 两屏相接时追踪区的表现，输入法在边缘面板里组字）没法在用户用着电脑时做——不去动用户的鼠标——改成**不依赖它们的写法**加手测：边缘面板在框选 / 长截图 / 录屏选区 / 状态屏期间由代码显式停用（不靠「被盖住就收不到」）；不激活本 App 的面板里打字、输入法、撤销，三块面板和翻译原文框（`SourceTextView`）已经在用，沿用同一套（`canBecomeKey`、`acceptsFirstMouse`、方向键回车走 `doCommandBy`）；从剪贴板面板 / 启动器「粘贴」到便签不靠合成 ⌘V 落到哪个窗口，而是粘贴目标是便签时直接把内容插进便签的文本框。真机要看的进 `HANDTEST.md`「便签手测」。
- 第 1 批（2026-10-12，数据层；除了导出 / 导入表单多一行「便签」，还没有用户能碰到的入口，更新日志没动）：`Notes/` 三个文件（§4 文件表）+ 导出文件第七类「便签」（`SettingsArchive.NoteEntry`，`currentFormat` 1 → 2）+ `AppDelegate` 接线（在剪贴板库之后开、打不开单独问；启动和换日清「最近删除」里到期的；跟着 `backupIfDue` 备便签库；退出 / 锁屏 / 睡眠前落盘——应用内更新的重启走的是 `NSApp.terminate`，同一条路）。规矩写进了 mac-native §1 §2 §3、mac-clipboard §1，手测在 `HANDTEST.md`「便签手测」1–9。实现时定的取舍：① **文件里便签的时间存整数毫秒**，不跟别的类别用 ISO 8601：合并要拿「改于」和本机的比，编码器的 ISO 只到秒，带小数秒的写法实测是截断的（14 万个毫秒值里一半读回来差 1 ms）。② 文件里的便签**逐条宽松解码**：哪一条缺字段、类型不对只丢那一条（别的类别是整个文件读不出来）；编号统一成大写，修订号夹到 10 亿以内（导入后还要 +1）。③ **库是更新版本写的不算坏**：不问、不动，说一声「更新后照常可用」（评审后从弹框改成刘海岛的一条警告），这次运行里便签不可用——不给「重新开始」（那会把新版本的数据挪开）；挑备份时更新版本写的那几份也不算可用。④ 标题和正文一样是打字改的，也走「停手再落盘」（拍板里只说了正文）。⑤ 顺序：新建 = 现有最小的 order − 1；挪动只改被挪那条（取两边中间的值），中间取不出值时整列重排；取消归档排回最前，从「最近删除」放回是回原处，归档列表按「改于」倒序。⑥ 导入时两边都有、文件更新的：**整条**换成文件的（连归档、固定、顺序），修订号取两边大的再 +1，「建于」留本机的；文件里比现在还晚的时间收成现在。⑦ 上限：5000 条、正文 1 MB（`Note.maxBodyBytes`）、标题 200 字（评审后加了 1 KB，并且仓库的写入口统一截断）；**正文仓库自己不拦**（还没有能写便签的界面）——第 2 批的编辑器、第 8 批的「存成便签」要按它拦，不然那条便签会让「便签」一类导不出去。⑧ 便签库的备份是**整库**（连「最近删除」里的；剪贴板那边只备留下的）；空表不备，所以便签全删光之后旧备份不再轮换、一直留着；用备份时把备份里有、图片目录里没有的图片补回来（不覆盖已有的）。⑨ 便签不可用时便签库的备份也不做；便签库当天备份查出有问题（`.damaged`，库还开着）时，每日 JSON 备份同样不带便签。⑩ 退出时还落不下去只留日志（这一批写不了便签，碰不到；有了编辑界面后要在 `applicationShouldTerminate` 里拦）。⑪ 导入表单上便签不可用时那一行照常能勾，说明写「会跳过」，结果岛说「便签没导入」并换成警告色。⑫ 不带便签的文件也写格式 2，不为它另留一条路。没在这台机器上看过的：两张表单多一行之后的样子（截图自检要带环境变量，这一批没跑；`renderTransfer` 已经跟着带上便签、加了两张不可用时的图）。
- 第 1 批评审后的一轮（2026-10-12，两份评审合并，同一个提交里）。**会丢东西的**：① 导入把本机的一条整条换掉时，被换掉的那一版（有文字、且和文件里的不一样）另存成一条新便签进「最近删除」，留 30 天——导入不让任何一段本机的文字无声消失。② 文件里「改于」比现在还晚的条目（那台电脑的钟快）：本机已有就不覆盖，只在本机没有时加进来（时间收成现在）；同一个文件连导两遍，第二遍什么都不变。③ 文字里的 NUL（U+0000）在每个写入口和读文件时去掉（`Note.sanitized(text:)`）：库里的文字按 C 字符串存取，碰到它后面的都丢了；`Database` 没动。④ 标题上限定成「200 个字、且 UTF-8 不超过 1 KB」，写入口和读文件时统一**截断**（`Note.sanitized(title:)`，原来读文件时是清空）。⑤ 便签库备份里图片尽力而为：一张张拷，拷不成的记日志，不让这份备份作废。⑥ 每日 JSON 备份太大时先去掉编出来最大的那一类、再去掉次大的，原因只列真去掉的（原来固定「片段 → 便签 → 生词本」，空的片段也会被说成「太多」）。⑦ 修订号读库时夹到和导入同一个上限（10 亿），+1 到顶为止不溢出；文件里顺序不是有限数的那条不要，库里的当 0。⑧ 落盘失败后自己再试（5 秒起、每次翻倍、封顶 60 秒；成了、仓库放手了就停），等待可注入；`adopt` 带出落没落下去，没落下去时导入结果说「便签没存上」（警告色）。⑨ 库不见了 / 是空文件时，只要 `notes-backups/` 里还有备份文件夹——哪怕都读不出来——就问，不当成全新安装。**启动**：开便签库、到期清理、第一次每日备份三样一起挪到启动流程的最后（`finishLaunchingNotes`；便签开好之前 `backupIfDue` 不做），弹框里那句「别的功能不受影响」才成立；库是更新版本写的改成刘海岛一条警告、不弹框。**界面文字**：只勾了便签又被跳过时标题是「没有导入 / 没有恢复」；`backups/` 里最近一份带着便签的每日 JSON 在时，恢复弹框多一段怎么从它导回来；「下次打开时再试」「便签这次用不了」。**接口**：`NoteStore` 去掉注入的钟，要用「现在」的改动带 `now: Date = .now`（同剪贴板、翻译历史的仓库）；`search` 改成 `static`；`capture(notes:)` 没有默认值，三处调用都传 `exportable`；编号校验用 `UUID(uuidString:)`；颜色夹范围收成 `Note.clamped(color:)`；`NotesRecovery.Failure` 说得出原因；`Database.swift`、`Backup.swift` 只各补了注释。
- 已知取舍（便签的备份，2026-10-12 评审时记下）：① 便签全删光之后不再备份（空表不备），旧备份不再轮换、一直留着。② 永久删除的便签在 `notes-backups/` 里最多还留 7 份（不是每天都开就更久），在每日 JSON 备份里同理。③ 便签连续 7 天不可用（每次都选「这次先不用」、或者一直是更新版本写的库）时，带便签的每日 JSON 会被不带的顶光——这期间 `notes-backups/` 不动，数据还在。
- 第 2 批（2026-10-12 做、2026-10-13 收尾；便签从这一批起能用：记、看、改、搜、归档、删、找回）。**做了什么**：① 三个全局动作追加在 `HotKeyAction` 末尾——快速记一条（默认 ⌥N）、新建便签、全部便签（后两个不设默认键）；`sections` 最前面：选了取消时录屏 / 录音什么都还没动）。⑤ 设置 › 便签的骨架（正文字号、打开全部便签、数据说明）。⑥ 版本 0.5.0、更新日志条目；规则 `mac-whisker-notes.mdc`（新）、`mac-overlay-panel` §1–§4、Whisker 核心的清单；手测 `HANDTEST.md`「便签手测」10–38；截图自检 `SnapshotProbeTests/notes()`。**实现时定的取舍**（说明里没写死的）：① **⌘⌫ 只在焦点在列表上时删除这条便签**；光标在标题、正文、搜索框里时它是输入框自己的「删到行首」（实现者原来做成「在正文里也删整条」，主会话审查时改回：同剪贴板面板「输入框里有字时 ⌘⌫ 归输入框」，在正文里按惯了的删行键不该删掉整条便签；在正文里删整条走工具栏、右键。第 3 **固定只是一个标记**（行上带图钉），不把固定的排到前面：拍板里固定是「打开着的便签点别处不收」（B④），列表顺序仍是拖出来的那个；第 3、4 批用它。③ **新建时最前面那条还是空白的就用它**，不再多建一条（连按 ⌘N、连点「新建便签」不会攒出一串空便签）。④ 快速记的目的地 = 没归档的里**最近改过**的 8
