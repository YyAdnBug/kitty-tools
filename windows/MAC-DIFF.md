# windows/MAC-DIFF.md：和 mac 版不一样的地方

界面和行为先照 mac（`AGENTS.md`「和 mac 版统一什么」）。这里记的是**现在实际不一样**的地方和原因，分两类：

- **长期例外**：Windows 上做不到，或者照搬会违背 Windows 用户的习惯、放弃系统的材质 / 无障碍。以后也不改。
- **还没对齐**：能照 mac 做、只是还没做。做完从这里删掉（原来排的「0.2.0」那几批 2026-10-30 已并进 0.1.0）。

改了界面的人顺手更新这一页。2026-10-29 用户：「windows 上有些窗口的布局和 macos 不一致……如果 windows 上有什么特殊的条件不能保持一致，可以添加到说明文档中」。

## 设置窗

2026-10-29 照 mac 的各页（`macos/KittyTools/Settings/*Tab.swift`，以 origin/main 为准）对过一遍：侧栏顺序、页头说明、分组和顺序、每组的说明写在组下面、
功能页第一行「启用 X」（功能关着时下面变灰、管数据的那几行除外）、各页最后一行「X 里的按键 · 查看全部快捷键…」、快捷键页分组和录制框、关于页的品牌页，都已经和 mac 一样。

### 长期例外

- **壳**：Windows 11 设置的样子（NavigationView + 设置卡，PLAN-v7 U6），不是 mac 的侧栏 + 分组表单；侧栏的选中是系统画的（mac 自绘是为了绕开 AppKit 把强调色压暗）。
- **窗口标题**固定「Kitty Tools 设置」，不跟着页名变：任务栏和 Alt+Tab 靠标题认出是哪个程序。
- **选项控件一律下拉框**：mac 两三项用分段、三到五项用横排单选；Windows 11 设置里选项都是下拉框，WinUI 3 也没有系统的分段控件。
- **mac 独有的几页没有**：便签、启动台、程序坞预览（PLAN-v10 D7、§4；状态屏、提醒 PLAN-v12 已做）。侧栏其余几页同 mac 的顺序。
- **通用**
  - 「动效 › 呼出面板时挤压弹开」只缩放面板里面的内容（mac 是整扇窗口逐帧改尺寸）：Windows 的窗口外框和阴影由 DWM 画，跟不上逐帧改尺寸。
  - 没有「菜单栏」一组：常驻入口是托盘，托盘图标显不显示由 设置 › 个性化 › 任务栏 管，程序自己藏不了。
  - 「权限」只有麦克风：Windows 上截图、粘贴回原程序、取选中的字都不用授权（mac 还有辅助功能、屏幕录制、剪贴板访问）。麦克风的状态读系统记在注册表里的总开关和「允许桌面应用访问你的麦克风」。
  - 「登录时自动打开」写注册表的 Run 项，没有 mac「要到登录项里允许」那一行。
  - 「数据」组多一行「从这台电脑移除 Kitty Tools…」：便携版没装进开始菜单，也要能干净地拿掉（mac 拖进废纸篓就行）。
  - 「同步」的话写的是「电脑」「OneDrive」，不是「Mac」「iCloud 云盘」。
- **侧栏分组**（PLAN-v16 G2）：NavigationView 里组标题是一行不选中的小字（点了收起 / 展开），不是系统的分组；没有 mac 的「桌面」组（启动台、程序坞预览）。
- **新功能标记**（PLAN-v16 G3）：托盘菜单是系统菜单，画不了强调色小圆点，「新」写在文字后面；设置页里一节标题后的「新」这一版没有条目用到。
- **欢迎引导**：三屏照 mac，第二屏 mac 是「先开两项授权」，Windows 不用授权，换成「它住在托盘里」；对话框是系统的底色（不是奶油底），换屏不滑动。
- **剪贴板**：说「应用」不说「App」（Windows 的叫法），排除的应用按 exe 名存。
- **启动器**：文件搜索走 Windows 搜索的索引，那一组只有「建了索引的位置」一行（mac 是 Spotlight，另有「完全磁盘访问」那一行）；浏览器只列 Windows 上装了的。
- **翻译**：查词没有「显示系统词典的释义」「打开词典」：Windows 没有系统词典的接口（PLAN-v3 §3.4）。
- **翻译服务**（PLAN-v14）：没有系统词典卡（有道词典当替代）、没有「系统翻译」（mac 的 Translation 框架；从 Mac 同步来的留在列表里、灰字「只在 Mac 上能用」、不开卡）。
- **面板拖边**（PLAN-v14 V9）：剪贴板、启动器、翻译浮窗用系统的拖边，下面两个角也能拖（一次改宽和行数，Windows 用户习惯拖角）；mac 只有左右边和下边。
- **钉图**：透明度滑块在右键菜单「透明度 N%…」打开的小浮层里（WinUI 的右键菜单放不了滑块）。
- **截图翻译盖回截图上**（PLAN-v16 S1）：Windows 的识字在行内代码块那里把一行切成几段，先按排接回一行再分段（mac 的 Vision 给的就是整行）；识字常丢下划线（`total_count` → `tota count`），这时译文里认不出代码词、不画底框。字是 Segoe UI（系统字体回退到微软雅黑），代码词 Cascadia Mono。
- **框选时保持屏幕原色**（PLAN-v16 S2）：Windows 的悬停窗口本来只描边、放大镜本来只描中间一格，开关只管压暗。
- **截图**：「截完图放哪」没有 mac 的「晾衣绳」（PLAN-v9 S7 定了只做两档）；快门声用系统自带的一个短音，不随包带素材。
- **截图 / 录制的保存位置分开**：截图默认存系统的「屏幕截图」文件夹，录屏录音默认存「视频\Screen Recordings」（同 Windows 自带的截图工具），两页各有一行「保存到」；mac 是同一个文件夹。
- **快捷键**：键名写成 `Ctrl + Shift + S`；组合至少带 Ctrl 或 Alt，或者单独一个 F1–F24（Windows 全局热键的限制）。录制框是系统按钮的样子。
- **录制**：倒数时选区边框不走蚂蚁线、录制中不呼吸发光，是静止的实线（四条细窗口只能填纯色，PLAN-v9 R6 定了不做）。
- **录制**：「标准」清晰度是长边封顶 1920（mac 是高分屏上宽高各减半）；GDI 那条退路录屏不认清晰度。
- **录制**：没有「编码（H.264 / HEVC）」：Windows 上播 HEVC 要另装扩展，录出来发给别人常常打不开（PLAN-v9 R5）。
- **关于**：没有「未来计划」（mac 那份 `roadmap.json` 写的是 mac 的计划，Windows 的计划在各版 PLAN 里，PLAN-v9 G4）；顶上是品牌粉淡下去的底（mac 是奶油色）；更新日志的条目没有「范围」那一列（Windows 的 `changelog.json` 没有 scope）；素材出处只有状态屏表情那一行（没有便签）。

### 还没对齐

- 同步有六类（片段与收藏、生词本、网页搜索、翻译服务、状态屏的状态、提醒——后两类是 PLAN-v12 加的）：mac 还同步设置、快捷键、功能开关和启动器收藏（PLAN-v8 G6，0.1.0 不做）。

## 其他窗口

剪贴板面板、启动器、翻译浮窗、截图遮罩照 PLAN-v7 对齐过（取舍在 PLAN-v7 §1）。已知的长期例外：

- 窗口外壳（圆角、阴影、亚克力）由 DWM 画，窗口退场不淡出。

主界面（托盘左键，PLAN-v10 §5）的长期例外：

- 从托盘打开时贴着任务栏、靠通知区那一侧弹出、从任务栏那边滑进来（同系统的音量 / 网络面板）；mac 挂在菜单栏图标下面。
- 格子宽 104（mac 92）：Windows 的字最小 12（mac 11），「钉住剪贴板里的图」要放得下；面板宽 548（mac 488）。
- 底栏「退出」没有键帽（mac ⌘Q）：Windows 没有通用的退出快捷键，Alt+F4 在面板上是收起。
- 托盘菜单里没有「划词翻译」（一点托盘原来的程序就不在前台了），主界面里有：点格子时先把前台还给原来的窗口再取字。

还没对齐的（能照 mac 做，0.1.0 先做了能用的那一版，S11 S12 的 ponytail）：

- 主界面开着的时候钉图那两格不跟着钉图状态实时变，下次打开才换（高亮滑动、跟着录屏 / 录音变 PLAN-v11 C2 已做）。

- 长截图面板：预览没有 mac 的纸带滑动、接缝闪品牌粉、高度数字滚动，预览是最近邻取样。
- 长图标注窗口是铺满工作区的深色窗口（mac 是盖住整屏的暗底遮罩）；缩放档位、实心 / 模糊这类选项、双击文字重新编辑、
  画到窗口边自动滚、空格拖动平移 PLAN-v11 C1 已做。
- mac 的刘海岛在 Windows 上是屏幕底部、任务栏上方的轻提示胶囊；跟刘海有关的交互不移植。
- 常驻入口是托盘，不是菜单栏：左键主界面、右键菜单（同 mac 菜单栏图标的左右键）。

状态屏（PLAN-v12 N5）的长期例外：

- 「透出」样式是一扇分层的压暗窗 + 一扇 HUD 小窗垫着那一列（mac 是一整块透明面板）：透明的 WinUI 窗在用户机器上是白的。所以透出样式不冒眼睛，眼睛只在告示样式上出。
- 拦不住的和 mac 不同：Ctrl+Alt+Del、Win+L、电源键、合盖、触屏的边缘手势、UAC 的安全桌面（mac 是电源键 / 触控 ID 键 / 合盖）。设置页里写的是 Windows 的这几样。
- 退出密码存在凭据管理器（mac 钥匙串），数字按扫描码认（mac 按键码），一样不看输入法和键盘布局。
- 动画表情 160 像素一格、12 帧每秒（mac 256 像素、24 帧）：素材 9.5 MB；24 帧要 18 MB、Windows 不一定装了 HEIF 解码器。

还没对齐的（ponytail，写在 StatusScreenView.cs / StatusPicker.cs 文件头）：

- 标题逐字只淡入、整行一起浮上来（mac 每个字还从模糊变清楚、各自上浮）；小字的数字滚动是一个字一个 TextBlock（mac 整行排一次再切开），冒号不抬高。
- 选状态的面板：选中的卡片不长成整屏、选中不放大到 1.04（Windows 版全 App 不做「从小放到大」）。

提醒（PLAN-v12 N6）的长期例外：

- 到点的样子 mac 挂在刘海岛上，这里挂在屏幕底部的提示上（挂着不自己收，× = 知道了）；全屏提醒借状态屏「透出」的做法（压暗窗 + 底板窗）。
- 提示音：存的是 mac 的 14 个名字（同步、导入两边认得），放的是 Windows 自带的 14 个声音（`Reminders.WindowsChimes`），叫法按 Windows 的声音起。
  没有 mac 的个人「声音」文件夹，自己的声音只走「选择文件…」（PLAN-v16 E2）；mac 认、Windows 文件名不许的编号（带 `\`、`*` 这类）照存、同步不丢，这台放通知声。
- 图标的「其他表情」（PLAN-v16 E1）：点了叫系统的表情面板（Win + .，Windows 没有给桌面程序叫面板的公开接口，往前台发这两个键），面板插进小输入框的那个字才收；
  系统表情用 Segoe UI Emoji 画（静态、扁平风格，和 mac 的 Apple 表情长得不一样）。托盘的状态子菜单只有标题，本来就不画图标。
- 边框的呼吸靠 UI 线程上 30 Hz 的计时器换整体透明度（mac 交给渲染服务），只在边框挂着时跑。
- 「N 分钟后提醒我」「暂停全部提醒」在托盘的「提醒」子菜单（mac 在菜单栏菜单）；启动器里一句话建提醒同 mac。

便签（PLAN-v13，2026-11-05 审查方在 Mac 上写、**没编译**；核验后照实际改这一节）的长期例外：

- 正文编辑器是 RichEditBox（mac TextKit 1）：任务方框是存着的那个字本身（Segoe UI Symbol 画），不是自己画的圆角方框；引用块没有左边的竖线（只缩进 + 色条色的字）；
  代码块的底是一行行的字底色，不是整块圆角矩形；查找是正文顶上一个输入框（mac 用系统查找条）；撤销自己管、按 1 秒分组（mac 用系统默认）。
- 行内图片：RichEdit 里的图拿不到把手，改宽度用右键「图片宽度」五档（mac 还能拖右下角）；裁切是一个对话框、只有自由比例（mac 在正文上原地盖一层，有 7 种比例）。
- 屏幕边缘那叠：透明窗口在用户机器上是白的，药丸、标签列、预览卡、打开的便签各是一扇不透明的小窗（药丸和标签列是亚克力），没有 mac 那块整屏高的透明面板；
  药丸那扇窗就是药丸那么大（12 宽，PLAN-v16 V1），「感应范围」是压在它下面的一扇看不见的分层小窗（同 mac 药丸外面那圈感应区），「不显示药丸」时只剩它；
  药丸的圆角是 DWM 的（Windows 11 的小圆角，不是 mac 那种两头全圆），出现、消失不淡入淡出；贴在工作区的边上（不挡任务栏）；
  打开的便签要打字，所以拿前台（mac 的面板不激活 App）；全屏判定 = 前台窗口盖满那块屏；按住 Alt 拖药丸（mac ⌥）。
- 导入的选择框不能同时选文件和文件夹：「导入…」是两项的小菜单（选择文件… / 选择文件夹…）。
- 快捷键：便签里的 ⌘ 换成 Ctrl；删除是 Ctrl+Shift+Delete（mac ⌘⌫；Ctrl+Backspace / Ctrl+Delete 在 Windows 是删一个词）；快速记一条默认 Alt+N。
- 托盘「便签」一节不画节标题（Windows 的托盘菜单都不画）。

还没对齐的（ponytail，写在各文件头）：

- 屏幕边缘那叠没有动画（扇出、滑出、收回）；标签不倾斜；打开的便签旁边没有 mac 那张跟着它的标签（标签列里那张描粗边表示打开着）；拖动排序时别的标签不让位。
- 便签墙不能拖动排序、方向键不能在卡片之间挑、Enter / 空格不能放大（mac 都能）；卡片一次全画（mac 先建看得见的）。
  卡片上的列表符号画成淡色圆点「•」（PLAN-v16 V2 要的；mac 是淡色的原符号「-」）；代码块只换等宽字，没有 mac 那块底色。
- 导入按文件名排序用当前区域的不区分大小写比较（mac 是「自然顺序」）；图片路径只看最后那个文件是不是符号链接（mac 整条路径解析完再比）。
