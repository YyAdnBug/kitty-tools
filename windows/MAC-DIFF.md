# windows/MAC-DIFF.md：和 mac 版不一样的地方

界面和行为先照 mac（`AGENTS.md`「和 mac 版统一什么」）。这里记的是**现在实际不一样**的地方和原因，分两类：

- **长期例外**：Windows 上做不到，或者照搬会违背 Windows 用户的习惯、放弃系统的材质 / 无障碍。以后也不改。
- **还没对齐**：能照 mac 做、只是还没做。排进 0.2.0（PLAN-v10 §3），在 `windows-next` 分支上做，做完从这里删掉。

改了界面的人顺手更新这一页。2026-10-29 用户：「windows 上有些窗口的布局和 macos 不一致……如果 windows 上有什么特殊的条件不能保持一致，可以添加到说明文档中」。

## 设置窗

2026-10-29 照 mac 的各页（`macos/KittyTools/Settings/*Tab.swift`，以 origin/main 为准）对过一遍：侧栏顺序、页头说明、分组和顺序、每组的说明写在组下面、
功能页第一行「启用 X」（功能关着时下面变灰、管数据的那几行除外）、各页最后一行「X 里的按键 · 查看全部快捷键…」、快捷键页分组和录制框、关于页的品牌页，都已经和 mac 一样。

### 长期例外

- **壳**：Windows 11 设置的样子（NavigationView + 设置卡，PLAN-v7 U6），不是 mac 的侧栏 + 分组表单；侧栏的选中是系统画的（mac 自绘是为了绕开 AppKit 把强调色压暗）。
- **窗口标题**固定「Kitty Tools 设置」，不跟着页名变：任务栏和 Alt+Tab 靠标题认出是哪个程序。
- **选项控件一律下拉框**：mac 两三项用分段、三到五项用横排单选；Windows 11 设置里选项都是下拉框，WinUI 3 也没有系统的分段控件。
- **mac 独有的几页没有**：便签、启动台、状态屏、程序坞预览（PLAN-v10 D7、§4）。侧栏其余几页同 mac 的顺序。
- **通用**
  - 「动效 › 呼出面板时挤压弹开」只缩放面板里面的内容（mac 是整扇窗口逐帧改尺寸）：Windows 的窗口外框和阴影由 DWM 画，跟不上逐帧改尺寸。
  - 没有「菜单栏」一组：常驻入口是托盘，托盘图标显不显示由 设置 › 个性化 › 任务栏 管，程序自己藏不了。
  - 「权限」只有麦克风：Windows 上截图、粘贴回原程序、取选中的字都不用授权（mac 还有辅助功能、屏幕录制、剪贴板访问）。麦克风的状态读系统记在注册表里的总开关和「允许桌面应用访问你的麦克风」。
  - 「登录时自动打开」写注册表的 Run 项，没有 mac「要到登录项里允许」那一行。
  - 「数据」组多一行「从这台电脑移除 Kitty Tools…」：便携版没装进开始菜单，也要能干净地拿掉（mac 拖进废纸篓就行）。
  - 「同步」的话写的是「电脑」「OneDrive」，不是「Mac」「iCloud 云盘」。
- **欢迎引导**：三屏照 mac，第二屏 mac 是「先开两项授权」，Windows 不用授权，换成「它住在托盘里」；对话框是系统的底色（不是奶油底），换屏不滑动。
- **剪贴板**：说「应用」不说「App」（Windows 的叫法），排除的应用按 exe 名存。
- **启动器**：文件搜索走 Windows 搜索的索引，那一组只有「建了索引的位置」一行（mac 是 Spotlight，另有「完全磁盘访问」那一行）；浏览器只列 Windows 上装了的。
- **翻译**：查词没有「显示系统词典的释义」「打开词典」：Windows 没有系统词典的接口（PLAN-v3 §3.4）。
- **钉图**：透明度滑块在右键菜单「透明度 N%…」打开的小浮层里（WinUI 的右键菜单放不了滑块）。
- **截图**：「截完图放哪」没有 mac 的「晾衣绳」（PLAN-v9 S7 定了只做两档）；快门声用系统自带的一个短音，不随包带素材。
- **截图 / 录制的保存位置分开**：截图默认存系统的「屏幕截图」文件夹，录屏录音默认存「视频\Screen Recordings」（同 Windows 自带的截图工具），两页各有一行「保存到」；mac 是同一个文件夹。
- **快捷键**：键名写成 `Ctrl + Shift + S`；组合至少带 Ctrl 或 Alt，或者单独一个 F1–F24（Windows 全局热键的限制）。录制框是系统按钮的样子。
- **录制**：倒数时选区边框不走蚂蚁线、录制中不呼吸发光，是静止的实线（四条细窗口只能填纯色，PLAN-v9 R6 定了不做）。
- **录制**：「标准」清晰度是长边封顶 1920（mac 是高分屏上宽高各减半）；GDI 那条退路录屏不认清晰度。
- **录制**：没有「编码（H.264 / HEVC）」：Windows 上播 HEVC 要另装扩展，录出来发给别人常常打不开（PLAN-v9 R5）。
- **关于**：没有「未来计划」（mac 那份 `roadmap.json` 写的是 mac 的计划，Windows 的计划在各版 PLAN 里，PLAN-v9 G4）；顶上是品牌粉淡下去的底（mac 是奶油色）；更新日志的条目没有「范围」那一列（Windows 的 `changelog.json` 没有 scope）；没有素材出处那两行（Windows 版没用状态屏的表情，也没有便签）。

### 还没对齐（0.2.0，windows-next）

- 同步只有四类（片段与收藏、生词本、网页搜索、翻译服务）：mac 还同步设置、快捷键、功能开关和启动器收藏（PLAN-v8 G6，0.2.0 也不做）。

## 其他窗口

剪贴板面板、启动器、翻译浮窗、截图遮罩照 PLAN-v7 对齐过（取舍在 PLAN-v7 §1）。已知的长期例外：

- 窗口外壳（圆角、阴影、亚克力）由 DWM 画，窗口退场不淡出。
- mac 的刘海岛在 Windows 上是屏幕底部、任务栏上方的轻提示胶囊；跟刘海有关的交互不移植。
- 常驻入口是托盘菜单，不是菜单栏。
