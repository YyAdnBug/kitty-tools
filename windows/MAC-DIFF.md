# windows/MAC-DIFF.md：和 mac 版不一样的地方

界面和行为先照 mac（`AGENTS.md`「和 mac 版统一什么」）。这里记的是**现在实际不一样**的地方和原因，分两类：

- **长期例外**：Windows 上做不到，或者照搬会违背 Windows 用户的习惯、放弃系统的材质 / 无障碍。以后也不改。
- **还没对齐**：能照 mac 做、只是还没做。做完从这里删掉（原来排的「0.2.0」那几批 2026-10-30 已并进 0.1.0）。

改了界面的人顺手更新这一页。2026-10-29 用户：「windows 上有些窗口的布局和 macos 不一致……如果 windows 上有什么特殊的条件不能保持一致，可以添加到说明文档中」。

## 设置窗

2026-10-29 照 mac 的各页（`macos/KittyTools/Settings/*Tab.swift`，以 origin/macos 为准）对过一遍：侧栏顺序、页头说明、分组和顺序、每组的说明写在组下面、
功能页第一行「启用 X」（功能关着时下面变灰、管数据的那几行除外）、各页最后一行「X 里的按键 · 查看全部快捷键…」、快捷键页分组和录制框、关于页的品牌页，都已经和 mac 一样。
2026-11-15 对齐检查又查出页头说明、快捷键页和启动器页的分节、提醒的编辑框等几处没跟上（`REVIEW.md`「对齐检查」R90–R102），修完删掉这一句。

### 长期例外

- **同步的设置与快捷键**（PLAN-v21）：和 Mac 只同步两边都有的设置（对照表在 PLAN-v21 §1）；**全局快捷键、截图工具栏的键只在 Windows 之间同步**（两边默认键刻意不一样、⌘ 在 Windows 上没有对应）；
  Windows 独有的设置（排除的应用按 exe 名、启动器命令的别名、浏览器来源……）另走 `windows-settings` 一类。只有 Windows 的文件夹里不写 `settings.json`，等有了 Mac 再写（免得 Mac 第一次加入时被清掉 Mac 独有的设置）。
- **启动器收藏只在 Windows 之间同步**（`windows-launcher`，PLAN-v21 D5）：mac 收到 Windows 独有的类型会整类停下，Windows 的应用路径在 Mac 上也打不开。
- **壳**：Windows 11 设置的样子（NavigationView + 设置卡，PLAN-v7 U6），不是 mac 的侧栏 + 分组表单；侧栏的选中是系统画的（mac 自绘是为了绕开 AppKit 把强调色压暗）。
- **窗口标题**固定「Kitty Tools 设置」，不跟着页名变：任务栏和 Alt+Tab 靠标题认出是哪个程序。
- **从子页回上一层**（PLAN-v23 W3）：Alt + ←、鼠标的后退侧键、键盘的「后退」键，子页左上角一行「‹ 页名」文字链接（Windows 设置、资源管理器的习惯）；
  mac 是工具栏常驻的「‹」按钮 + ⌘[ + 菜单「显示 › 返回」（Windows 的设置窗没有工具栏和菜单栏）。
- **侧栏当前页所在的组点标题收不起来**（PLAN-v16 G2 的单测锁着「当前页在里面就展开」）：mac 能收起、换走后也不展开；两边「跳到收起的组里的页时那组展开并记住」一样（PLAN-v23 W8）。
- **有序列表的键盘**（PLAN-v23 L1）：Enter 打开、Delete 删、Alt + ↑ / ↓ 上移下移（Windows 列表的习惯）；mac 是 ↑↓ 选、↩ 推进、⌫ 删，上移下移在右键菜单和无障碍动作里。
  列表下面没有 mac 系统样式的「+ −」小按钮条：「＋」是一颗下拉按钮，删除在右键菜单和 Delete 键。
- **选项控件一律下拉框**：mac 两三项用分段、三到五项用横排单选；Windows 11 设置里选项都是下拉框，WinUI 3 也没有系统的分段控件。
- **mac 独有的几页没有**：启动台、程序坞预览、访达右键、刘海岛（PLAN-v10 D7、§4，PLAN-v18 D12，PLAN-v20 §4；便签、状态屏、提醒 PLAN-v12 / v13 已做）。侧栏其余几页同 mac 的顺序。
- **通用**
  - 「动效 › 呼出面板时挤压弹开」只缩放面板里面的内容（mac 是整扇窗口逐帧改尺寸）：Windows 的窗口外框和阴影由 DWM 画，跟不上逐帧改尺寸。
  - 没有「菜单栏」一组：常驻入口是托盘，托盘图标显不显示由 设置 › 个性化 › 任务栏 管，程序自己藏不了。
  - 「权限」只有麦克风：Windows 上截图、粘贴回原程序、取选中的字都不用授权（mac 还有辅助功能、屏幕录制、剪贴板访问）。麦克风的状态读系统记在注册表里的总开关和「允许桌面应用访问你的麦克风」。
  - 「登录时自动打开」写注册表的 Run 项，没有 mac「要到登录项里允许」那一行。
  - 「数据」组多一行「从这台电脑移除 Kitty Tools…」：便携版没装进开始菜单，也要能干净地拿掉（mac 拖进废纸篓就行）。
  - 「同步」的话写的是「电脑」「OneDrive」，不是「Mac」「iCloud 云盘」。
  - 连 WebDAV 服务器（PLAN-v19，同 mac 0.9.0）时数据目录里那份镜像：没拿下来的文件放空文件 + Offline 属性（mac 放旧式 iCloud 占位 `.名字.icloud`）；
    账放在镜像旁边的 `<编号>.json`（mac 在镜像根上，Windows 的 `SyncDisk.LooksForeign` 会把它当成「放着别的东西」）；本机有的图是拷进镜像的
    （NTFS 没有克隆，镜像里的图和本机图片目录各占一份；mac 在 APFS 上不占地方）；比上限还大的放长期占位（mac 放同样大小的空洞文件）；
    服务器上的名字只认规范写法（编号大写、不是保留名：NTFS 不分大小写）；Windows 不同步的那几类的文件不拿。对话框是系统的 ContentDialog，
    「合在一起？」在同一个对话框里换内容问（ContentDialog 不能叠两个）。
- **插件**（PLAN-v20 K2）：只有「保持唤醒」一个。mac 0.9.0 把便签、提醒、状态屏、启动台、程序坞预览、访达右键、刘海岛七样改成了插件、侧栏改成五组，
  Windows 这次不动（mac 拍板页 P8）：便签、提醒、状态屏照旧是功能、照旧在「便签与提醒」一组，「插件」一组排在它后面。欢迎引导里不列插件（mac 第一屏下面有一组）。
- **保持唤醒**（PLAN-v20 K1）：**mac 0.9.0 发布前拿掉了**（`07da6ad3`，代码在 mac 分支 `plugins-wip`），现在只有 Windows 有；用电源请求（PowerSetRequest，`powercfg /requests` 里写「Kitty Tools：保持唤醒」，mac 是 ProcessInfo.beginActivity）；
  开始 / 停止 / 到点 / 进出时段的话在底部轻提示上（mac 刘海岛），子菜单在托盘（mac 菜单栏）；合上盖子睡不睡看系统「合上盖子时」的设置。
- **侧栏分组**（PLAN-v16 G2）：NavigationView 里组标题是一行不选中的小字（点了收起 / 展开），不是系统的分组；mac 0.9.0 起七样插件都在「插件」一组（没有「桌面」组了），Windows 是「便签与提醒」一组 + 「插件」一组（见上面「插件」那条）。
- **新功能标记**（PLAN-v16 G3）：托盘菜单里的「新」写在文字后面（mac 用的是系统菜单的徽标，Windows 的托盘菜单没有徽标）；设置页里一节标题后的「新」没有画（现在也没有这种条目：脚本命令、同步服务器并进 0.2.0 后不标）。
- **欢迎引导**：三屏照 mac，第二屏 mac 是「先开两项授权」，Windows 不用授权，换成「它住在托盘里」；对话框是系统的底色（不是奶油底），换屏不滑动。
- **剪贴板**：说「应用」不说「App」（Windows 的叫法），排除的应用按 exe 名存。
- **启动器**：文件搜索走 Windows 搜索的索引，那一组只有「建了索引的位置」一行（mac 是 Spotlight，另有「完全磁盘访问」那一行）；浏览器只列 Windows 上装了的。
- **设置 › 启动器**（REVIEW R93）：「脚本命令」是一行、点进子页（mac 铺在启动器页上：Windows 那一节的说明、文件夹、例子加起来比整页还长）；
  从启动器 Ctrl+K「改别名…」进来时滚到那一行、描两秒（mac 只列那一条）。「命令和别名」的筛选是下拉框（mac 分段），自带的叫「自带的命令」（Windows 的是 C# 写的内置命令，不是脚本）。
- **脚本命令**（PLAN-v18 L1，D7–D9）：用什么跑看扩展名（.ps1 / .cmd / .bat，装了 Python 的 .py），不看 `#!`；输出按系统代码页读（.py 和存成 UTF-8 的批处理按 UTF-8）；
  看全文、全部输出是一扇普通窗口（mac 在启动器面板里原地显示：Windows 的启动器失焦就收）；自带的七条（time、json、uuid、bcvt、url、b64、regt）是 C# 写的内置命令、
  不是随包的脚本（PowerShell 冷启动约 0.2 秒，列表打字就跑会卡），「切换深色模式」是系统命令 dark，「防止睡眠」是插件「保持唤醒」（PLAN-v20；mac 0.9.0 发布前又拿掉了插件、放回了 awake 脚本，`07da6ad3`）；没有「把脚本文件拖进来导入」（直接放进脚本文件夹，
  下载来的照样先看全文）、没有「命令的查找路径 / 重新读取」（PATH 每次从注册表重读）；启动器里脚本的行画头部 icon 写的表情和脚本旁边的图片（PLAN-v20 L1），写的是图标名（mac 的 SF 符号名）、网址时照旧画统一的脚本图标。
- **翻译**：查词没有「显示系统词典的释义」「打开词典」：Windows 没有系统词典的接口（PLAN-v3 §3.4）。
- **翻译服务**（PLAN-v14）：没有系统词典卡（有道词典当替代）、没有「系统翻译」（mac 的 Translation 框架；从 Mac 同步来的留在列表里、灰字「只在 Mac 上能用」、不开卡）。
- **面板拖边**（PLAN-v14 V9）：剪贴板、启动器、翻译浮窗用系统的拖边，下面两个角也能拖（一次改宽和行数，Windows 用户习惯拖角）；mac 只有左右边和下边。
- **钉图**：透明度滑块在右键菜单「透明度 N%…」打开的小浮层里（WinUI 的右键菜单放不了滑块）。
- **截图翻译盖回截图上**（PLAN-v16 S1）：Windows 的识字在行内代码块那里把一行切成几段，先按排接回一行再分段（mac 的 Vision 给的就是整行）；识字常丢下划线（`total_count` → `tota count`），这时译文里认不出代码词、不画底框。字是 Segoe UI（系统字体回退到微软雅黑），代码词 Cascadia Mono。
- **框选时识别元素**（PLAN-v20 E1）：用 UI Automation 按冻结时的窗口句柄读那扇窗口的元素框（mac 用辅助功能、现问指针下面的元素），不用授权；
  读在后台、指针第一次停进一扇窗口时读一次，读好之前只认整扇；mac 的「程序坞、菜单栏也能悬停」在这里对应任务栏：它在冻结的窗口列表里，能悬停、单击截下，开着识别元素时也读它的元素（`--element-probe` 读到 26 个；2026-11-15 只读代码，没上机看）。
- **框选时保持屏幕原色**（PLAN-v16 S2）：Windows 的悬停窗口本来只描边，开关只管压暗和放大镜的十字带（只描边，同 mac）。
- **放大镜**（REVIEW G6 照 mac 做了）：阴影是三层半透明圆角矩形叠的（Win2D 不起效果链）；信息卡的坐标是全局的物理像素（多屏时不重号，mac 是这块屏里的）；
  出不出放大镜照旧是 Windows 原来的条件（键盘在这块屏上就出），mac 在调整选区、拖标注时收起。
- **吸附**：mac 按住 ⌃ 暂停吸附，这里 Ctrl 给了十字准线，不跟（REVIEW G7 推荐「不适用」）；参考线同 mac。
- **截图**：「截完图放哪」没有 mac 的「晾衣绳」（PLAN-v9 S7 定了只做两档）；快门声用系统自带的一个短音，不随包带素材。
- **截图时的键**：钉图默认 P（mac T），T 给了截图翻译（mac 的翻译钮没有键，Windows `PLAN.md` 起就这么定）；比 mac 多自动滚 A、裁剪 X，一共 24 个（mac 21 个）；重做是 Ctrl+Y（PLAN-v9-annotate D5）。截图时的键只在 Windows 之间同步，不冲突。
- **识字接行**：截图翻译不进截图页（没开「盖回截图上」）时，识出的字接不接行跟 设置 › 截图「接起来」走（`Screenshot/ScreenshotSession.cs:929-931`）；mac 这里总是接。
- **截图 / 录制的保存位置分开**：截图默认存系统的「屏幕截图」文件夹，录屏录音默认存「视频\Screen Recordings」（同 Windows 自带的截图工具），两页各有一行「保存到」；mac 是同一个文件夹。
- **快捷键**：键名写成 `Ctrl + Shift + S`；组合至少带 Ctrl 或 Alt，或者单独一个 F1–F24（Windows 全局热键的限制），或者连按两下 Ctrl / Alt / Shift（PLAN-v18 第 3 批）。录制框是系统按钮的样子。
- **录制**：倒数时选区边框不走蚂蚁线、录制中不呼吸发光，是静止的实线（四条细窗口只能填纯色，PLAN-v9 R6 定了不做）。
- **录制**：「标准」清晰度是长边封顶 1920（mac 是高分屏上宽高各减半）；GDI 那条退路录屏不认清晰度。
- **录制**：没有「编码（H.264 / HEVC）」：Windows 上播 HEVC 要另装扩展，录出来发给别人常常打不开（PLAN-v9 R5）。
- **关于**：顶上是品牌粉淡下去的底（mac 是奶油色）；更新日志的条目没有「范围」那一列（Windows 的 `changelog.json` 没有 scope）；多一个「反馈问题」（见末尾「Windows 先做了的」）。两边都没有「未来计划」了（mac 0.9.0 也删了，`8e60ccf8`）。

### 还没对齐

- 识字时框里有二维码 / 条码，mac 复制码的内容（`92d1cf14`），这里没有：WinRT 没有识别静态图片里条码的公开接口，依赖又只许用微软的包，
  要自己在 Core 里写解码（REVIEW G1，用户 2026-11-15 定了「以后」）。

## 其他窗口

剪贴板面板、启动器、翻译浮窗、截图遮罩照 PLAN-v7 对齐过（取舍在 PLAN-v7 §1）。已知的长期例外：

- 窗口外壳（圆角、阴影、亚克力）由 DWM 画，窗口退场不淡出。

主界面（托盘左键，PLAN-v10 §5）的长期例外：

- 从托盘打开时贴着任务栏、靠通知区那一侧弹出、从任务栏那边滑进来（同系统的音量 / 网络面板）；mac 挂在菜单栏图标下面。
- 格子宽 104（mac 92）：Windows 的字最小 12（mac 11），最长的名字（七个字）要一行放得下；面板宽 548（mac 488）。
- 底栏「退出」没有键帽（mac ⌘Q）：Windows 没有通用的退出快捷键，Alt+F4 在面板上是收起。
- 托盘菜单和启动器的内置动作里没有「划词翻译」「划词翻译并替换」（一点托盘、打开启动器，原来的程序就不在前台了），主界面里有：点格子时先把前台还给原来的窗口再取字。

- 常驻入口是托盘，不是菜单栏：左键主界面、右键菜单（同 mac 菜单栏图标的左右键）。
- mac 的刘海岛在 Windows 上是屏幕底部、任务栏上方的轻提示胶囊；跟刘海有关的交互不移植。

长截图和长图标注（PLAN-v10 S11 S12）的长期例外：

- 长图标注窗口是铺满工作区的深色窗口（mac 是盖住整屏的暗底遮罩：透明的那层在用户机器上是白的）。
- 长截图面板不拿键盘（焦点留在被滚的程序上，不然滚轮、自动滚动落不到它身上）：mac 面板上的空格（开关自动滚动）、A（标注）、⌘S / ⇧⌘S 这里没有，
  点面板上的 ▶ / ⏸、标注、存储 ▾；Enter、Esc 照旧是长截图期间的全局临时键（REVIEW G2 推荐「不适用」的那半）。
- 长截图时和选区相交的钉图是**藏起来**、完了放回（mac 淡到 0.3、不接鼠标）：点穿要分层窗口，分层窗口再设「不进截图」在用户机器上整个看不见（2026-10-29 实测），
  不设又会被按选区抓屏拍进长图（REVIEW G3）。
- 长图标注的「识字并拷贝」认完窗口留着接着标（截图遮罩里识字是交出去、遮罩收起）；比识字引擎上限高的长图按空白行切段分开认（REVIEW G5）。

还没对齐的：

- 长截图面板：预览没有 mac 的纸带滑动、接缝闪品牌粉、高度数字滚动，预览是最近邻取样（G2 的按钮、橙色边框、一直在的速度那排已做）。

状态屏（PLAN-v12 N5）的长期例外：

- 「透出」样式是一扇分层的压暗窗 + 一扇 HUD 小窗垫着那一列（mac 是一整块透明面板）：透明的 WinUI 窗在用户机器上是白的。所以透出样式不冒眼睛，眼睛只在告示样式上出。
- 拦不住的和 mac 不同：Ctrl+Alt+Del、Win+L、电源键、合盖、触屏的边缘手势、UAC 的安全桌面（mac 是电源键 / 触控 ID 键 / 合盖）。设置页里写的是 Windows 的这几样。
- 退出密码存在凭据管理器（mac 钥匙串），数字按扫描码认（mac 按键码），一样不看输入法和键盘布局。
- 动画表情 160 像素一格、12 帧每秒（mac 256 像素、24 帧）：素材 9.5 MB；24 帧要 18 MB、Windows 不一定装了 HEIF 解码器。

还没对齐的（ponytail，写在 StatusScreenView.cs / StatusPicker.cs 文件头）：

- 标题逐字只淡入、整行一起浮上来（mac 每个字还从模糊变清楚、各自上浮）；小字的数字滚动是一个字一个 TextBlock（mac 整行排一次再切开），冒号不抬高。
- 选状态的面板：选中的卡片不长成整屏、选中不放大到 1.04（Windows 版全 App 不做「从小放到大」）。
- 自带的动画表情 16 个（mac 28 个：后加的 12 个这里只认不画）；没有「动画表情」那一格（release `emoji-pack-1` 按需下载）和「自动下载动画表情」开关（PLAN-v16 V1 b，等用户定）。提醒的图标同样。
- 编辑状态、编辑提醒还是对话框、点「保存」才存（mac 推进一页详情、即时存、底下有删除）：PLAN-v23 E1 排了。
- 图标格子旁边没有一直播动画的大预览，状态的样式预览是静止的（REVIEW G9）。状态、提醒的列表拖动排序 PLAN-v23 第 3 批已做（G8）。
- 编辑网页搜索的那一条同样是对话框（mac `SearchEngineDetail` 推进一页、即时存），和上一条一起在 PLAN-v23 E1 里。

提醒（PLAN-v12 N6）的长期例外：

- 到点的样子 mac 挂在刘海岛上，这里挂在屏幕底部的提示上（挂着不自己收，× = 知道了）；全屏提醒借状态屏「透出」的做法（压暗窗 + 底板窗）。
- 提示音：存的是 mac 的 14 个名字（同步、导入两边认得），放的是 Windows 自带的 14 个声音（`Reminders.WindowsChimes`），叫法按 Windows 的声音起。
  没有 mac 的个人「声音」文件夹，自己的声音只走「选择文件…」（PLAN-v16 E2）；mac 认、Windows 文件名不许的编号（带 `\`、`*` 这类）照存、同步不丢，这台放通知声。
- 图标的「其他表情」（PLAN-v16 E1；mac 现在叫「系统表情」，`7c203b88`）：点了叫系统的表情面板（Win + .，Windows 没有给桌面程序叫面板的公开接口，往前台发这两个键），面板插进小输入框的那个字才收；
  系统表情用 Segoe UI Emoji 画（静态、扁平风格，和 mac 的 Apple 表情长得不一样）。托盘的状态子菜单只有标题，本来就不画图标。
- 边框的呼吸靠 UI 线程上 30 Hz 的计时器换整体透明度（mac 交给渲染服务），只在边框挂着时跑。
- 「N 分钟后提醒我」「暂停全部提醒」在托盘的「提醒」子菜单（mac 在菜单栏菜单）；启动器里一句话建提醒同 mac。
- 一小时以内的提醒 mac 在刘海上倒数（能提前结束、推后 5 分钟），这里不跟（PLAN-v20 §4：刘海的交互不移植）。

便签（PLAN-v13，2026-11-06 在 Windows 上核验过）的长期例外：

- 正文编辑器是 RichEditBox（mac TextKit 1）：任务方框是存着的那个字本身（Segoe UI Symbol 画），不是自己画的圆角方框；引用块没有左边的竖线（只缩进 + 色条色的字）；
  代码块的底是一行行的字底色，不是整块圆角矩形；查找是正文顶上一个输入框（mac 用系统查找条）；撤销自己管、按 1 秒分组（mac 用系统默认）。
- 行内图片：RichEdit 里的图拿不到把手，改宽度用右键「图片宽度」五档（mac 还能拖右下角）；裁切是一个对话框、只有自由比例（mac 在正文上原地盖一层，有 7 种比例）。
- 屏幕边缘那叠：透明窗口在用户机器上是白的，药丸、标签列、预览卡、打开的便签各是一扇不透明的小窗（药丸和标签列是亚克力），没有 mac 那块整屏高的透明面板；
  药丸那扇窗就是药丸那么大（12 宽，PLAN-v16 V1），「感应范围」是压在它下面的一扇看不见的分层小窗（同 mac 药丸外面那圈感应区），「不显示药丸」时只剩它；
  药丸的圆角是 DWM 的（Windows 11 的小圆角，不是 mac 那种两头全圆），出现、消失不淡入淡出；贴在工作区的边上（不挡任务栏）；
  打开的便签要打字，所以拿前台（mac 的面板不激活 App）；全屏判定 = 前台窗口盖满那块屏；按住 Alt 拖药丸（mac ⌥）。
- 导入的选择框不能同时选文件和文件夹：「导入…」是两项的小菜单（选择文件… / 选择文件夹…）。
- 快捷键：便签里的 ⌘ 换成 Ctrl；删除是 Ctrl+Shift+Delete（mac ⌘⌫；Ctrl+Backspace / Ctrl+Delete 在 Windows 是删一个词）；快速记一条默认 Alt+N。
- 托盘「便签」一节不画节标题（Windows 的托盘菜单都不画）。

还没对齐的（ponytail，写在各文件头）：

- 屏幕边缘那叠没有动画（扇出、滑出、收回）；标签不倾斜；打开的便签旁边没有 mac 那张跟着它的标签（标签列里那张描粗边表示打开着）；拖动排序时别的标签不让位。
- 便签墙不能拖动排序（mac 能）；卡片一次全画（mac 先建看得见的）。
  卡片上的列表符号画成淡色圆点「•」（PLAN-v16 V2 要的；mac 是淡色的原符号「-」）；代码块只换等宽字，没有 mac 那块底色。
