## 3. 各项要点和替用户定的

### N1 汇率换算（第 1 批）

- 照 mac：写法、连接词、口语问法、倍数（100万、1.5k、2w）、算式金额、货币在前、只问汇率按 1 算、本机地区的货币当默认目标（左边就是它时换成美元）；
  结果大字「667.14 CNY」（小数位按币种，不到 1 的 4 位有效数字，金额是 1 时按汇率的精度），右侧小字「人民币 · 11-03 汇率」，
  Ctrl+K 多「复制原始数字」「复制汇率」；输「汇率 / huilv / currency」出用法提示（Enter / Tab 填进示例）；货币打到一半列候选，用过的排前面。
- 汇率表：同 mac，jsDelivr 上的 fawazahmed0/currency-api（CC0、不要密钥），连不上换它的备用地址；6 小时过期，取到前用旧的；一份都没有时「正在取汇率…」，
  停 0.3 s 再取（打字路过不发请求）。
- **替用户定的**：
  - 货币表（159 种 ISO 代码、简体 / 繁体 / 英文名、小数位）在 Mac 上用系统的 Locale 生成成 `KittyTools.Core/Resources/currencies.txt`
    （`swift windows/tools/currency-table.swift`），两边的货币名一字不差；Windows 的 `RegionInfo` 给不出每种货币的中文名。
  - 汇率表存在数据目录的 `exchange-rates.json`（不进设置文件、不导出、不同步，同 mac 不注册默认值）；用过的货币记在设置里 `launcherRecentCurrencies`（导出清单是白名单，本来就不带）。
  - 本机地区的货币取 `RegionInfo.CurrentRegion.ISOCurrencySymbol`，不在表里时按人民币。

### N2–N4（第 2 批，写到时补细节）

- N2：设置 › 剪贴板「面板」、设置 › 启动器第一组各一行「面板位置」；上次位置 = 用户拖到的地方（没拖过按屏幕上方）。`83040384` 的「跟随鼠标」照用，加「上次位置」和启动器那一行。
- N3：速度放在长截图面板上（不放设置页），`83040384` 的设置项和 `ScrollPacer` 换成 mac 389289d4 的做法：每帧发一小段像素滚轮、按 posted 和画面实际滚的像素对账校准。
- N4：照 mac 0f83c117；设置跟着导出导入。

### N5 状态屏（第 3–4 批，已写，细节和替用户定的在 REVIEW「第 3 批」）

- 2026-11-05 用户定：这一版窗口、合成、输入钩子都由审查方在 Mac 上写，Windows 只编译、核验、修编译错。
- 透出样式：分层压暗窗 + HUD 小窗（透明 WinUI 窗在用户机器上是白的）；眼睛只在告示样式上。
- 自检开关 `--status-screen-probe`：只拦带标记的注入事件，真的键盘鼠标照常放行。

### N6 提醒（第 5–6 批，已写，细节和替用户定的在 REVIEW「第 5 批」「第 6 批」）

- 模型、时间表、合并、和 mac 一字不差的同步行在 Core；到点的样子：轻提醒挂在底部提示上（`NoticeHost.Pin`）、边框是每屏四条分层窄窗、全屏借状态屏的压暗层 + HUD 底板。
- 入口：启动器「提醒 / tx / remind + 空格」一句话建、托盘子菜单、主界面一格、快捷键 `reminderNew`（不设默认键）；导出导入、同步都带提醒列表，处理到哪 / 暂停是各台自己的。
- 状态屏的状态列表的同步、边框的渐变呼吸、14 个提示音、标题逐字、小字滚动、藏指针在第 7 批补上（REVIEW「第 7 批」）。

### N5、N6（第 3–6 批，开工前补的一节）

要先定的 Windows 做法：拦输入用 `WH_KEYBOARD_LL` / `WH_MOUSE_LL` 吞掉（Ctrl+Alt+Del 拦不住，正好当最后的出口）；动画表情 mac 是 HEICS，
Windows 要在 Mac 上转成别的格式（WinUI 放 GIF 只有一位透明，边缘难看）；提醒到点的样子 mac 挂在刘海岛上，Windows 挂在底部提示上。
