# HANDTEST.md：手测清单

> 2026-11-03（PLAN-v11 D9）起：发版前走下面的「真机回归清单」，它代替原来的「发版冒烟清单」。到 0.1.0 为止的全部手测（发版冒烟清单 18 步 + 1–811，编号不变）原样归档在 `windows/docs/archive/HANDTEST-2026-11.md`；REVIEW、各版 PLAN、提交正文里「HANDTEST N」（N ≤ 811）「冒烟第 N 步」都去那里找，812 起在本文件末尾。
>
> **怎么走**：用要发的那个 Release 包（`build-release.ps1` 出的 setup.exe）从头走一遍，约一个半小时（要两台电脑的同步那两条另算）。每条「做什么 → 期望」，最后「→」后面是细节在哪：「冒烟 N」= 归档里「发版冒烟清单」第 N 步，纯数字 = 归档里那一条（812 起是本文件末尾的）。写着「只在 Dev 数据上」的会动数据，用 `%LOCALAPPDATA%\KittyTools.Dev` 那一套，别在用户的真数据上做。每次发版重走一遍，上一次的勾发版后清掉。
>
> **怎么加**：新一版 / 一批要真机验收的，在本文件末尾另起一节（节名写清是哪一版、哪一批），编号接着往下排（下一个是 854），条目前写拍板条目号（如「（M3）」），一条「做什么 → 期望」。那一版发布、真机走完后，把以后每次发版都该再看的（最容易坏、自动测不到的）并进真机回归清单，整节挪进归档。回归清单用 R 编号：新条目取下一个没用过的号、放进它那一组（组里不必按号码排），删掉的号不复用；细节指到归档或那一节，不在清单里展开；清单保持 40 条上下，加一条先想想能不能并掉一条。
> 自动测得到的（`dotnet test`、`--ui-snapshots`、`setup-e2e.ps1`、`update-e2e.ps1`、`--update-live`）照旧每次打包前跑，不写进这里。

## PLAN-v11 第 1 批：数据与隐私（M2 M3 M4 M7 M8 M10；812–826，2026-11-03，审查方在 Mac 上写、没编译）

mac 0.7.1（第四轮体检）修掉、Windows 也有的那几条，照 mac 同一条的做法改。数据目录一律用 `.Dev` 那一套的临时目录。

812. **改小保留期先问**（M2）：剪贴板里有几条两天前的普通历史（改系统时间或用测试库）→ 设置 › 剪贴板「保留普通历史」改成「1 天」→ 弹「保留普通历史改成「1 天」？」，说明「会删掉 N 条普通历史，收藏和片段不受影响。」；点「取消」或 Esc → 下拉框回到原来那档、一条没少；再改一次点「删除」→ 删了、出「已按新上限清理」。
813. 改成更长的（「30 天」→「90 天」）、改了也不会删东西的那一档 → 不弹框、直接生效。「图片最多占用」同样走一遍（说明写「N 张普通历史里的图片」）。
814. **截图历史的保留 / 最多占用**同样先问（「截图历史改成保留「7 天」？」「会删掉 N 条截图历史，连同留着的原图…」），取消回原值。
815. **关机 / 注销时清空**（M3）：开「退出时清空」，复制几条普通的、收藏一条 → **注销**（或重启）再登录、打开 → 普通历史没了、收藏还在。日志里有 `app.end-session` 和 `clipboard.cleared-on-quit`。
816. **闪退后启动先清**（M3）：开着「退出时清空」，复制几条 → 任务管理器结束进程（按 PID）→ 再打开：普通历史没了（日志 `clipboard.cleared-on-launch`）。
817. **删了的内容在库文件里找不到**（M3）：复制一段独特的字（比如 `kitty-secret-0815`）→ 「立即清空」普通历史 → 退出 → 用文本编辑器 / `findstr /m kitty-secret-0815` 搜数据目录里的 `kitty.sqlite3` 和 `kitty.sqlite3-wal`：搜不到（`-wal` 被截成 0 或很小）。
818. **撤销栈里的删除关机后不回来**（M3 顺带）：剪贴板面板里删一条（还能 Ctrl+Z）→ 注销 → 登录打开：那条没回来。
819. **马赛克打进历史原图**（M4）：截一张有字的图，打一块马赛克、画一个箭头 → 拷贝 → 打开截图历史：那条的缩略图、拷贝出来的都打了码；到数据目录 `shots\<编号>.png`（原图）看：马赛克那块也是方块，不是原文。
820. 历史里双击那条「改标注」→ 箭头还在、能改，马赛克那块是图的一部分（不是能删的标注）；再画一块新的马赛克 → 存 → `shots\<编号>.png` 里新的那块也打上了。「模糊」那档打进原图的是方块（成品照旧模糊，MosaicBurn 的 ponytail）。
821. **长图**：长截图标注里打马赛克（跨 4096 行的接缝那种）→ 拷贝 → 历史原图里那块是方块、接缝两边对得上。
