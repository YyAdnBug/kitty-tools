# HANDTEST.md

Windows 原生版的发版冒烟清单和每批手测。编号一直往下排，写「怎么做 → 应该看到什么」。
每批提交前自己先走一遍这一批的条目。

## 发版冒烟清单

（第 6 批补全；现在先按第 1 批的条目走。）

## 第 1 批：壳

环境：Windows 11 22H2 以上；至少测 100% 和 150% 缩放、浅色和深色、主屏一块。
需要时用第二块屏再走一遍多屏相关条目。

1. **首次运行**
   删掉 `%LOCALAPPDATA%\KittyTools.Dev`，从 `windows/` 构建后运行 `KittyTools.exe`。
   → 设置窗自动打开，通用页顶部有「欢迎使用 Kitty Tools」，里面有托盘溢出区的提示、
   默认快捷键、默认勾上的「登录时自动打开」和「开始使用」按钮；托盘图标已加上；
   点「开始使用」后欢迎块消失，`settings.json` 出现，`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
   里有 `KittyTools.Dev`，值是带引号的 exe 完整路径。

2. **单实例**
   应用已经在跑时再运行一次 `KittyTools.exe`。
   → 第二个进程退出（任务管理器里只剩一个），第一个实例把设置窗打开到前台。

3. **托盘菜单**
   右键托盘图标。
   → 和左键同一个菜单：剪贴板历史 / 启动器 / 输入翻译 / 截图 / 截图翻译 / 识字 ｜
   复制即译 / 暂停记录剪贴板 ｜ 设置… / 检查更新 / 退出 Kitty Tools。
   没做的模块是灰的，右边仍写快捷键；复制即译能勾 / 取消并把状态写进 `settings.json`；
   暂停记录剪贴板只在这次运行里有效，重启后恢复记录（PLAN §6.1）。
   设置…能打开设置窗，退出能退进程；左键和右键都能弹出同一个菜单。

4. **热键默认值**
   依次按 Alt+C、Alt+Space、Alt+E、Alt+T、Alt+S、Alt+X、Alt+O。
   → Alt+C 打开剪贴板面板（第 2 批接上），Alt+Space 打开启动器占位，其余弹轻提示「第 3 / 5 批接上」。
   浮层打开时再按同一个热键 → 收起并把前台还给打开前的窗口。

5. **热键占用**
   用另一个程序先注册 Alt+C（或先开一个占着 Alt+C 的 Kitty Tools 实例），再启动本应用。
   → 设置 › 快捷键里「剪贴板历史」那一行显示红色的「被占用」，托盘菜单里这一项右边
   不写 Alt+C；其它键正常。

6. **录制 / 清空 / 恢复默认**
   设置 › 快捷键，点「剪贴板历史」的「录制」，按 Ctrl+Alt+K。
   → 行里变成 Ctrl+Alt+K，状态「正常」，`settings.json` 的 modifiers=3、virtualKey=75；
   按 Ctrl+C 录制会被拒绝并说明原因；按 Esc 取消；点「清空」显示「未设置」；
   「全部恢复默认」回到 Alt+C / Alt+Space / …
   Win 组合、单独字母、Shift+字母、Alt+F4/Tab/Esc 都应被拒绝。

7. **浮层关闭**
   打开 Alt+C 后分别试 Esc、Ctrl+W、再按 Alt+C、点别的窗口。
   → 都收起；前三种把前台还给打开前的窗口，点到别处收起时不还前台（用户已经点走了）。
   浮层有系统圆角、阴影、没有标题栏条、亚克力透明、搜索框已经有焦点可以打字。

8. **轻提示**
   按 Alt+T / Alt+X。
   → 鼠标所在屏顶部居中、往下 12 px 出现深色圆角条，停约 2 s 自己消失；
   不抢焦点、不接鼠标；新的一条会替换旧的。三种语气（普通 / 警告 / 错误）颜色不同；
   管理员粘贴被拦时是警告。

9. **设置窗**
   托盘 › 设置…。
   → 普通窗口有标题栏和任务栏图标，Mica 背景，左边导航「通用 / 快捷键 / 关于」。
   通用：登录时自动打开能改并写注册表；外观改浅色 / 深色 / 跟随系统立即变；
   强调色换「跟随系统」后强调色跟着系统；自动检查更新能存；
   「打开数据目录」打开 `%LOCALAPPDATA%\KittyTools.Dev`。
   关于：版本 0.1.0、更新日志一行、检查更新暂时灰、打开数据目录可用。
   关闭设置窗不退出进程，托盘还在。

10. **深浅色 / 150%**
    外观切浅色、深色各看一遍；显示缩放切到 150% 再各看一遍。
    → 设置窗、浮层、轻提示都不被裁切；浮层位置在鼠标所在屏顶部 20%；
    文字和背景对比度正常；切换缩放后热键和托盘仍然可用。

11. **日志**
    跑一遍上面的操作，看 `%LOCALAPPDATA%\KittyTools.Dev\logs\kitty-YYYYMMDD.log`。
    → 只有事件、错误码、时间，没有剪贴板文本、原文、译文、URL、请求头、密钥；
    只保留最近 7 天的 `kitty-*.log`。

12. **数据目录分开**
    同时装 Debug 和 Release（或先跑 Debug 再跑 Release）。
    → 数据目录分别是 `KittyTools.Dev` 和 `KittyTools`，settings、日志、注册表 Run 值、
    互斥量、实例管道都分开；两个能同时跑（热键会冲突，后启动的那个标红）。

## 第 2 批：剪贴板

环境：Windows 11 22H2 以上；100% 和 150% 各一次；浅色和深色。
下面「面板」指 Alt+C 打开的剪贴板历史。

13. **采集文本**
    在记事本、浏览器正文、VS Code 里各复制一段文字，再打开面板。
    → 每条出现在最上面（按复制时间新→旧），显示预览、来源和字数；
    同样的内容再复制一次只把原条目挪到最前，不新增一条。

14. **带格式文本**
    从网页复制一段带粗体 / 链接的文字，粘到 Word 或 VS Code。
    → 默认粘贴保留格式；面板里 Shift+Enter 或右键「粘贴为纯文本」只粘纯文本。

15. **采集图片**
    截图（Win+Shift+S）或用看图软件复制一张图，打开面板。
    → 出现「图片 宽 × 高」，右边预览等比显示并标尺寸；连按同一张图不会多出重复条目；
    `images\` 里只有一张 PNG。

16. **采集文件**
    在资源管理器里复制一个文件，打开面板。
    → 出现文件名；右键「在资源管理器中显示」能选中它；粘回资源管理器会复制一份。

17. **隐私格式**
    用 KeePass 复制一条密码（或跑 `windows/build/set-private.ps1` 模拟打标记）。
    → 面板里不出现这条；日志里有 `clipboard.skip-private`，没有密码内容。
    紧接着复制普通文本 → 照常记录。

18. **排除的应用**
    设置 › 剪贴板 › 不记录的应用加一个 `notepad.exe`，从记事本复制文字。
    → 不记录；移除后又照常记录。默认列表里 KeePass / KeePassXC / 1Password / Bitwarden
    在装了的机器上同样不记录。

19. **敏感文本过滤**
    复制一行 `sk-` 开头的长串、一段 `Bearer …` 或一个能过 Luhn 的 16 位卡号。
    → 不记录；设置里关掉「不记录疑似密钥和卡号」后再复制就记录。

20. **暂停记录**
    托盘菜单勾「暂停记录剪贴板」，复制几段文字；退出并重开 Kitty Tools。
    → 暂停期间不记录；`settings.json` 里没有暂停状态，重开后恢复记录。

21. **搜索**
    面板搜索框里输入两个词（空格分开）、大写、全角字母，再搜来源名。
    → 两个词都要命中（AND）；大小写和全半角不影响；顺序仍是时间从新到旧；
    没有结果时底栏写「没有匹配的条目」。

22. **收藏和范围**
    选中一条按 Ctrl+D（或右键收藏），点「收藏」范围，再点「全部」。
    → 条目右侧出现品牌粉星标；「收藏」里只剩收藏的；再按 Ctrl+D 取消。

23. **面板按键**
    依次试 Enter、Shift+Enter、Ctrl+1–9、Ctrl+C、Ctrl+D、Delete、Ctrl+Z、Ctrl+T、Tab、Esc。
    → 前两个粘贴，Ctrl+数字粘第 N 条，Ctrl+C 只复制不关面板，Delete 删除选中（先不真删），
    Ctrl+Z 连着撤销，Ctrl+T 弹「第 3 批接上」，Tab 在全部 / 收藏间切换，
    Esc 先清空搜索词、再按关闭；焦点一直在搜索框，↑↓ 选条目。

24. **右键菜单**
    在一条上点右键。
    → 菜单是：粘贴、粘贴为纯文本、复制、收藏 / 取消收藏、（文本）翻译、
    （图片）钉到屏幕、（文件）在资源管理器中显示、删除；名字和按键一一对应。

25. **粘贴回原窗口**
    先在记事本 / Edge / VS Code / 管理员身份运行的记事本里放好光标，再 Alt+C 选一条按 Enter。
    → 面板收起，前台回到那个窗口，内容粘进去；管理员窗口只写剪贴板并提示
    「目标窗口以管理员身份运行，请手动粘贴」。

26. **粘贴前检查**
    复制一个文件后把它移走（或让图片文件被手工删掉），再选这一条粘贴。
    → 不粘、轻提示「没能粘贴」，并说明图片文件丢了 / 文件已经不在原处。

27. **保留天数**
    设置 › 剪贴板 › 保留普通历史改成 1 天；把一条普通条目的时间改早或等一天。
    → 重新打开面板（或重启）后超期的普通条目被清掉，收藏的还在；底栏条数跟着变。

28. **图片上限**
    设置 › 剪贴板 › 图片最多占用改成 128 MB，再连续复制几张大图。
    → 超了从最旧的普通图片删起，最新的一张这一轮不删，收藏的图片不占额度也不删；
    设置页「占用」里的 MB 数跟着变。

29. **清空**
    设置 › 剪贴板 ›「立即清空普通历史」点两次。
    → 普通条目清空，收藏还在；面板里只剩收藏的条目。

30. **每次收起都复位**
    搜索、切到「收藏」、选到第三条，然后 Esc 收起再 Alt+C 打开。
    → 搜索词清空、范围回到「全部」、选中回到第一条；删除的条目这时才真的从库里删掉。

31. **深浅色 / 150%**
    外观切浅色、深色各看一遍；显示缩放切到 150%。
    → 面板不裁切、不超出工作区；搜索框 56 高、字号 20；列表和预览的对比度正常；
    浮层仍在鼠标所在屏顶部 20%。

32. **日志**
    走一遍上面的操作，看 `%LOCALAPPDATA%\KittyTools.Dev\logs\kitty-YYYYMMDD.log`。
    → 只有 `clipboard.record kind=… count=…`、跳过原因和错误，没有正文、图片、文件路径或来源标题。

33. **5000 条搜索耗时**
    跑 `dotnet test windows/KittyTools.Tests` 里的 `SearchPerformanceTests`（或看提交报告里的数）。
    → 5000 条首次搜索（含折叠缓存）在 10 ms 量级，之后每次远低于 1 ms。

## 第 3 批：翻译

环境：Windows 11 22H2 以上；100% 和 150% 各一次；浅色和深色。
下面「浮窗」指 Alt+T 打开（或划词 / 复制即译弹出）的翻译浮窗。

34. **默认服务**
    第一次打开设置 › 翻译（或删掉 `settings.json` 后重开）。
    → 服务列表只有「智谱 GLM（免费）」且启用；没有内置 key 的构建里点「详情」会提示填自己的 API Key。

35. **加服务**
    设置 › 翻译 ›「＋ 添加服务」。
    → 菜单里列着还没加的内置服务（Google / DeepL / 微软）、9 个 AI 厂商预设，以及「自定义 OpenAI 兼容 / Azure OpenAI」。
    加进来后能勾选启用、点「详情」改地址 / 模型 / 协议 / 密钥，删除内置服务后再加回来还在。

36. **测试连接**
    在服务「详情」里填好 Key，点「测试连接」。
    → 成功时显示「连接成功：你好」；失败时显示中文原因（缺 Key / 地址错 / 网络不通 / 服务端错误）。
    密钥只进凭据管理器（`控制面板 › 凭据管理器 › Windows 凭据` 里能看到 `KittyTools.Dev/…`），`settings.json` 里没有。

37. **输入翻译**
    按 Alt+T，输入一段英文，Enter。
    → 浮窗出现在鼠标右下（放不下翻到左上），一个服务一张卡；结果逐字出来，完成后显示「完成」和「复制」。
    再按 Alt+T 收起；再打开保留上次原文和结果，原文全选（打字就替换）。

38. **中文输入**
    输入一段中文，Enter。
    → 自动目标变成英语（第一/第二语言默认简中 / 英语）；浮窗底栏写「检测：简体中文 · 目标：英语」。

39. **固定源 / 目标**
    点顶上两枚语言胶囊，把源固定成英语、目标固定成日语；再输入中文。
    → 请求按固定的方向走；源自动、目标正好是原文语言时，底栏写「原文已是…，改按自动」，并译成另一种语言。

40. **流式与截断**
    用一个慢的本地服务（或长文本）看流式；再让服务返回 `finish_reason: length`。
    → 正文逐字出现、末尾有光标；截断时半截照常显示并写「只翻了前一部分」，不算完成（不自动复制）。

41. **错误分两种**
    把 AI 地址改成错的、把 Key 清空、断网各试一次。
    → 配置 / 密钥问题：橙/红卡 +「打开设置」直达这个服务；网络 / 服务问题：「重试」。
    重试会重新发这次请求；日志里没有 URL、请求头、密钥。

42. **划词翻译**
    在记事本、Edge、VS Code、Word 里选中一段文字，按 Alt+E。
    → 取到词之前浮窗不出现；出现后原文就是选中的文字并开始翻译；
    取不到时打开输入翻译，占位文字写「没取到选中的文字，可以直接输入或粘贴」。

43. **剪贴板兜底**
    在一个 UIA 读不到选区的程序里选中文字，按 Alt+E。
    → 短暂备份剪贴板 → 发 Ctrl+C → 读回文字 → 还原剪贴板（原来是什么还是什么）；
    目标窗口以管理员身份运行时只提示，不动剪贴板。

44. **复制即译**
    托盘菜单或浮窗「⋯」打开复制即译，复制一段英文。
    → 浮窗在鼠标旁只露出、不抢焦点；翻译完不自动复制（剪贴板还是刚复制的原文）；
    点窗口外面自己收起。复制网址、单行路径、纯数字、超过 32 KB 的、和上次相同的、中文（目标自动）都不弹。

45. **剪贴板面板的「翻译」**
    剪贴板面板里选一条文本，Ctrl+T 或右键「翻译」。
    → 翻译浮窗出现并翻这一条；剪贴板面板收起（Windows 下浮窗要拿焦点）。

46. **复制结果**
    浮窗里按 Ctrl+1–9 或点卡片「复制」；设置里打开「自动复制」再翻一次。
    → 剪贴板变成译文，并记进剪贴板历史（自家生成）；自动复制只复制第一个服务的结果；
    复制即译带来、没改过的原文不自动复制。

47. **固定与关闭**
    按 Ctrl+P 或点图钉，再点别的窗口；然后按 Esc。
    → 固定后点别处不收起，Esc 仍关闭；没固定时失去激活就收起；关闭不退出进程。
    顶栏能拖动窗口，左右边能改宽并记住。

48. **Microsoft 免 key**
    只启用「微软翻译」、清掉 Key，翻一句英文。
    → 走 Edge 浏览器翻译的免登录接口，返回中文；填了 key 后走认知服务并带区域。

49. **Google / DeepL / 智谱**
    分别填 key 试一次；DeepL 免费版 key 以 `:fx` 结尾走 api-free，自建 DeepLX 填地址。
    → 都能出译文；缺 key 时是配置类错误，不会去请求。

50. **AI 厂商预设**
    选 OpenAI / DeepSeek / 通义千问 / Kimi / 硅基流动 / OpenRouter / Gemini / Anthropic / Ollama 之一，填 key / 地址。
    → 地址自动补 `/chat/completions`；关思考参数按厂商分档，400 / 422 时降一档重试；
    OpenCode 地址带会话 ID 和 User-Agent。

51. **深浅色 / 150%**
    外观切浅色、深色各看一遍；显示缩放切到 150%。
    → 浮窗不裁切、不超出工作区；卡片、语言胶囊、按钮的对比度正常；宽度和位置记住。

52. **日志和设置**
    走一遍上面的操作，看 `settings.json` 和日志。
    → 日志只有 show/hide/focus/selection 字数和错误，没有原文、译文、URL、请求头、密钥；
    `settings.json` 里只有语言、服务名 / 地址 / 模型、窗口位置，没有密钥。

53. **英文 / 日文 / 韩文 / 俄文检测**
    分别输入一句英文、日文、韩文、俄文。
    → 检测结果分别是对应语言；纯数字 / 符号不检测（复制即译直接跳过）。

## 第 4 批：启动器

环境：Windows 11 22H2 以上；100% 和 150% 各一次；浅色和深色。

54. **应用目录**
    按 Alt+Space 打开启动器，先输入「计算」「设置」「chrome」。
    → 商店应用（计算器、设置）和桌面应用（Chrome 等）都在；都带自己的图标；
    商店应用的副标题是「商店应用」，桌面应用是「桌面应用」或开始菜单里的分组名。

55. **拼音和缩写**
    用 `wx`、`weixin`、`jisuanqi`、`browser`、`vsc` 搜。
    → 中文名能用全拼 / 首字母搜到；英文名能用缩写搜到（Visual Studio Code → vsc）。
    结果按匹配分排序：完全相同 > 开头 > 词首 > 缩写 > 子串。

56. **打开应用**
    选中 Chrome 按 Enter。
    → 启动器收起，Chrome 到前台；再打开启动器、清空查询，「常用」里出现 Chrome。
    商店应用（计算器）也能打开。

57. **管理员 / 文件位置**
    桌面应用按 Ctrl+Shift+Enter；按 Ctrl+Enter。
    → 前者弹 UAC 以管理员身份运行；后者在资源管理器里选中它的快捷方式。
    商店应用这两项都不能用，轻提示说明原因。

58. **系统设置页**
    输入「显示」「声音」「网络」「Windows 更新」。
    → 每条副标题「系统设置」，Enter 打开对应的 `ms-settings:` 页面。

59. **系统命令**
    输入「锁定」「睡眠」「注销」「重启」「关机」「清空回收站」，拼音 `suoding` / `guanji` 也行。
    → 锁定、睡眠直接执行（自己确认安全再按）；
    注销 / 重启 / 关机 / 清空回收站第一下只把副标题换成「再按一次 Enter 确认」，同一个再按一次才执行。

60. **计算**
    输入 `1+2*3`、`(1+2)*3`、`2^3^2`、`200*15%`、`100+10%`、`（1+2）×3`、`1,299*3`。
    → 每条都出「计算结果」卡；Enter 把结果粘回原窗口，Ctrl+Enter 只复制结果；
    `1/0`、`1+`、`2024-01-01`、`12` 不出计算卡。

61. **网址直达**
    输入 `linux.do`、`localhost:3000`、`docs.rs/serde`、`https://a.com/x`。
    → 第一条「在浏览器中打开」，Enter 用默认浏览器打开；`Safari.app`、`install.sh`、`file.txt` 不算网址。

62. **路径直达**
    输入 `C:\Windows`、`%TEMP%`、`~\`。
    → 存在的路径出现「打开」，Enter 打开；不存在的、`./foo` 这类相对路径不出。

63. **网页搜索**
    输入 `g swift`、`bing 天气`、`bd 北京`。
    → 关键词直达对应的搜索引擎；`calc` 这类没有本地结果时，最后出一张 Bing 兜底卡；
    有本地结果（计算、应用、路径）时不显示兜底。

64. **网页搜索设置**
    设置 › 启动器，勾某个搜索的「兜底」（只能一个）、上下移动、删除、添加。
    → 排序和兜底立即生效；清空使用记录只清「常用」，不动搜索列表。

65. **面板按键**
    依次试 ↑↓（到头循环）、Enter、Ctrl+Enter、Ctrl+Shift+Enter、Ctrl+1–9、Tab、Ctrl+C、Esc、双击、右键。
    → 都和 PLAN §8 一致；Tab 把选中项的名字补进搜索框；Ctrl+C 只复制路径 / 网址；
    Esc 先清空查询再关闭；右键菜单和按键一一对应。

66. **常用和使用记录**
    连续打开几个 App / 设置页，再清空查询。
    → 「常用」按使用频率排，最多 8 行；每打开成功一次分才涨；清空后「常用」变空。

67. **60 秒保留查询**
    输入 `chrome`、不执行，点窗口外面收起；60 秒内再按 Alt+Space。
    → 查询和选中项都还在（全选）；超过 60 秒或执行过一项后再打开就是空查询。

68. **`cb` 关键词**
    输入 `cb 测试`，Enter。
    → 启动器收起，剪贴板面板打开，搜索框里是「测试」。

69. **`fy` 关键词**
    输入 `fy hello`，Enter。
    → 启动器收起，翻译浮窗打开并翻译 hello。

70. **应用目录刷新**
    新装一个开始菜单应用，等 5 分钟后（或重启）再打开启动器。
    → 新应用出现；扫描时先用上一次的结果，底栏写「正在扫描应用…」（第一次打开时）。

71. **设置 › 启动器**
    从托盘 / 设置窗打开这一页。
    → 网页搜索列表、兜底开关、上下移动、添加 / 删除、清空使用记录都在；
    改完立即写 `settings.json`。

72. **深浅色 / 150%**
    外观切浅色、深色各看一遍；显示缩放切到 150%。
    → 面板不裁切、不超出工作区；行高 48、最多同时看到 8 行；图标和文字对比度正常。

73. **日志**
    走一遍上面的操作，看日志。
    → 只有 launcher.apps 的数量 / 来源、启动失败和错误，没有搜索过的词、文件路径或应用名列表。

## 第 5 批：截图

环境：Windows 11 22H2 以上；100% 和 150% 各一次；浅色和深色；单屏和双屏各一次。

74. **冻结帧**
    按 Alt+X，先别动，看屏幕。
    → 整块屏立刻变成按下那一瞬的画面（不跟着后面的窗口动）；多屏时每块屏都盖上，鼠标所在屏有「拖动框选」提示和放大镜。
    没授权的受保护内容（DRM 视频）会是黑的，日志没有内容。

75. **框选**
    拖一个框；反方向拖；按住 Shift 拖；按住 Alt 拖；拖到窗口边附近；鼠标悬停窗口后单击。
    → 框跟着鼠标任意方向拉；Shift 是正方形、Alt 从中心；边和窗口边 6 px 内会吸住；
    悬停窗口时整窗高亮，单击直接选中整窗。

76. **调整选区**
    拖 8 个手柄；拖四条边；在选区里拖；把选区拖到屏幕外。
    → 手柄和边都能改大小；越过对边会翻过去；拖里面是平移；选区不会跑出屏幕。
    右下角（或左上，放不下时）的尺寸胶囊是当前像素数。

77. **放大镜和取色**
    鼠标移到选区里不同位置，按 C。
    → 放大镜 11×11、8 倍，中心格有白框；下面写全局坐标和 `#RRGGBB`；
    C 把色值写进剪贴板并记进历史，然后退出截图。

78. **复制和历史**
    选区按 Enter（或 Ctrl+C）。
    → 剪贴板同时有 PNG 和 CF_DIBV5；剪贴板历史里多一条「截图」，尺寸和选区一致。

79. **保存**
    选区按 Ctrl+S；再按 Ctrl+Shift+S；设置 › 截图里换一个文件夹再 Ctrl+S。
    → Ctrl+S 存到设置的文件夹（默认 `图片\Screenshots`），文件名 `截图 年-月-日 时.分.秒.png`；
    Ctrl+Shift+S 弹系统的另存为；设置里「恢复默认」回到系统「屏幕截图」文件夹。

80. **标注**
    工具栏依次选矩形、箭头、画笔、文字、马赛克，各画一笔；文字输入框里打中文和英文。
    → 都在选区里按当前颜色 / 线宽画出来；文字在点下去的位置，确定后留下；马赛克是 8 px 的方块。
    画完再复制 / 保存，导出的 PNG 里标注和屏幕上一致（像素 1:1，不是截图软件的截图）。

81. **撤销 / 重做 / 颜色 / 线宽**
    画三笔，点 ↶ 两次，再点 ↷ 一次；点颜色圆点换色；点「3」换线宽。
    → 撤销按顺序回退，重做按顺序恢复；换色后新画的用新颜色，旧的不变；线宽 2 / 3 / 5 / 8 循环。
    选「选择」工具后拖里面只移动选区，不画。

82. **工具栏**
    选区下方（放不下时上方）出现工具栏；点每个按钮。
    → 工具高亮当前项；复制 / 保存 / 钉图 / 识字 / 翻译 / ✕ 都执行对应动作；工具栏不超出屏幕。

83. **钉图**
    选区按 P（或点「钉图」）。
    → 截图以原尺寸钉在屏幕上，无边框、置顶；拖动可移动；滚轮 10%–500%；双击 / Esc 关闭；
    Ctrl+C 复制、Ctrl+S 快存、Ctrl+Shift+S 另存为、O 识字、0 恢复 100%、右键菜单同这些。

84. **剪贴板图片钉图**
    复制一张图片，打开剪贴板历史，右键图片 →「钉到屏幕」。
    → 图片居中钉在鼠标附近，太大的按工作区 80% 缩小；拖动 / 缩放 / 关闭同上。

85. **识字**
    框一段中英文，按 O（或工具栏「识字」）。
    → 识别出的文字进剪贴板和历史，提示里是前 30 个字；中文词之间没有多余空格，段落按行框切开。

86. **没装识字组件**
    在没有中文 OCR 组件的系统上按 O。
    → 提示「没装中文识字组件」，并打开「语言和区域」的设置页；不崩溃。

87. **截图翻译**
    框一段文字，按 Alt+S 或工具栏「翻译」。
    → 松手后直接识别并弹翻译浮窗，原文进剪贴板历史但不覆盖剪贴板；浮窗里翻译失败时能打开设置和重试。
    空区域只提示「没有识别到文字」。

88. **热键和托盘**
    不打开截图时按 Alt+X / Alt+S / Alt+O；右键托盘图标点「截图」「截图翻译」「识字」。
    → 都进入对应的框选；托盘菜单不再是灰的；截图期间这些热键暂时失效，退出后恢复。

89. **快速模式**
    截图翻译 / 识字模式拖一个框，松手。
    → 不再等确认，直接识别 / 翻译；框小于 8 px 当误触，回到待选。

90. **DPI / 多屏**
    150% 缩放、双屏（副屏在主屏左边或上面）各截一次。
    → 遮罩正好盖住每块屏，选区、放大镜坐标、尺寸胶囊和导出的 PNG 像素都按物理像素算；
    副屏的负坐标也正确，不会把框画到另一块屏。

91. **取消**
    按 Esc（有选区先清选区，再按退出）；右键；选「✕」。
    → 都退出遮罩，恢复原来的前台窗口和全部热键；不会留下全屏透明窗口。

92. **日志**
    走一遍上面的操作。
    → 只有截图失败、保存失败这类错误；没有识别出的文字、原文、译文、URL 或选区内容。
