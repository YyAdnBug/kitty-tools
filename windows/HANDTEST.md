# HANDTEST.md

Windows 原生版的发版冒烟清单和每批手测。编号一直往下排，写「怎么做 → 应该看到什么」。
每批提交前自己先走一遍这一批的条目。

## 发版冒烟清单

（第 6 批补全；现在先按第 1 批的条目走。）

## 第 1 批：壳

环境：Windows 11 22H2 以上；至少测 100% 和 150% 缩放、浅色和深色、主屏一块。
需要时用第二块屏再走一遍多屏相关条目。

1. **首次运行**
   删掉 `%LOCALAPPDATA%\KittyTools.Dev`，从 `windows/` 构建后运行 `KittyTools.exe`。
   → 设置窗自动打开，通用页顶部有「欢迎使用 Kitty Tools」，里面有托盘溢出区的提示、
   默认快捷键、默认勾上的「登录时自动打开」和「开始使用」按钮；托盘图标已加上；
   点「开始使用」后欢迎块消失，`settings.json` 出现，`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
   里有 `KittyTools.Dev`，值是带引号的 exe 完整路径。

2. **单实例**
   应用已经在跑时再运行一次 `KittyTools.exe`。
   → 第二个进程退出（任务管理器里只剩一个），第一个实例把设置窗打开到前台。

3. **托盘菜单**
   右键托盘图标。
   → 和左键同一个菜单：剪贴板历史 / 启动器 / 输入翻译 / 截图 / 截图翻译 / 识字 ｜
   复制即译 / 暂停记录剪贴板 ｜ 设置… / 检查更新 / 退出 Kitty Tools。
   没做的模块是灰的，右边仍写快捷键；复制即译能勾 / 取消并把状态写进 `settings.json`；
   暂停记录剪贴板只在这次运行里有效，重启后恢复记录（PLAN §6.1）。
   设置…能打开设置窗，退出能退进程；左键和右键都能弹出同一个菜单。

4. **热键默认值**
   依次按 Alt+C、Alt+Space、Alt+E、Alt+T、Alt+S、Alt+X、Alt+O。
   → Alt+C 打开剪贴板面板（第 2 批接上），Alt+Space 打开启动器占位，其余弹轻提示「第 3 / 5 批接上」。
   浮层打开时再按同一个热键 → 收起并把前台还给打开前的窗口。

5. **热键占用**
   用另一个程序先注册 Alt+C（或先开一个占着 Alt+C 的 Kitty Tools 实例），再启动本应用。
   → 设置 › 快捷键里「剪贴板历史」那一行显示红色的「被占用」，托盘菜单里这一项右边
   不写 Alt+C；其它键正常。

6. **录制 / 清空 / 恢复默认**
   设置 › 快捷键，点「剪贴板历史」的「录制」，按 Ctrl+Alt+K。
   → 行里变成 Ctrl+Alt+K，状态「正常」，`settings.json` 的 modifiers=3、virtualKey=75；
   按 Ctrl+C 录制会被拒绝并说明原因；按 Esc 取消；点「清空」显示「未设置」；
   「全部恢复默认」回到 Alt+C / Alt+Space / …
   Win 组合、单独字母、Shift+字母、Alt+F4/Tab/Esc 都应被拒绝。

7. **浮层关闭**
   打开 Alt+C 后分别试 Esc、Ctrl+W、再按 Alt+C、点别的窗口。
   → 都收起；前三种把前台还给打开前的窗口，点到别处收起时不还前台（用户已经点走了）。
   浮层有系统圆角、阴影、没有标题栏条、亚克力透明、搜索框已经有焦点可以打字。

8. **轻提示**
   按 Alt+T / Alt+X。
   → 鼠标所在屏顶部居中、往下 12 px 出现深色圆角条，停约 2 s 自己消失；
   不抢焦点、不接鼠标；新的一条会替换旧的。三种语气（普通 / 警告 / 错误）颜色不同；
   管理员粘贴被拦时是警告。

9. **设置窗**
   托盘 › 设置…。
   → 普通窗口有标题栏和任务栏图标，Mica 背景，左边导航「通用 / 快捷键 / 关于」。
   通用：登录时自动打开能改并写注册表；外观改浅色 / 深色 / 跟随系统立即变；
   强调色换「跟随系统」后强调色跟着系统；自动检查更新能存；
   「打开数据目录」打开 `%LOCALAPPDATA%\KittyTools.Dev`。
   关于：版本 0.1.0、更新日志一行、检查更新暂时灰、打开数据目录可用。
   关闭设置窗不退出进程，托盘还在。

10. **深浅色 / 150%**
    外观切浅色、深色各看一遍；显示缩放切到 150% 再各看一遍。
    → 设置窗、浮层、轻提示都不被裁切；浮层位置在鼠标所在屏顶部 20%；
    文字和背景对比度正常；切换缩放后热键和托盘仍然可用。

11. **日志**
    跑一遍上面的操作，看 `%LOCALAPPDATA%\KittyTools.Dev\logs\kitty-YYYYMMDD.log`。
    → 只有事件、错误码、时间，没有剪贴板文本、原文、译文、URL、请求头、密钥；
    只保留最近 7 天的 `kitty-*.log`。

12. **数据目录分开**
    同时装 Debug 和 Release（或先跑 Debug 再跑 Release）。
    → 数据目录分别是 `KittyTools.Dev` 和 `KittyTools`，settings、日志、注册表 Run 值、
    互斥量、实例管道都分开；两个能同时跑（热键会冲突，后启动的那个标红）。

## 第 2 批：剪贴板

环境：Windows 11 22H2 以上；100% 和 150% 各一次；浅色和深色。
下面「面板」指 Alt+C 打开的剪贴板历史。

13. **采集文本**
    在记事本、浏览器正文、VS Code 里各复制一段文字，再打开面板。
    → 每条出现在最上面（按复制时间新→旧），显示预览、来源和字数；
    同样的内容再复制一次只把原条目挪到最前，不新增一条。

14. **带格式文本**
    从网页复制一段带粗体 / 链接的文字，粘到 Word 或 VS Code。
    → 默认粘贴保留格式；面板里 Shift+Enter 或右键「粘贴为纯文本」只粘纯文本。

15. **采集图片**
    截图（Win+Shift+S）或用看图软件复制一张图，打开面板。
    → 出现「图片 宽 × 高」，右边预览等比显示并标尺寸；连按同一张图不会多出重复条目；
    `images\` 里只有一张 PNG。

16. **采集文件**
    在资源管理器里复制一个文件，打开面板。
    → 出现文件名；右键「在资源管理器中显示」能选中它；粘回资源管理器会复制一份。

17. **隐私格式**
    用 KeePass 复制一条密码（或跑 `windows/build/set-private.ps1` 模拟打标记）。
    → 面板里不出现这条；日志里有 `clipboard.skip-private`，没有密码内容。
    紧接着复制普通文本 → 照常记录。

18. **排除的应用**
    设置 › 剪贴板 › 不记录的应用加一个 `notepad.exe`，从记事本复制文字。
    → 不记录；移除后又照常记录。默认列表里 KeePass / KeePassXC / 1Password / Bitwarden
    在装了的机器上同样不记录。

19. **敏感文本过滤**
    复制一行 `sk-` 开头的长串、一段 `Bearer …` 或一个能过 Luhn 的 16 位卡号。
    → 不记录；设置里关掉「不记录疑似密钥和卡号」后再复制就记录。

20. **暂停记录**
    托盘菜单勾「暂停记录剪贴板」，复制几段文字；退出并重开 Kitty Tools。
    → 暂停期间不记录；`settings.json` 里没有暂停状态，重开后恢复记录。

21. **搜索**
    面板搜索框里输入两个词（空格分开）、大写、全角字母，再搜来源名。
    → 两个词都要命中（AND）；大小写和全半角不影响；顺序仍是时间从新到旧；
    没有结果时底栏写「没有匹配的条目」。

22. **收藏和范围**
    选中一条按 Ctrl+D（或右键收藏），点「收藏」范围，再点「全部」。
    → 条目右侧出现品牌粉星标；「收藏」里只剩收藏的；再按 Ctrl+D 取消。

23. **面板按键**
    依次试 Enter、Shift+Enter、Ctrl+1–9、Ctrl+C、Ctrl+D、Delete、Ctrl+Z、Ctrl+T、Tab、Esc。
    → 前两个粘贴，Ctrl+数字粘第 N 条，Ctrl+C 只复制不关面板，Delete 删除选中（先不真删），
    Ctrl+Z 连着撤销，Ctrl+T 弹「第 3 批接上」，Tab 在全部 / 收藏间切换，
    Esc 先清空搜索词、再按关闭；焦点一直在搜索框，↑↓ 选条目。

24. **右键菜单**
    在一条上点右键。
    → 菜单是：粘贴、粘贴为纯文本、复制、收藏 / 取消收藏、（文本）翻译、
    （图片）钉到屏幕、（文件）在资源管理器中显示、删除；名字和按键一一对应。

25. **粘贴回原窗口**
    先在记事本 / Edge / VS Code / 管理员身份运行的记事本里放好光标，再 Alt+C 选一条按 Enter。
    → 面板收起，前台回到那个窗口，内容粘进去；管理员窗口只写剪贴板并提示
    「目标窗口以管理员身份运行，请手动粘贴」。

26. **粘贴前检查**
    复制一个文件后把它移走（或让图片文件被手工删掉），再选这一条粘贴。
    → 不粘、轻提示「没能粘贴」，并说明图片文件丢了 / 文件已经不在原处。

27. **保留天数**
    设置 › 剪贴板 › 保留普通历史改成 1 天；把一条普通条目的时间改早或等一天。
    → 重新打开面板（或重启）后超期的普通条目被清掉，收藏的还在；底栏条数跟着变。

28. **图片上限**
    设置 › 剪贴板 › 图片最多占用改成 128 MB，再连续复制几张大图。
    → 超了从最旧的普通图片删起，最新的一张这一轮不删，收藏的图片不占额度也不删；
    设置页「占用」里的 MB 数跟着变。

29. **清空**
    设置 › 剪贴板 ›「立即清空普通历史」点两次。
    → 普通条目清空，收藏还在；面板里只剩收藏的条目。

30. **每次收起都复位**
    搜索、切到「收藏」、选到第三条，然后 Esc 收起再 Alt+C 打开。
    → 搜索词清空、范围回到「全部」、选中回到第一条；删除的条目这时才真的从库里删掉。

31. **深浅色 / 150%**
    外观切浅色、深色各看一遍；显示缩放切到 150%。
    → 面板不裁切、不超出工作区；搜索框 56 高、字号 20；列表和预览的对比度正常；
    浮层仍在鼠标所在屏顶部 20%。

32. **日志**
    走一遍上面的操作，看 `%LOCALAPPDATA%\KittyTools.Dev\logs\kitty-YYYYMMDD.log`。
    → 只有 `clipboard.record kind=… count=…`、跳过原因和错误，没有正文、图片、文件路径或来源标题。

33. **5000 条搜索耗时**
    跑 `dotnet test windows/KittyTools.Tests` 里的 `SearchPerformanceTests`（或看提交报告里的数）。
    → 5000 条首次搜索（含折叠缓存）在 10 ms 量级，之后每次远低于 1 ms。
