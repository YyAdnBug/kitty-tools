## 2. 拍板（照 mac 2026-10-26 已拍的板，审查方替 Windows 定）

- **H1 存什么**：每条存**原图 + 标注（JSON）+ 一张小缩略图**，拷贝 / 存储 / 钉图要的成品用时再合成；录制的只记文件路径和一张封面，不复制文件。识字、翻译不产出图，不进历史。
- **H2 存哪**：`<数据目录>\shots\<id>.png`（原图）、`<id>-t.png`（缩略图，长边 480）；记录在主库的 `shots` 表（迁移第 8 步）。图不进每日备份（和剪贴板图片一样）；记录跟着库进备份，图丢了那一条照样能看信息、操作时提示「原图不在了」。不进同步。
- **H3 留多久**：30 天、总共 2 GB，超了先删最旧的；最新那一条不按总量删（`ShotHistoryRules.Stale`，纯函数配单测）。设置 › 截图「保留截图历史」（默认开）关掉后不再记、已记的留着；截图功能整个关掉时也不记。
- **H4 标注 JSON**：Windows 自己的格式（不和 mac 互通，历史不同步）：`[{"tool":"rectangle","rect":[x,y,w,h],"points":[[x,y],…],"text":"…","color":"#AARRGGBB","width":3}]`，坐标是原图里的像素。**tool 的名字、字段名进了磁盘，以后别改**。
- **H5 历史窗口**：普通的 WinUI 窗口（外壳跟 Windows：系统标题栏、Mica），默认 960 × 620、最小 720 × 420。左边按天分组的缩略图网格（卡片 168 × 112、圆角 8、组标题 12 semibold tertiary 吸顶：「今天」「昨天」「10 月 24 日」，跨年带年份），选中那张 2 px 强调色描边、没有填充；不是截图的左下角黑底白字小角标（长截图 / 录屏 / 录音 / GIF）。右边 280 宽：大预览 + 两行信息（时间 · 尺寸 · 来源；存到哪 · N 条标注 · 钉过）+ 一列操作：改标注（第 3 批前置灰）、拷贝、存储、另存为…、钉到屏幕、识字并拷贝、在资源管理器中显示、删除（危险色，删前确认一次）。顶上搜索框 + 「全部 / 截图 / 长截图 / 录制」分段。空状态用 `EmptyState`。双击一条 = 改标注（第 3 批起）；录制的双击用默认程序打开。
- **H6 入口**：新快捷动作「截图历史」（`HotKeyActions.ShotHistory`，**加在默认表最后**，默认不设键）：托盘「截图与录制」一节、启动器（搜「截图历史」）、快捷键页三处；角落缩略图卡的右键菜单多一项「在历史里看」。
- **H7 标注遮罩（第 3 批再细化）**：整屏压暗，图按可见区八成适配（最大 1:1）居中，能滚能缩；工具栏是截图工具栏的另一种形态（左段工具 ｜ 撤销重做，右段识字 ｜ 存储 ▾ ｜ 取消、拷贝），贴在图下方；长图只画看得见的那一段（Win2D `CanvasVirtualControl`，避开 16384 的纹理上限）；画过标注的 Esc 要按两下；有标注才重新合成。从历史打开的，改完回写同一条。
- **H8 速查表（第 4 批再细化）**：设置窗里一个按钮打开，按功能分组（剪贴板与启动器 / 翻译 / 截图与录制 / 设置），全局快捷键 + 各面板里的按键（剪贴板 Ctrl+K、截图里的 S / P / O…），从哪一页打开就先滚到哪一组；没设键的写「未设置」。

## 3. 分批

每批照 `AGENTS.md` 的流程（审查方写、你们验），做完在 `REVIEW.md`「v8 分工」记一句。

### 第 1 批：截图历史的存储和记录

- `Core/ShotHistoryRules.cs`：种类、`Stale`、标注 JSON 的编 / 解、按天分组的标题；单测 `ShotHistoryTests`。
- `Schema` 第 8 步 `shots` 表；`Settings.ShotHistory`（默认 true）。
- `Screenshot/ShotHistory.cs`：记一条（写原图、缩略图在后台线程）、读、改（存到哪、钉过、标注）、删、清理；`Changed` 事件。
- 记录的地方：截图的拷贝 / 存储 / 另存为 / 钉图（原图 + 标注）、截取上次区域、长截图、录屏 / 录音 / GIF / 压缩版（文件 + 封面）。
- 设置 › 截图「保留截图历史」开关。
- **验收**：单测；截几张图、录一段、转一次 GIF，`<数据目录>\shots\` 里有原图和缩略图，`shots` 表里对应几行，标注 JSON 对得上；关掉开关后不再记。

### 第 2 批：截图历史窗口和入口

- `Screenshot/ShotHistoryWindow.cs`（H5）；入口（H6）。
- **验收**：浅 / 深 / 高对比度截图（`--ui-snapshots` 加 `shot-history`、`shot-history-empty`）；每个操作走一遍；200 条历史时滚动不卡、窗口关掉后缩略图放掉（内存探针加一步）。

### 第 3 批：标注遮罩

- 长截图拼完按 A；历史里双击改标注回写。
- **验收**：30000 像素高的长图能滚、能画、能导出；从历史打开改完，再打开看到改过的标注。

### 第 4 批：速查表

- **验收**：每个分组都有、和快捷键页一致；改了快捷键再打开速查表跟着变。
