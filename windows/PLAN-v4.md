## 1. 定下来的

| # | 问题 | 定下来的做法 |
|---|---|---|
| V1 | 画面怎么取 | **Windows.Graphics.Capture**：按显示器取，区域靠裁剪；`IsBorderRequired = false`（不要黄框），`IsCursorCaptureEnabled` 跟设置走 |
| V2 | 怎么编码 | **Media Foundation 的 SinkWriter**，H.264，优先硬件编码（`MF_READWRITE_ENABLE_HARDWARE_TRANSFORMS`）；画面从 GPU 纹理直接喂给编码器（DXGI 设备管理器 + `MFCreateDXGISurfaceBuffer`），不拷回 CPU |
| V3 | 文件格式 | **分片 MP4**（`MFTranscodeContainerType_FMPEG4`）：程序崩了、断电了，已经录的部分也能播。第 1 批先验证 Windows 媒体播放器、电影和电视、Edge、Chrome 都能放；放不了就退回普通 MP4，接受「崩了这次就丢」，报告里写明 |
| V4 | 声音 | 系统声音用 WASAPI 回环录默认输出设备，麦克风用 WASAPI 录默认输入设备；两路都打开时混成一条 AAC 音轨（48 kHz 立体声，160 kbps） |
| V5 | 默认值 | 帧率 30（可选 60）；清晰度「原始」（屏幕像素，可选「标准」= 按每 DIP 1 像素）；倒数 3 秒（可选 0 / 5）；录光标；系统声音开、麦克风关；显示点按、显示按键都关 |
| V6 | 存到哪 | 先写到保存目录所在的卷上的隐藏临时文件，录完改名放进保存目录。保存目录默认「视频」文件夹下的 `Screen Recordings`（和系统截图工具录屏存的地方一样，中文系统显示成「屏幕录制」；拿不准就先确认截图工具的默认目录再定）。文件名 `录屏 2026-10-24 13.05.12.mp4`、`录音 2026-10-24 13.05.12.m4a` |
| V7 | 热键 | 录屏 **Alt+R**（同 mac 的 ⌥R），录音不设默认键；录制中再按同一个热键 = 停止 |
| V8 | 停止的地方 | Windows 没有菜单栏：录制中托盘菜单最上面多一项「■ 停止录屏 0:12」，托盘图标换成右下角带红点的 `KittyTools/Resources/AppIconRecording.ico`（已经在 Mac 上生成好，`windows/tools/app-icon.swift`） |
| V9 | 录音的入口 | 同 mac 手测反馈第 3 批：按录音热键先出「待录」控制条（两个来源开关 + ✕ + ●），点 ● 才开始；设置 › 录制「按快捷键后立即开始录音」打开时直接开始 |
| V10 | 录制中的自家窗口 | 录制条、HUD、选区边框、倒数都用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，不进画面；点按圈、按键胶囊**要**进画面（不设）；剪贴板面板、翻译浮窗、钉图、设置窗照常录进去（同 mac R4-a） |

## 2. 第 1 批：录屏的底座（没有界面，先用命令行开关驱动）

- **画面**：
  - `GraphicsCaptureItem` 按显示器建（`IGraphicsCaptureItemInterop.CreateForMonitor`）；
  - `Direct3D11CaptureFramePool.CreateFreeThreaded`，帧格式 BGRA8；
  - 区域录制：每帧 `CopySubresourceRegion` 裁到选区（宽高向下取偶数，H.264 要求）大小的纹理再交给编码器。
- **帧率**：按固定帧率写（30 或 60）。没有新帧时重复上一帧，来得太快的丢掉；时间戳用帧的 `SystemRelativeTime`，减掉开录那一刻。
- **声音**：
  - WASAPI 回环和麦克风各一个线程，用事件驱动（`AUDCLNT_STREAMFLAGS_EVENTCALLBACK`）；
  - 时间戳用 `GetBuffer` 给的 QPC 位置，和画面在同一个时钟上；
  - 两路重采样到 48 kHz 浮点后相加、限幅，送 AAC 编码；
  - 回环设备没有声音时也要持续给静音样本，不然音轨会断。
- **COM 和 AOT**：Media Foundation、D3D11、DXGI、WASAPI 的接口用 CsWin32 生成（`allowMarshaling=false`，裸指针调用）；WGC 是 WinRT，走 CsWinRT；从 `IDirect3DSurface` 取 `ID3D11Texture2D` 用 `IDirect3DDxgiInterfaceAccess`。CsWin32 生成不了的接口，按 `AGENTS.md` 红线里写的办法处理。
- **收尾**：停止 → 冲掉编码器里剩下的帧 → `Finalize` → 改名进保存目录。下面几种情况和用户停止走同一条收尾、保存已经录的部分，原因写进结果提示：
  - 锁屏（`WM_WTSSESSION_CHANGE`）、系统睡眠（`WM_POWERBROADCAST`）；
  - 被录的显示器拔掉了（`WM_DISPLAYCHANGE` 之后它不在了）；
  - 磁盘剩余不到 1 GB；
  - 捕获会话自己结束（`GraphicsCaptureItem.Closed`）。
- **录制中不让系统闲置睡眠**：`SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED)`，停了恢复。
- **闪退恢复**：开录时把临时文件路径记进设置。下次启动看到它还在，就把它挪进保存目录（分片 MP4 可以直接播），轻提示「上次的录屏已保存」。
- **自检开关** `--record-probe <目录>`（同 mac 的 `RecordingProbeTests`）：
  - 自己开一块会动的彩色窗口和一个周期性的提示音，录 5 秒；
  - 报告写进 `<目录>\report.md`：时长、帧数、平均帧间隔、有没有声音轨、声音峰值、文件能不能被 `MFCreateSourceReaderFromURL` 读完。
- **验收**：
  - 自检报告：30 fps 录 5 秒，帧数 145–155，有声音；
  - 音画同步：自检窗口闪白的那一帧和提示音的起点，相差不到 50 ms；
  - 1080p30 硬件编码时进程 CPU < 15%，录 5 分钟内存不持续上涨；
  - 录的时候用任务管理器结束进程，下次启动能找回文件、能播放。

## 3. 第 2 批：录屏的界面

- **入口**：
  - Alt+R，或托盘「录屏」：进截图遮罩的「录屏模式」；
  - 截图框选时按 R 也能切过去（同 mac）；已经画了标注的不切。
- **选择**：拖一块区域；单击一个窗口（按冻结时的窗口边界）；按 F 或点「整屏」录鼠标所在的那块屏。
- **录制条**（选区下方，样子照 mac-whisker-capture）：`[系统声音][麦克风][显示点按][显示按键] ｜ [● 开始]`。开关记住上一次；录制中改不了。
- **倒数**（V5 默认 3 秒）：
  - 遮罩收起，选区外一圈蚂蚁线边框，HUD 显示「3 秒后开始」；点数字马上开始；
  - **Esc 取消**：倒数期间临时注册一个不带修饰键的 Esc 全局热键（同 mac §4「录屏倒数的临时 Esc」），倒数一结束（开始 / 取消）就立刻注销——挂着的时候别的程序都收不到 Esc，所以只挂那几秒；
  - 本 App 自己的窗口在前台时，这一下 Esc 交给那个窗口，不取消倒数。
- **录制中**：
  - 选区外一圈静止的强调色边框（整屏录制不画）；
  - HUD 停在录制条原来的位置：`[● 0:12][声音状态] ｜ [✕ 放弃][■ 停止]`。红点呼吸（只在录制态挂这一个循环动画）；计时每秒跳一次，只换数字，不做逐帧动画；放弃要点两下（第一下变红「再点一次放弃」，2 秒内再点才放弃）；
  - HUD 可以拖动，位置按屏记在内存里；
  - 托盘照 V8 变样、多出停止项。
- **麦克风授权**：系统「隐私和安全性 › 麦克风 › 允许桌面应用访问麦克风」关着时，打开麦克风会失败（`E_ACCESSDENIED`）。这时照样开录、不带麦克风，警告提示「没有麦克风权限 · 这段录屏不带麦克风」，开关弹回关；**录完之后**才打开 `ms-settings:privacy-microphone`（开录前打开会盖住选区、录进画面）。
- **录完**：沿用第二版 §3.8（D5）的飞入和角落缩略图卡片，卡片换成视频那一种：
  - 第一帧当封面，标时长；
  - 按钮：播放（默认播放器）、复制（`CF_HDROP` 文件）、在资源管理器中显示、转成 GIF、压缩、删除（进回收站）；
  - 复制会记一条文件条目进剪贴板历史。
- **设置 › 录制**：录屏（帧率、清晰度、倒数、录光标、保存目录）。功能开关（第三版第 1 批）加「录制」一项。
- **验收**：
  - 三种选择方式各录一次；
  - HUD、边框不在视频里，点按圈在视频里（第 3 批做完后再验一次）；
  - 倒数时 Esc 取消，之后别的程序照常收得到 Esc；
  - 麦克风权限关着时照样能录；
  - 锁屏时自动停止并保存。

## 4. 第 3 批：点按圈、按键胶囊、转 GIF、压缩

- **点按圈**（mac §10「点按圈」、mac-whisker-capture「点按圈」）：
  - 录制中装 `WH_MOUSE_LL`，按下、松开时在一块盖在被录区域上的透明窗口里画圈（按下时缩小、松开时扩散淡出，左右键颜色不同）；
  - 窗口：`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`，点得穿、不抢焦点，**不设** `WDA_EXCLUDEFROMCAPTURE`，所以会录进画面；
  - 画圈用 Composition，不逐帧重画整块窗口；钩子回调里只记坐标，画交给 UI 线程。
- **按键胶囊**（mac §10「按键提示」）：
  - 录制中装 `WH_KEYBOARD_LL`，只看按下。组合键显示成 `Ctrl + Shift + S`，单个字母不显示（「只显示快捷键」，同 mac 的默认）；画在被录区域底部居中的胶囊里，1.5 秒后淡出；
  - 本 App 自己发的合成按键（粘贴的 Ctrl+V、片段的 ←、取词的 Ctrl+C）不显示：看 `LLKHF_INJECTED`，并且对照本进程最近一次发合成按键的时刻；
  - 本 App 自己的密码框（设置里的 API Key 框）拿着焦点时不显示。**界面上不承诺「别的程序的密码不会显示」**（同 mac）。
- **转成 GIF**（mac `VideoExport.gif`）：
  - `MFCreateSourceReaderFromURL` 按 10 fps 取帧，长边缩到 800；
  - 每帧单独量化调色板，WIC 的 GIF 编码器（`GUID_ContainerFormatGif`）**一帧一帧**写，不把所有帧攒在内存里；
  - 存成「<原名>.gif」，在卡片上显示进度；卡片关掉就取消，删掉半成品。
- **压缩**（mac `VideoExport.compress` 和它的 `compressedLimit` 公式）：
  - 用 SinkWriter 重新编码成 H.264，目标码率 = 视频 48 × 像素数^0.75 bps + 原音频码率，且总大小不超过原文件的 60%；分辨率、帧率、音轨不变；
  - 存成「<原名> 压缩版.mp4」；取消或失败时删掉半成品。
- **验收**：
  - 点按圈和按键胶囊都录进了视频，自己的合成按键不出现；
  - 一段 10 秒、1080p 的录屏转 GIF：峰值内存增量 < 100 MB，结果能在浏览器里播放；
  - 压缩后的体积不超过原来的 60%，能播放。

## 5. 第 4 批：录音和第四版收尾

- **录音会话**（mac `AudioRecorder.swift`）：
  - 来源：麦克风 / 系统声音 / 两者（设置 › 录制「录音」，待录控制条上也能切）；
  - 输出 m4a（MPEG-4 容器，AAC 48 kHz，单声道 128 kbps；有系统声音时立体声）；
  - **三种来源都能暂停 / 继续**：暂停期间不写样本，之后的时间戳减掉暂停的时长；计时不算暂停的时间。
- **录音控制条**（样子照 mac-whisker-capture「录音」，鼠标所在屏工作区底部居中、离底 24）：
  - 待录：`[系统声音][麦克风] ｜ [✕ 关闭][● 开始]`；
  - 录制中：`[● 0:42][电平] ｜ [⏸] ｜ [✕][■]`。电平是最近 3 秒的竖条，每 50 ms 一根，超过 −1 dB 的那根标橙；
  - 开头 5 秒一直低于 −70 dB 时，计时旁边出橙字「没听到声音」（只看麦克风那一路）；
  - 两者模式里麦克风中途断开，照录系统声音，那个位置换成橙字「麦克风断开了」。
- **中断**：
  - 只录麦克风时：锁屏照录；系统睡眠、输入设备断开、磁盘剩余不到 1 GB 时停止并保存；
  - 录系统声音（或两者）时：锁屏、睡眠也停止并保存；
  - 录制中防系统闲置睡眠（不防显示器睡眠）。
- **录完**：用电平包络画波形当封面，从控制条的位置飞到右下角，变成录音卡片（播放、复制、在资源管理器中显示、删除）。
- **第四版收尾**：
  - 版本号改 0.4.0，更新日志加 0.4.0 的条目，跑 `build-release.ps1` 准备好 zip 和 `.sha256`（不发布）；
  - `HANDTEST.md` 的发版冒烟清单加上录屏、录音几步。
- **验收**：
  - 三种来源各录一次，能播放、有声音；
  - 暂停后继续，文件里没有空白的那一段，时长等于实际录的时长；
  - 「没听到声音」的提示（拔掉或静音麦克风时）；
  - 录音期间空闲 CPU < 3%。
