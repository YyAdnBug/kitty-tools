# Kitty Tools Windows 版：第十六版方案（跟上 mac 0.7.1 之后的新东西，Windows 自己实现）

2026-11-07。用户：「windows 还需要实现的功能给我，我让 windows agent 实现」。

**这一版由 Windows 的 agent 自己写、自己编译、自己验**（不再是审查方在 Mac 上写）。不是拍板页：行为、默认值、文案照 mac
（`AGENTS.md`「跟 mac 走」），只有 Windows 自己要定的写在各项「Windows」那一列和 §3，带推荐答案，**照推荐做**；用户不同意再改。
每批照 `AGENTS.md`「每一批的流程」和自查清单走（编译零警告、单测、AOT 两个架构、内存、空闲 CPU、截图、手测、报告），
交接和结果写在 `REVIEW.md`「PLAN-v16」，手测接着 `HANDTEST.md` 从 **1156** 往下编。

**mac 的源码怎么看**：大部分在 `origin/macos` 上，`git show origin/macos:macos/KittyTools/<路径>`、`git show <提交号>` 都看得到；
标了「（mac 只在本地）」的那几个提交没推，照本文的描述做。

**开始之前**：先把 `REVIEW.md`「PLAN-v15」（截图拷贝为文件）核验完——上一轮给的指令。
