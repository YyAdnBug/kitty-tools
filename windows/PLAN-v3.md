# Kitty Tools Windows 版：第三版及以后的路线

2026-10-24 写。内容是 `PLAN-v2.md` §7「第三版候选」整理出来的路线图，外加第三版每一批的细则。

- **第二版全部审完之后再开始**（第二版是 0.2.0；按 PLAN-v2 的 D9，0.1.0 在第二版第 2 批之后就发了）。
- 本文只写新功能；工作方式、视觉规矩（PLAN-v2 §3 的主题资源、`Motion`、无障碍）、AOT 和依赖的红线照旧。
- 每个新功能的**行为**以 mac 版为准：下面每项都点了 mac 的规则章节和源码，只当行为规格读，实现照 Windows 的做法。和本文冲突时以本文为准。
- §1 的 E1–E10 等用户拍板。用户没改的项按推荐做。

## 2. 第 1 批：数据安全、导出导入、功能开关

第三版开始存用户自己留下的东西（片段、收藏夹、生词本），所以先把备份和恢复做好。

### 2.1 每日备份和打不开时的恢复

- 行为照 mac-clipboard §1「每日备份、打不开时的恢复」；代码看 `macos/KittyTools/Storage/Backup.swift`，单测看 `BackupTests.swift`。
- **只备用户明确留下的**：收藏、片段、收藏夹、生词本、启动器收藏。普通剪贴板历史、没收藏的翻译历史、启动器使用记录不进备份。
  以后加新表、新列时，先想清楚它算不算「留下的」，不算就加进删行的清单。
- **备份的顺序不能换**：
  1. `PRAGMA quick_check` 是 ok；
  2. `VACUUM INTO` 写出半成品；
  3. 在半成品上删掉不留的行；
  4. 再 `VACUUM` 一遍（只删行的话，内容还留在文件的空闲页里）；
  5. 检查一遍是不是好的；
  6. 改成正式名字 `backups\kitty-YYYY-MM-DD.sqlite3`；
  7. 最后才删超出 3 份的旧备份。

  任何一步失败，已有的备份一个字节都不动，半成品删掉。
- **线程**：另开一个只读连接，在后台线程上做；主连接照旧只在 UI 线程上用。
- **时机**：启动时、锁屏时（`WTSRegisterSessionNotification` → `WM_WTSSESSION_CHANGE`）、从睡眠唤醒时（`WM_POWERBROADCAST`）各看一眼今天备过没有，不另加定时器。
- **打不开时**：开库、建表、迁移、读表任何一步出错，或者库文件不见了而备份还在，就弹框让用户选：
  - 用最近一份备份（按钮上写日期）；
  - 重新开始；
  - 退出。

  出问题的库**连同 `-wal`、`-shm`** 一起挪进 `damaged-<时间>\`，一律不删（mac 实测过：`-wal` 留在原地会被重放到恢复出来的库上）。
- 图片不备份，同 mac。

### 2.2 设置与数据的导出和导入（E2）

- 行为和格式照 mac-native §2「设置的导出与导入」，代码看 `macos/KittyTools/Storage/SettingsArchive.swift`（format 2，文件头注释写了每一类），单测看 `SettingsArchiveTests.swift`。
- 设置 › 通用「导出与导入」：按类别勾选，导出成一个 JSON。
  - **密钥默认不带**；要带就设密码，用 PBKDF2-HMAC-SHA256 派生出密钥，再 AES-256-GCM 加密（.NET 自带 `Rfc2898DeriveBytes` 和 `AesGcm`，AOT 能用）。
  - 参数、以及密钥和服务地址绑在一起校验的做法，都要和 mac 一字不差，两边的文件才能互相解开。
- **和 Mac 互通**：
  - Windows 导出的文件多写一个 `"platform": "windows"`；
  - 导入时，没有这个字段（Mac 导出的）或值不是 windows 的，跳过「设置」「快捷键」两类，其余照导；
  - 片段、收藏、生词本是合并进来（同样的正文不重复，只补标记），不删本机已有的。
- **自动备份导出文件**：照 mac 的 `Storage/SettingsBackup.swift`，每天存一份 `Kitty Tools 自动备份 日期.json`（留 7 份），导入前另存一份（留 3 份）。
- 读文件当成不可信输入：不认识的、类型不对的、超出范围的项一律丢掉，条数有上限（同 mac：收藏夹 200、条目 5000）。

### 2.3 功能开关（E10）

- 行为照 mac `macos/PLAN.md` §10「功能开关」和 `Shell/Feature.swift`。
- 设置 › 通用 › 功能：剪贴板、翻译、启动器、截图（第四版加录屏录音）各一个开关。关掉一样就：
  - 注销它的热键；
  - 托盘里不再显示它的菜单项；
  - 停掉它的后台工作（比如剪贴板监听）；
  - 设置里它那一页变灰并写明「已关闭」。

### 2.4 验收

- 备份：造一个坏库（连 `-wal` 一起删），确认弹框和三个选项都对，`damaged-` 里的文件齐全。
- 导入导出：用 mac 版真导出的文件（用户提供，或者用 mac 的单测样本）导进 Windows，片段、收藏、生词本都对；带密钥的文件用对的密码能解开，地址被改过的文件解不开。
- 功能开关：关掉以后热键不响、托盘里没有它；再打开一切照常。

## 3. 第 2 批：翻译补齐

### 3.1 历史和收藏（生词本）

- 行为照 mac-translate §5.1、§5.3，代码看 `Translate/HistoryStore.swift`、`HistoryView.swift`。
- **存储**：表 `translations`（原文、源语言、目标语言、译文、服务、时间、是否收藏）；「原文 + 实际目标语言」唯一。
  - **只有第一个服务**的完成结果写历史（同自动复制）；
  - 保留条数 1000 / 5000 / 不限（默认 5000），收藏的不算、永不淘汰。
- **界面**：浮窗里 Ctrl+H 打开 / 关上历史（E3），原文区不动，结果区换成历史列表。
  - 列表：搜索、按天分组，「全部 / 收藏」两个范围（Shift+Tab 切换）；
  - 按键：Enter 重新翻译这条、Delete 删除（Ctrl+Z 撤销）、Ctrl+C 复制译文、Ctrl+Shift+C 复制原文、Ctrl+D 收藏、Esc 回到浮窗；
  - 右键菜单和这些按键一一对应。
- **导出**：全部 / 只收藏 × CSV / Anki TSV（`FileSavePicker`）。**清空历史**要确认，收藏的保留。设置 › 翻译里有历史开关、保留条数、导出、清空。
- 浮窗顶栏和卡片上的收藏按钮 = Ctrl+D。

### 3.2 替换原文、划词翻译并替换

- 行为照 mac-translate §5.1「替换原文 / 静默替换」那两条。
- **替换原文**：浮窗里的按钮。依次：收起浮窗 → 写入译文 → 粘回原窗口（走 `Paster`）。
  - 粘之前核对前台还是**取词时记下的那个进程**，对不上就只复制；
  - 译文补回原选区首尾的空白。
- **划词翻译并替换**（新热键，不设默认键）：不开浮窗，取词后只用第一个服务翻译，结果直接替换原文，进度走轻提示。翻译中再按一次热键 = 取消。
- 单词模式的结果是释义、不是译文，所以不给「替换原文」。

### 3.3 朗读

- 原文框和每张卡片上一个朗读按钮。用 `Windows.Media.SpeechSynthesis.SpeechSynthesizer` 合成，`MediaPlayer` 播放。
- 声音：按语言挑系统里装了的；同一语言有多个时，优先名字里带 Natural / Neural 的。
- 浮窗收起时停止；朗读中按钮显示「停止」。

### 3.4 查词（单词模式）

- 行为照 mac-translate §5.2「大模型单词模式」，判断规则看 `Translate/WordLookup.swift` 的 `isWord`（字母文字 1–3 个词、≤ 40 字；中日文 1–4 个字）。
- 原文是「一个词」时，智谱和 AI 服务改用单词模式的提示词：**给一个完整示例让模型照着写**，不写格式说明（mac 实测：免费的 glm-4-flash 会把格式说明原样抄出来）。
- 单词模式的结果不自动复制、不给替换原文。Windows 没有 mac 那样的系统词典接口，**不做系统词典卡**。设置 › 翻译 › 查词有开关，默认开。

### 3.5 百度、有道、火山、腾讯

- 行为照 mac-translate §3「传统接口」「签名」「错误」几条，代码看 `Translate/Providers/RESTProviders.swift`、`CloudProviders.swift`、`Signing.swift`。
- 四种签名（百度 MD5、有道 v3、火山 HMAC-SHA256、腾讯 TC3）写成 Core 里的纯函数，时间由参数传入。**单测期望值原样搬 mac 的 `ProviderSigningTests.swift`**。
- 都不是流式接口，结果包成一次给完的流；译文按纯文本显示。百度 6000 字、有道 5000 字上限。
- 错误码逐个译成中文（mac 的 `Baidu.error(code:)` / `Youdao.error(code:)`），按「设置问题 / 服务问题」分卡片颜色。
- 凭据字段名和 mac 一样（`baidu.appId`、`baidu.secret`、`youdao.appKey`、`youdao.appSecret`、`volcengine.accessKey`、`volcengine.secretKey`、`tencent.secretId`、`tencent.secretKey`），这样导入导出才对得上。

### 3.6 验收

- 历史：写入、搜索、收藏、删除和撤销、导出两种格式、清空保留收藏、保留条数的淘汰（单测）。
- 替换：记事本、Edge 的输入框、Word（有的话）里替换成功；切到别的程序再点「替换原文」只复制；管理员窗口只复制。
- 四家服务：签名单测全过；有 key 的话每家联网冒烟一次（环境变量开关，默认不跑）。

## 4. 第 3 批：剪贴板（一）片段、收藏夹、备注、固定、操作面板

- **库**：表 `clips` 加 `snippet`、`note`、`group_id` 三列，新表 `clip_groups`（名字、顺序、建于）。按第二版的逐版本迁移加，配迁移单测。
  不变式：有 `group_id` 的条目一定是收藏（mac-clipboard §1「收藏夹」）。
- **片段**（mac-clipboard §4「片段」「编辑 / 新建片段」「片段占位符」，代码看 `Clipboard/Snippet.swift`）：
  - 「存为片段 / 移出片段」；Ctrl+N 新建片段（可选的名称存成备注，再加正文），Ctrl+E 编辑。
  - 占位符：`{date}` `{time}` `{datetime}` `{weekday}` `{uuid}` `{clipboard}` / `{clipboard:N}` `{cursor}`，展开写成纯函数，单测照搬 mac（固定当前时间和时区）。
  - `{cursor}`：粘贴后按「光标之后的字符数」发那么多次 ←（同一套 `SendInput`）；超过 500 字、多条合并粘贴时不挪。
- **收藏夹**（mac-clipboard §1、§4「管理收藏夹」）：
  - 收藏就是默认收藏夹；可以建命名收藏夹，名字去掉首尾空白、不重名、最多 24 字；
  - 「移到收藏夹 ›」子菜单；
  - 管理对话框：改名、拖动或用键盘排序、删除（只解除归属，条目留在默认收藏里，能 Ctrl+Z 撤销）。
- **备注**：每一条都能写，显示在行的右侧，能被搜到；取消收藏不清备注。
- **范围**：全部 / 收藏 / 片段三枚胶囊（Shift+Tab 循环）；选「收藏」时旁边出一个收藏夹下拉。
- **留下的条目**（收藏或片段）不受保留天数和图片上限影响；第 1 批的备份带上它们。
- **固定面板**（Ctrl+P 或底栏图钉）：固定后点到别处不收起，Esc 照样收。
  固定着的时候用 `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 记住「最近一个不是本 App 的前台窗口」，粘贴就粘进它（mac-overlay-panel §5：用户点进别的程序再回来粘贴，要粘进那个程序）。
- **操作面板**（Ctrl+K）：在选中行旁边弹出这一条的全部操作，和右键菜单是同一份（名字、顺序、出现条件都一样），可以打字过滤。
- **验收**：
  - 占位符和片段展开的单测（含 `{cursor}` 的字符数）；
  - 收藏夹的不变式单测；
  - 迁移单测；
  - 固定面板时在别的程序里点一下再回来粘贴，粘对地方。

## 5. 第 4 批：剪贴板（二）多选、拖出、链接预览、识字后可搜

- **多选**（mac-clipboard §4 表里的单击 / Ctrl 单击 / Shift 单击，和「操作对象」那条）：
  - Ctrl+单击切换勾选，Shift+单击整段选，Shift+↑↓ 扩展；
  - 粘贴按复制先后：全是文本就「合并粘贴」（用换行连成一条，并记一条新历史）；全是文件就「一起粘贴」；其余「依次粘贴」，每条间隔 250 ms；
  - 底栏写「已选 N 条」和这次的动词；收藏、删除、移到收藏夹都能批量做。
- **拖出**（mac-clipboard §4「拖到别的 App」）：从行上拖到别的程序，用 WinUI 的 `DragStarting` + `DataPackage`。
  - 文本带格式；图片给一个临时 PNG 文件（`SetStorageItems`）；文件给原文件；
  - 拖的是勾选项之一时就拖全部勾选项；
  - 拖出去不算粘贴：不挪到最前、不记新历史。
- **链接预览**（E5，mac-clipboard §5「链接预览」，代码看 `Clipboard/LinkPreview.swift`）：
  - 选中「只有一个网址」的文本条目，停留 0.25 s 后取网页标题、描述、头图、网站图标，显示在预览卡里；
  - 拦截规则照 mac：本机 / 内网 / 私有地址 / IPv6 字面量 / 带账号密码的不访问；像一次性令牌的链接不访问；
  - 请求：不收发 Cookie、不缓存；网页读到 `</head` 或 512 KB 就停，图片超过 4 MB 放弃；
  - 内存：头图缩到长边 1200，最多记 12 条，空闲回收时丢掉解码好的图、留着下载来的字节；
  - 设置里能关，关掉时连缓存也不显示。
- **识字后可搜**（E4，mac-clipboard §1「后台识字」、§3）：
  - 图片条目空闲时在后台**排队一张一张**识字，结果存进 `ocr_text` 列；搜索时也搜它，靠它命中时行标题显示命中的那一段；
  - 右键或 Ctrl+K 里加「复制图中文字」；
  - 空闲回收时放掉识字引擎；量常驻多占多少写进报告（超过 20 MB 按 E4 改子进程）。
- **验收**：
  - 三种粘贴方式在记事本里各试一次；
  - 拖到资源管理器（图片成文件）、拖到 Word / 写字板（带格式）；
  - 链接预览的拦截规则单测（照搬 mac 的 `LinkPreviewTests` 里不联网的那部分）；
  - 识字后可搜的耗时和内存。

## 6. 第 5 批：启动器补齐

- **收藏**：
  - Ctrl+D 收藏 / 取消；空查询时先列收藏（按加入顺序，Ctrl+Alt+↑↓ 调顺序），再用「常用」补满 8 行；
  - 表 `launcher_favorites`；备份带上它。
- **文件搜索**（E6，mac 的 `Launcher/FileSearch.swift` 文件头）：
  - 触发：空格开头、或者 `open 词` / `find 词`；结果异步到，先留着上一次的结果；
  - 先做样机比 E6 的两种查法，把延迟写进报告，再定；
  - 范围：桌面、文档、下载、图片、视频、音乐、OneDrive；查询为空时列「最近的文件」（`%APPDATA%\Microsoft\Windows\Recent` 里的快捷方式）；
  - 按键：Enter 打开、Ctrl+Enter 在资源管理器里显示（`explorer /select,`）、Ctrl+C 复制路径；
  - 图标用 `IShellItemImageFactory`。
- **浏览器书签和历史**（E7，mac 的 `Bookmarks.swift`、`BrowserHistory.swift`、`Browsers.swift`）：
  - Chromium 系（Chrome、Edge、Brave、Vivaldi，含多个配置）：书签读 `Bookmarks` JSON；历史读 `History`（SQLite，浏览器开着时被锁住，先拷到临时目录再只读打开）；
  - Firefox：读 `places.sqlite`；
  - 设置 › 启动器里每个浏览器一个「也搜浏览历史」，默认关；历史排在书签后面、不和书签重复，最多 5 行。
- **进程和端口**（E8，mac 的 `Processes.swift`、`SystemCommands.swift` 里 kill / port 那部分）：
  - `kill 词`：列进程（名字、PID、内存）；
  - `port 词`：列在监听的 TCP / UDP 端口（`GetExtendedTcpTable` / `GetExtendedUdpTable`，IPv4 和 IPv6）和占用它的进程；
  - 结束进程照 E8；以管理员身份运行的、系统的进程结束不了时说明原因；
  - 列表在后台取，再呼出时重新取。
- **验收**：收藏的顺序和备份；文件搜索的延迟；书签和历史在 Chrome、Edge、Firefox（有的话）上都能搜到；端口列表和 `netstat -ano` 对得上；结束进程的两种方式。

## 7. 第 6 批：截图补齐

- **截取上次区域**（E9）：记住上一次截图的那块屏和选区（物理像素，只在内存里，同 mac 不进导出文件）。按热键直接冻结那块屏、裁出那块区域，按截图的输出方式处理（复制 + 飞入）。显示器布局变了、区域不在屏上了，就轻提示并改成普通截图。
- **长截图**：行为照 mac-overlay-panel §10，拼接算法照 `Screenshot/ScrollStitcher.swift`（文件头写了做法：逐行哈希投票、模糊匹配兜底、两个方向都能拼、吸顶栏和页脚的处理），单测照搬 `ScrollStitcherTests.swift`。
  - 入口：截图框选时按 S，遮罩收起，在**实时画面**上截。
  - 选区边框和长截图的小控制条都设 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，不会被截进去。
  - 滚动：用户自己滚；或者点「自动滚动」，往选区中心发滚轮（`SendInput` 的 `MOUSEEVENTF_WHEEL`）。
  - 每隔一会儿截一帧选区交给拼接；Enter 或「完成」结束，Esc 放弃；高度到上限（30000 px）自动结束。
  - 结果走截图的输出（复制、保存、钉图、飞入）。
- **验收**：
  - 拼接单测；
  - 在 Edge 网页、资源管理器的长列表、VS Code 的长文件上各截一次，往下拼、往上拼都试，看有没有接错或重复的行；
  - 截图期间的内存峰值。

## 8. 第四版：录屏和录音（要点，开始前另写 PLAN-v4）

- **录屏**：
  - 入口：截图框选时按 R（同 mac），可以选区域、窗口或整屏，倒数 3 s；
  - 画面用 Windows.Graphics.Capture（按显示器或按窗口，区域靠裁剪；`IsBorderRequired = false`），编码用 Media Foundation 的 SinkWriter（H.264，优先硬件编码），出 MP4；
  - 声音：系统声音用 WASAPI 回环，麦克风用 WASAPI；
  - 录制条和点按圈都用 `WDA_EXCLUDEFROMCAPTURE`，不进画面；
  - 可选：显示点按、显示按键；结束后可以转 GIF、压缩；
  - 麦克风受系统「隐私和安全性 › 麦克风 › 允许桌面应用访问」管着，被拒时照样开录、不带麦克风，并说明原因。
- **录音**：麦克风或系统声音，出 m4a（AAC），录音控制条上有电平。
- 行为参照 mac 的 `Screenshot/ScreenRecorder.swift`、`AudioRecorder.swift` 文件头、mac-overlay-panel §8 和录屏相关的条目、mac-whisker-capture。
