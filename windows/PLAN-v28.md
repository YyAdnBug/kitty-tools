## 1. 逐页：每一行放哪

「外 / 子:<名> / 高」= 页面上 / 推进去的那个子页 / 「高级」。mac 那一栏是 `SettingsIndex.swift` 里的位置；Windows 独有的行按 mac 规格 §1.1 的规矩放：
功能开关、天天碰的、要授权的、管数据的（清空、导出导入）放外面；同一主题 4 项以上或本身是一组状态的推进子页；零散的、一年改一次的进「高级」；
**会删数据的上限、功能开关、危险操作不进「高级」**。页面先后：功能开关 → 常用的组 → 推进行的组 → 按键行 → 「高级」。

## 5. 替用户定的

1. 「权限」不单独成子页：Windows 只有麦克风一行（§1.1）。
2. Windows 独有的行的去处：提示显示在、显示点按、显示按键 → 高级；系统声音、麦克风（录屏带不带声音）→ 外面；从这台电脑移除 → 外面最后；Windows 10 黄框 → ⓘ。
3. 「应用」推进行的标题不改成「应用别名」：Windows 那一页还管便携软件的文件夹和隐藏的应用（R115 之后），叫「应用」更准；行尾写「n 个别名」。
