## 1. 现在能做什么

- **剪贴板历史**：文本 / 图片 / 文件、收藏、收藏夹、备注、搜索（含识字出来的字）、去重、保留期、图片额度、隐私格式、排除的程序；
  列表里直接显示图片（行高可调）；多选（合并 / 一起 / 依次粘贴）、拖出、链接预览、固定面板、Ctrl+K、空格预览。
  **片段**：占位符（`{cursor}` `{clipboard}` `{date+3d:格式}` `{input:名字}` 当场填空），**打关键词就展开**（Raw Input 只听不拦，密码框、提权窗口、中文输入法中文模式不展开）。
- **翻译**：八个服务、30 种语言、流式、划词 / 输入 / 复制即译 / 截图翻译、自动复制、固定浮窗；长文按服务的上限分段翻完；外文句子能讲解、服务能加附加要求；
  折叠的服务点开才翻；历史与生词本、查词、替换原文、朗读（四档快慢）。
- **启动器**：应用 / 设置页 / 系统命令 / 计算 / 汇率 / 网址直达 / 网页搜索 / 书签和历史 / 脚本命令 / 提醒和保持唤醒的一句话；
  文件搜索（Windows 搜索的索引，装了 Everything 时用它，都不行时扫常用文件夹）；**路径模式**（C:\、~\、%变量%\、\\服务器\共享\ 直接列文件夹，Tab 进、Shift+Tab 回）；
  文件多选一起打开 / 拷贝 / 删，在终端中打开、拷贝文件、复制终端写法的路径；kill / port / quit；打开文件后 90 秒回到原处。
- **截图**：冻结帧框选（吸附窗口、识别窗口里的元素，可认网页里的）、放大镜和取色、标注、打码、识字（先认二维码 / 条码）、钉图（上面的字能直接选）、
  截图翻译（浮窗或盖回原图，盖回时单击一块就翻）、截取上次区域、**延时截图**、窗口截图带阴影、截图圆角、长截图（含页面里的小滚动区）、截图历史。
- **录屏 / 录音**：WGC + 硬件 H.264 的 MP4，系统声音和麦克风混一条音轨，点按圈 / 按键胶囊；**能暂停、继续**（一个文件写到底）；压缩、转 GIF；
  录音（系统声音 / 麦克风 / 两者）带控制条、电平、待录、暂停；「暂停 / 继续录制」快捷键对两者都有用。
- **便签**：快速记一条（能贴图）、全部便签（便签墙 / 列表，多选整批、按最近修改排）、屏幕边缘那叠（有快捷键）、浮动便签；
  正文 Markdown（粘网页 / Word 转成 Markdown）、五种任务、文字颜色、行内图片；单独的库和每日备份、最近删除 30 天、Markdown 导出导入（能撤回导入）。
- **提醒**：一次 / 每天 / 每周 / 每月 / 间隔（时段能跨半夜）；轻提醒、边框、全屏、进入状态屏；推后、暂停到几点 / 明天第一个时段；启动器一句话建。
- **状态屏**、**保持唤醒**（插件）。
- **同步**：和 Mac 同一个同步文件夹或同一台 WebDAV 服务器：片段与收藏、生词本、网页搜索、翻译服务、便签、提醒、设置、快捷键、功能开关、启动器收藏；
  密码不对不再硬试、停了会说。
- **壳**：托盘、主界面、全局快捷键（能按程序停用）、功能开关、设置（搜索落到那一行、每页能恢复默认，关掉两分钟后整个放掉）、App 内自动更新（失败按原因说）、
  每日备份、设置与数据导出 / 导入（和 mac 互导）、安装程序、崩溃记录。

## 3. 没做成的、没测的

**没做（PLAN-v26 里留下的）**

- **跨屏框选**（第 2 批，PLAN-v24 H4）：这台机器只有一块屏，窗口那一半没写；Core 的 `ScreenSpan` 在。
- **设置改版的后一半**（G1）：子页 / 「高级…」的分法、说明压成一句 + 行尾 ⓘ 没做（搜索落到那一行、恢复默认做了）。效果演示照 D4 不做。
- **截图历史改标注的「完成」**（mac U7）没做。
- **R24 音画同步**：画面比声音晚约 170 ms（Debug、60 fps 的测试图案）；暂停不让它变大，但老问题没修。
- 先不跟的（英文界面、插件页改版、提醒认专注模式等）列在 `MAC-DIFF.md`「其他窗口 › 还没对齐」。

**还在的毛病**

- 截图遮罩用过之后常驻多十几 MB（WinUI 合成层的原生内存），两分钟后不降。
- 密排竖条（本身像条码）的 4K 截图认码约 570 ms（满屏文字没码的 263 ms）。

**没测的**：给用户的真机清单（≤ 30 条）在 `REVIEW.md`「PLAN-v26」最后：两块屏、真键盘打字、真 Mac / NAS、声音设备、改系统时间、高对比度、讲述人。

## 4. 已知风险

1. 和真 Mac 的长期同步没测；两台 Windows + 假 Mac 的集成测试只覆盖了 8 轮。
2. 长截图没在真机长页面上验证，吸顶栏 / 页脚判断只有合成样本单测。
3. 录屏 WGC + 声音的 CPU 9.2% 单核（测试图案在这台机器上被前台窗口限帧，画面是补帧），
   10 分钟 / 闪退 / 多屏 / 改分辨率 / 拖窗口没测；真耳听音画同步、5.1 真设备、麦克风拔插没测。
   分段 MP4 的缩略图 / seek 在 MediaComposition 里不准，已改成停止时无损重封装成普通 MP4（`Mp4Remux`）；
  重封装后的普通 MP4 时长 / 轨道能读，缩略图和长录制的重封装耗时还要验。
4. 四家云厂商只做了纯函数级签名验证，没有真实账号请求。
5. 一些历史文件里有早期会话留下的乱码注释（非用户界面）；新写的文件是 UTF-8。
6. 高对比度 / 150% / 多屏完全没测。
