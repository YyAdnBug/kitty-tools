# windows/STATUS.md：现状

最后更新：2026-10-26，PLAN-v6 第 7 批。版本 **0.6.0**，未发布（产物在 `windows/build/release/0.6.0/`）。
这份文档写**现在是什么样**，不写历史；每批收尾更新。

## 1. 现在能做什么

- **剪贴板历史**：文本 / 图片 / 文件、收藏、搜索、去重、保留期、图片额度、隐私格式、排除的应用；
  片段与占位符（`{date}` 等 + `{cursor}`）、收藏夹、备注、范围胶囊、固定面板、Ctrl+K；
  多选（合并 / 一起 / 依次粘贴）、拖出、链接预览（拦截本机 / 内网 / 令牌）、后台识字并可搜。
- **翻译**：八个服务（含百度 / 有道 / 火山引擎 / 腾讯云）、流式、划词 / 输入 / 复制即译、自动复制、固定浮窗；
  历史与生词本（Ctrl+H、搜索、重译、收藏、删除 / 撤销、CSV / Anki TSV 导出）、查词、替换原文、朗读。
- **启动器**：应用 / 设置页 / 系统命令 / 计算 / 网址路径直达 / 网页搜索 / 使用记录、收藏与顺序、
  文件搜索（走 Windows 索引的 OLE DB `SYSTEMINDEX`，100 条约 62 ms；索引不可用时退回 WinRT / 扫目录）、
  浏览器书签 / 历史、kill 进程、port 端口（`GetExtendedTcpTable` / `GetExtendedUdpTable`）。
- **截图**：冻结帧框选、吸附、放大镜、标注、识字、钉图、截图翻译、截取上次区域（Ctrl+Alt+Z）、
  长截图（S 向下、Shift+S 向上、A / Shift+A 自动滚动）、飞入卡片、选区里直接打字。
- **录屏**：Alt+R / 托盘 → 选区遮罩 → 倒数 → 录制条；Windows.Graphics.Capture 抓屏 → D3D11 → Media Foundation
  SinkWriter（DXGI 设备管理器 + 硬件 H.264，普通 MP4）；点按圈 / 按键胶囊用 Win2D 画在纹理上，窗口可以单独录。
  系统声音回环 + 麦克风混成一条 AAC 音轨，设置 / 录制条可开关（默认系统声音开、麦克风关），和画面同一个
  SinkWriter / QPC 时钟。帧率 / 目录 / 保存位置设置；锁屏 / 睡眠停止并保存；WGC 建不起来时退 GDI。
  AVI / MJPEG 那一套已经删掉；压缩 / 转 GIF 都改成对 MP4 做。
- **录音**：WASAPI 系统声音 / 麦克风 → 临时 WAV → MediaTranscoder 转 AAC 的 `.m4a`；暂停 / 继续、电平（RMS dBFS）
  的接口有了，录音控制条 / 电平方块 / 待录状态还没接界面（第 3 批收尾）。
- **同步**：和 Mac 互通的四类数据（片段与收藏 / 生词本 / 网页搜索 / 翻译服务），
  格式、版本钟、账本、墓碑、epoch、同步文件夹、20 秒一轮；合并引擎逐段照
  `reference/mac-sync/SyncRecords.swift` 移植，执行层在后台线程。
- **壳**：托盘、全局快捷键、功能开关（剪贴板 / 翻译 / 启动器 / 截图 / 录屏）、
  设置 › 通用 / 外观 / 功能 / 各功能页、App 内自动更新、每日备份、设置与数据导出 / 导入、
  开始菜单快捷方式（第一次运行建）、「从这台电脑移除 Kitty Tools…」、崩溃记录（logs\crash-*.log）。

## 3. 没做成的、没测的

**没做成（这一版还在做）**

- 录屏声音已经并进 WGC 管线；还差 5.1 / 44.1 kHz 真设备、麦克风说话、中间静音 20 秒、HUD 里的「麦克风断开了」、
  真耳听音画同步。分段 MP4 改成普通 MP4 后，闪退恢复只靠临时文件，没实测。
- 录音的采集 / 编码 / 暂停 / 电平接口有了，录音控制条、电平方块、待录状态还没接界面；「按快捷键后立即开始录音」
  设置还没加。
- 录屏声音：5.1 / 44.1 kHz 只有单测，没真设备；麦克风说话、真耳听音画同步、HUD 里的「麦克风断开了」没测。
- 截图 / 设置 / 录屏后的内存回落：0.6.0 全量探针已跑（见上表），设置窗关闭后稳定在 83.5 MB。
- AOT 选项只留了 `ConcurrentGarbageCollection=false`；`IlcOptimizationPreference=Size`、`UseSystemResourceKeys`、
  `IlcFoldIdenticalMethodBodies`、`System.GC.ConserveMemory` 没量到「省了且不变慢」，没开。
- 文件搜索已从 WinRT 换成 OLE DB 直查 `SYSTEMINDEX`（第 4 批做成）：x64 上 `DBBINDING` 的偏移 / 长度字段是
  8 字节、`IRowset` 不继承 `IAccessor`（必须单独 QI），修正后 `CreateAccessor` 返回 0；100 条结果约 62 ms。
  索引服务被关掉时的 WinRT / 扫目录退路只有代码路径，没在真机停过服务验证。
- 第 6 批剩余：讲述人真机朗读没走（轻提示已发 UIA 活区 + 通知）；卡片拖到资源管理器没走；
  高对比度 / 150% / 真多屏 / 真麦克风仍没测。高度动画已加逐帧自检（69 帧 / 0 异常）。
- 更新的端到端失败用例已有脚本：`pwsh windows/tools/update-e2e.ps1` 跑成功 / sha256 错 / 挡住回滚 / 包内无 exe
  四条路；真机替换正在运行的 App 仍需手工走一次。

**要用户真机走的**（详见 `HANDTEST.md`，标「待走 / 待定 / 没测」的条目）

## 4. 已知风险

1. 和真 Mac 的长期同步没测；两台 Windows + 假 Mac 的集成测试只覆盖了 8 轮。
2. 长截图没在真机长页面上验证，吸顶栏 / 页脚判断只有合成样本单测。
3. 录屏 WGC + 声音的 CPU 9.2% 单核（测试图案在这台机器上被前台窗口限帧，画面是补帧），
   10 分钟 / 闪退 / 多屏 / 改分辨率 / 拖窗口没测；真耳听音画同步、5.1 真设备、麦克风拔插没测。
   分段 MP4 的缩略图 / seek 在 MediaComposition 里不准，第 3 批重封装后再验。
4. 四家云厂商只做了纯函数级签名验证，没有真实账号请求。
5. 一些历史文件里有早期会话留下的乱码注释（非用户界面）；新写的文件是 UTF-8。
6. 高对比度 / 150% / 多屏完全没测。
