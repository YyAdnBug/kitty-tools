# windows/STATUS.md：现状

最后更新：2026-10-26，PLAN-v6 第 1 批。版本 **0.5.0**，未发布（产物只在 `windows/build/release/`）。
这份文档写**现在是什么样**，不写历史；每批收尾更新。

## 1. 现在能做什么

- **剪贴板历史**：文本 / 图片 / 文件、收藏、搜索、去重、保留期、图片额度、隐私格式、排除的应用；
  片段与占位符（`{date}` 等 + `{cursor}`）、收藏夹、备注、范围胶囊、固定面板、Ctrl+K；
  多选（合并 / 一起 / 依次粘贴）、拖出、链接预览（拦截本机 / 内网 / 令牌）、后台识字并可搜。
- **翻译**：八个服务（含百度 / 有道 / 火山引擎 / 腾讯云）、流式、划词 / 输入 / 复制即译、自动复制、固定浮窗；
  历史与生词本（Ctrl+H、搜索、重译、收藏、删除 / 撤销、CSV / Anki TSV 导出）、查词、替换原文、朗读。
- **启动器**：应用 / 设置页 / 系统命令 / 计算 / 网址路径直达 / 网页搜索 / 使用记录、收藏与顺序、
  文件搜索（目前走 Windows 索引的 WinRT 查询，慢，PLAN-v6 第 4 批改 OLE DB）、浏览器书签 / 历史、
  kill 进程、port 端口（`GetExtendedTcpTable` / `GetExtendedUdpTable`）。
- **截图**：冻结帧框选、吸附、放大镜、标注、识字、钉图、截图翻译、截取上次区域（Ctrl+Alt+Z）、
  长截图（S 向下、Shift+S 向上、A / Shift+A 自动滚动）、飞入卡片、选区里直接打字。
- **录屏**：Alt+R / 托盘 → 选区遮罩 → 倒数 → 录制条；Windows.Graphics.Capture 抓屏 → D3D11 → Media Foundation
  SinkWriter（DXGI 设备管理器 + 硬件 H.264，分段 MP4）；点按圈 / 按键胶囊用 Win2D 画在纹理上，窗口可以单独录。
  系统声音回环 + 麦克风混成一条 AAC 音轨，设置 / 录制条可开关（默认系统声音开、麦克风关）；**带声音时仍走 GDI
  那条 SinkWriter**，第 2 批再并到 GPU 管线。帧率 / 目录 / 保存位置设置；锁屏 / 睡眠停止并保存；闪退后找回临时文件。
  WGC 建不起来时退 GDI；AVI / MJPEG 那一套还在，只作退路（PLAN-v6 第 3 批删）。
- **录音**：托盘「录音（麦克风）」，WinRT `MediaCapture` 直接写 M4A；没有系统声音、电平、暂停（第 3 批补齐）。
- **同步**：和 Mac 互通的四类数据（片段与收藏 / 生词本 / 网页搜索 / 翻译服务），
  格式、版本钟、账本、墓碑、epoch、同步文件夹、20 秒一轮；合并引擎逐段照
  `reference/mac-sync/SyncRecords.swift` 移植，执行层在后台线程。
- **壳**：托盘、全局快捷键、功能开关（剪贴板 / 翻译 / 启动器 / 截图 / 录屏）、
  设置 › 通用 / 外观 / 功能 / 各功能页、App 内自动更新、每日备份、设置与数据导出 / 导入。

## 3. 没做成的、没测的

**没做成（这一版还在做）**

- 录屏的 WGC 管线已经接了，但 CPU 16.6% 单核（测试图案自己也在跑），比验收的 10% 高；10 分钟 / 闪退 /
  改分辨率 / 拖窗口的实拍没走。带声音时还走 GDI 那条（第 2 批并过来）。压缩 / GIF 只认 AVI（第 3 批）。
  分段 MP4 的缩略图 / seek 在 MediaComposition 里不准（第 3 批重封装后再验）。
- 录屏声音：5.1 / 44.1 kHz 只有单测，没真设备；麦克风说话、真耳听音画同步、HUD 里的「麦克风断开了」没测。
- 文件搜索一次约 880 ms（WinRT `StorageFile` 查询），打字时等不起。第 4 批换 OLE DB。
- AOT 选项没逐项量过（PLAN-v2 就要求了）。第 5 批。
- 高对比度、150% 缩放、第二块屏、中文输入法、ARM64 真机没测。第 6 批尽量补。

**要用户真机走的**（详见 `HANDTEST.md`，标「待走 / 待定 / 没测」的条目）

- 和数据安全有关：备份、锁屏 / 唤醒触发、损坏库恢复、导出 / 导入。
- 翻译：真实四家云厂商（没有 key）、真实翻译成功后落库。
- 剪贴板：`{cursor}` 落点、固定面板跨程序、拖到资源管理器 / Word、多选三种粘贴、链接预览真实网页。
- 启动器：真实文件搜索延迟、kill 两步、收藏顺序、书签。
- 截图：长截图在 Edge / 资源管理器 / VS Code 的实拍、向上滚、30000 上限、内存峰值。
- 同步：和真 Mac 一起走一遍、两边的密钥互换、云盘占位文件、刹车确认。
- 录屏 / 录音：真实快捷键交互、30 fps、闪退恢复、HUD 拖动 / 放弃、点按圈 / 按键的真实钩子、
  对着麦克风说话、麦克风权限被拒时的弹窗、5.1 / 44.1 kHz 真设备、真耳听音画同步。

## 4. 已知风险

1. 和真 Mac 的长期同步没测；两台 Windows + 假 Mac 的集成测试只覆盖了 8 轮。
2. 长截图没在真机长页面上验证，吸顶栏 / 页脚判断只有合成样本单测。
3. 录屏 WGC 的 CPU 16.6% 单核（测试图案 30 fps + 录制），10 分钟 / 闪退 / 多屏没测；
   分段 MP4 的缩略图 / seek 在 MediaComposition 里不准，第 3 批重封装后再验。
4. 四家云厂商只做了纯函数级签名验证，没有真实账号请求。
5. 一些历史文件里有早期会话留下的乱码注释（非用户界面）；新写的文件是 UTF-8。
6. 高对比度 / 150% / 多屏完全没测。
