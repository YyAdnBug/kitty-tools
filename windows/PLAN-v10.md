## 2. 0.1.0 收口（D1、D3 选 A 时）

1. **Windows 那边**：`git fetch && git rebase origin/windows-wip`，编译、单测、`--ui-snapshots`，编译错直接修。
2. **走发版冒烟清单**（HANDTEST 开头那 18 步；第 12–14 步录屏 / 录音、第 4 步启动器这次要走，D2 看结果），每一步失败先停下来修。
3. **优先手测**（每块挑核心路径，不是 300 条全走）：
   - 剪贴板：6b 列表、6d 键盘和菜单、6f 放大预览（459–472、484–499、509–517、628、651）；
   - 翻译：8a 会话、8c 结果卡、8d 历史（581–594、604–619）、643–646；
   - 启动器：7a–7d 里的结果顺序、Ctrl+K、设置页（529–575 挑）、621–624；
   - 截图：5a–5e 标注（375–447 挑）、625–627（识字放大）、663–666（闪白、边框）、675；
   - 录屏 / 录音：629–642、669–674；
   - 壳：656–658（开关不闪）、652（图标）。
   - 额外查一条：轻提示（`054022bd` 起设了 `WDA_EXCLUDEFROMCAPTURE`）在用户机器上看不看得见——同一台机器上设了这个标记的分层窗口不显示（`2136e58b`）；轻提示是 WinUI 窗口、不是分层窗口，录制条也设了这个标记一直看得见，按理没事，但要亲眼看一次。
4. **问题记 REVIEW**「0.1.0 收口」一节（现象、复现、日志行），审查方按条修；P0 / P1 修完为止，P2 以下记着进 0.2.0。
5. **打包**：`changelog.json` 的 0.1.0 条目补上 10-28 以后加的（录音快捷键、录制设置页、钉住剪贴板里的图……），`build-release.ps1` 出 zip、setup.exe 和 `.sha256`，跑 `setup-e2e.ps1`。
6. **用户**装 setup.exe 走最后一遍冒烟；发布由用户决定，发布时一律 `--latest=false`（AGENTS「版本和发布」）。
