# Kitty Tools Windows 版：第七版方案（界面对齐 mac）

2026-10-26。用户要求：「windows 版本的 ui 需要优化，请你出一个优化的方案，尽量保持和 macos 一致」。

- **§1 的 U1–U6 已拍板：2026-10-26 用户「全部按推荐」**。`AGENTS.md`「顺序」第 8 步就是本文第 1–6 批 → 0.7.0。
- 规格来源是 mac 的 Whisker：核心 `.cursor/rules/mac-whisker.mdc`，加上 `mac-whisker-{clipboard,launcher,translate,capture,settings}.mdc`。只照抄行为和数值，不搬 AppKit 的做法。文中「mac §x」指 Whisker 核心的章节，「mac · 剪贴板」这类指各界面文件。
- 本文**取代** PLAN-v2 里和它冲突的条目：D3 剪贴板两栏、§3.6 启动器两行 48；轻提示的语气改成 mac 的圆底符号，不再给整块胶囊换底色。PLAN-v6 第 6 批第 1 项（主题资源）并进本文第 1 批；那一批其余几项（多屏 DPI、无障碍审计、输入法、长截图、R12）还在 v6 里做。
- 红线不变（`AGENTS.md`）：只用微软的包、Native AOT 零警告、不用 `{Binding}` 和反射、截图只拍自己的窗口。
- 下文的尺寸单位都是 DIP（epx），mac 的 pt 按 1:1 换算。

## 0. 现在的问题

依据：`windows-shots` 分支上的截图（0.2.0–0.5.0 拍的，有的可能已经修过）和 `windows-wip` 现在的代码。

### 0.1 没有一套刻度

mac 的圆角、间距、字号、颜色全部从 `Shell/Style.swift` 取，Windows 版没有对应的东西：

- **圆角** 4 / 5 / 6 / 7 / 8 / 10 / 14 七种混用。
- **字号** 15 种，里面有 9 号（mac 最小 10）。
- **次要文字**靠 `Opacity = 0.5–0.7` 调（四十多处），高对比度下会糊。
- **颜色**：`Theme.CardBackground()` / `SecondaryText()` 为了绕开 R15 写死了值，主题字典没用上。画刷都是建元素那一刻取一次，运行中换外观，开着的窗口不跟着变。
- **功能家族色**只有 4 个，图标块的画法是家族色 12% 的淡底配彩色符号。mac 有 11 个家族色，画法是渐变实心色块配白色符号。
- **翻译服务**的标识色和 mac 不一样（比如智谱 mac 是 #3D5AFE，这里是绿色），也没用 mac 已经有的官方 logo。
- **共用部件各写一份**：剪贴板和启动器各自写了搜索框、底栏、键帽、空状态和滑动高亮。

### 0.2 布局和 mac 不是一个样子

| 界面 | mac | Windows 现在 |
|---|---|---|
| 剪贴板 | 单列「透镜指令条」：选中哪一行，哪一行就原地展开成预览；范围和筛选做成搜索框里的标签 | 左右两栏（v2 D3）。列表只占 5/11，标题被来源挤得只剩三个字（「ZNC…」）；搜索框右边一排「全部 / 收藏 / 片段」切换按钮 |
| 搜索框 | 无边框的「搜索线」：放大镜 + 20 号字，56 高，右边不放按钮 | 标准 TextBox，带边框和底部强调色横线 |
| 启动器 | 单行 40，图标 24，标题和副标题在同一行，右边写种类 | 两行 48，图标 32 |
| 底栏 | 一组组「动词 + 键帽」按钮：粘贴 ↩（强调色键帽）· 操作 ⌘K | 一行纯文字，用「｜」和「·」连起来 |
| 翻译浮窗 | 三层（头 / 输入 / 卡片），没有分割线，没有底部提示行 | 多出一行「检测：… · Enter 翻译 · Esc 关闭 · Ctrl+P 固定」 |
| 轻提示 | 纯黑胶囊，语气靠前面那个圆底符号的颜色区分 | 按语气给整块胶囊换底色（橙 / 红） |
| 截图工具栏 | 两段 HUD 胶囊，高 40、按钮 32、用 SF Symbols；颜色和线宽在样式托盘里 | 只有一段，按钮 26，用 ↖ ▭ ↗ ✎ ▦ ↶ ↷ ✕ 这些字符当图标；颜色和线宽每点一下换下一档 |
| 设置 | 侧栏每页一个 20 pt 家族色块；键帽是中性色 | 侧栏是单色图标；每张卡的图标都是剪贴板蓝，一半的卡没有图标、左边空着 36；快捷键页的键帽是强调色实心底 |

### 0.3 看得见的毛病（第 1 批顺手修；有的可能已经修过，先用 §2.4 的工具出一套现状图复查）

1. 深色下翻译错误卡是浅灰底，内容还被裁掉一半（`0.2.0-batch-4-5/translate-dark.png`）。
2. 启动器的计算行：28 号的结果冒出了 48 高的行，副标题是深色字压在深色底上（`launcher-calc-dark.png`）。
3. 轻提示胶囊外面露出一圈白底（`0.2.0-batch-3/notice-light.png`）。
4. 翻译生成中的光标单独占正文下面一行，没有贴在最后一个字后面；颜色写死成品牌粉，不跟强调色（`TranslateWindow.cs` 的 `_cursor`）。
5. 轻提示的宽度动画每 16 ms 改一次 XAML `Width`，等于每帧重排一次（`Notice.cs` 的 `StepWidth`）。
6. 托盘菜单：「复制即译」和「剪贴板历史」用同一个图标，「压缩」和「转 GIF」也用同一个；「■ 停止录音」字里又带了一个方块；没有 mac 那样的分节。
7. 浮层窗口的标题是乱码「娴眰」（`OverlayWindow.cs:51`），读屏软件会读出来。

## 1. 拍板结果（2026-10-26 全部按推荐）

「推荐」一列就是定下来的做法，「其他选择」只留作记录。

| # | 问题 | 推荐 | 其他选择 |
|---|---|---|---|
| U1 | 剪贴板布局 | **改成 mac 的单列透镜**（推翻 v2 D3）。D3 当时担心「变高的行会抖」，mac 的做法正好绕开这个问题：透镜高度按类型查表（是常数），窗口高度给最高的透镜预留好位置，每一行的位置用前缀和算出来，不测量也不估。Windows 上用 `ItemsRepeater` + 自己写的 `VirtualizingLayout`（按前缀和摆，约 150 行）。第 2 批先做原型，抖的话退回右边那一列的做法 | 保留两栏，只改比例（列表占 3/5，来源挪进预览卡头），补上吸顶标题、搜索线和底栏 |
| U2 | 剪贴板的范围和筛选 | **搜索框里的标签胶囊 + 按 Tab 弹出筛选菜单**（同 mac） | 保留「全部 / 收藏 / 片段」三个切换按钮 |
| U3 | 启动器的行 | **单行 40、图标 24**：标题和副标题在同一行，右边写种类名；计算卡 64（同 mac） | 保留两行 48、图标 32 |
| U4 | 轻提示 | **纯黑胶囊 + 语气色圆底符号**（同 mac 的岛）。停留时间按内容分 1.4 / 2.0 / 3.0 s；报得出百分比的加一条细进度条 | 保留按语气换底色 |
| U5 | 强调色 | **跟随系统 + mac 那 8 色**（蓝、紫、品牌粉、红、橙、黄、绿、石墨），默认仍是品牌粉 | 保持「品牌粉 / 跟随系统」两档 |
| U6 | 设置窗 | **壳保持 Windows 11 设置的样子**（NavigationView + 设置卡，v2 D4 不变），里面的内容对齐 mac：侧栏家族色块、按组排、说明文字的写法、中性键帽、外观三张缩略图、强调色一排色点 | 整个改成 mac 的侧栏 + 分组表单 |

不用拍板、直接定的：

- **窗口圆角保持系统的 8。** mac 的面板是 16，但 Windows 上要做到 16，就得放弃系统的亚克力和阴影：`DesktopAcrylicController` 只能铺满整个窗口，DWM 的圆角只有 8 和 4 两档。代价太大，不值。刻度按 §2.1 的换算表来。
- **不做「挤压入场」**（mac 上默认也是关的）。
- **退场不做淡出。** 窗口淡出的时候亚克力底会多留一会儿，做不出 mac「替身淡出」的效果。所以照旧立刻收起，Windows 弹出层的习惯也是这样。

**种类色块 `KindTile`**：照 mac 的画法——家族色从上往下 0.95 → 0.75 的渐变，加 0.5 px white 0.18 的内描边，上面放白色符号（24 的块配 12 号 semibold 符号）。分 24 / 32 两档，取代现在的淡底彩色符号。

**服务方块 `ServiceTile`**（18 / 22 两档）：

各部件的要点：

- **`SearchLine`**
  - 高 56、左右 18。
  - 17 号放大镜（tertiary），定宽 22 + 4，和输入框间距 6。
  - 输入框是去掉边框的 TextBox：用轻量样式把边框、背景和获得焦点时的下划线都设成透明，20 号字。
  - 选中文字的底色用强调色 0.28（`SelectionHighlightColor`）。
  - U2 的标签胶囊放在放大镜和输入框之间。
  - 下面一条 hairline，把搜索线和列表分开。
- **`PanelFooter`**：高 36、顶上一条 hairline、左右 16、12 号字。左边放状态和就地提示（secondary）；右边是「动词 + 键帽」按钮，能点的字用 primary。
- **`KeyCap`**：
  - 高 18、最小宽 20、左右内边距 5、11 号字、圆角 4、底色 `Kitty.Fill.Control`。
  - 两个变体：`Primary`（强调色底 + OnAccent 符号）、`Danger`（危险色底）。

- **`EmptyState`**：符号 28、标题 14 semibold、说明 12、间距 8。

- **`ListHighlight`**：
  - 一块会滑动的高亮，取代两块面板现在各自的那块。
  - 位置按前缀和算。键盘移动用 snap；按住连发和换列表时瞬时；鼠标点选用 glide。
  - 透镜展开时高度和位置一起动。
- **`ActionMenu`**：继续用 `MenuFlyout`（Windows 习惯，不做 mac 那种画在面板里的菜单），但要统一几点：
  - 每一项带图标，快捷键右对齐。
  - 危险项（删除、强制结束、清空）的文字和图标用 `Kitty.Danger`。
  - 界面上叫「操作」，底栏按钮写「操作 Ctrl+K」。

### 2.3 动效

`Motion.cs` 已经有四个现成的用法和七条曲线，这次补上：

- 高亮块的位置和高度一起动（给透镜用）。
- 轻提示改成窗口一次就定到最大宽，只动 Composition 里圆角矩形几何的尺寸（`CompositionRoundedRectangleGeometry.Size` 弹簧），不再每帧改 XAML `Width`。这就是 mac 的「窗口尺寸一次定死，只让形状变形」。
- 复制按钮点了变成对勾，1.2 s 后换回来；收藏星用 pop。
- 列表新条目用 settle 从上面滑进来，图标块从 0.85 放大到 1。
- 规则照 mac §4：bounce ≤ 0.25；粘贴、按住连发、拖动、按键后刷新结果一律 0 ms；循环动效只动变换，看不见了就停。

### 2.4 截图自检工具（第 1 批做，之后每批都用）

- **调试参数 `--ui-snapshots <目录>`**：在屏幕外用 `RenderTargetBitmap` 把每块界面的各种状态出成 PNG，浅色、深色、高对比度各一套。
  - 文件名照 mac `SnapshotProbeTests` 的叫法（`clip-*`、`launcher-*`、`translate-*`、`settings-*`、`island-*`、`shot-*`）。
  - 只渲染我们自己的元素、用假数据，图里不会有别的东西，可以直接推到 `windows-shots`。
- **亚克力**在 `RenderTargetBitmap` 里画不出来：出图时垫一层纯色，颜色接近亚克力的平均色。
- **mac 的参照图**：同名的图由审查方在 Mac 上跑 `SnapshotProbeTests` 出，放进 `windows-shots/mac-reference/`。每批报告附一张两边并排的对照表。

### 3.1 剪贴板（U1、U2）

### 3.3 翻译浮窗

**布局**

**头部和输入框**

- 语言选择：两个 28 高的胶囊（13 medium + 10 号下拉箭头），中间一个 24 的圆形互换钮。点互换钮时它转 180°，两个胶囊交换位置（glide）。

**结果卡**

- 用 `Kitty.Card` 样式。
- 卡头：18 的服务方块（有 logo 用 logo）+ 名字（12 semibold）+ 状态（12 secondary）；右边是图标按钮（复制会变对勾、朗读…），都要有读屏名字。
- 正文：15 号、行高 22、可以选中；最多 8 行，超出的在卡片里滚动，底部渐隐。

**生成中**

- 光标：贴在正文最后一个字后面的一根细条，宽 2、高为行高的 0.82，强调色。位置用 `TextBlock.ContentEnd.GetCharacterRect` 取。透明度在 1 和 0.35 之间来回，一程 0.55 s；出完字就收掉。
- 大模型生成时：卡片边框上有一段强调色的彗星光，2.4 s 绕一圈。
  - 做法：ShapeVisual 画圆角矩形描边，描边的画刷是 `CompositionLinearGradientBrush`，转它的 `RotationAngleInDegrees`。动画在合成器里跑，不占 CPU。
  - 结束时整圈边框闪一下再淡掉。

**等待第一个字**

- 两根骨架条：高 8，宽 94% / 58%，底色 `Kitty.Fill.Control`。
- 一条高光带 1.3 s 扫一趟：用 Composition 平移，按骨架条的形状裁。

- 系统关了动画效果时，这些都不动。

**错误卡**

- 配置或密钥问题用橙色，网络或服务出错用红色：0.05 的底 + 0.18 的描边。
- 按钮是 AccentText 字的文字按钮（「打开设置」「重试」）。

**翻译历史**

### 3.4 轻提示（U4）

**样子**

- 胶囊：纯黑 0.92 的底 + white 0.12 的 hairline，高 36，放在工作区顶部正中、往下 8。
- 前面一个 22 × 22 的槽：

**动效**

- 长出来：窗口定死在最大宽，胶囊形状的宽度从 36 长到实际宽度（island 弹簧，0.42 / 0.22）；内容晚 60 ms 出现，同时淡入、从 0.9 放大到 1。

**停留时间**

- 只有标题 1.4 s，带详情 2.0 s，错误 3.0 s。
- 进行中的一直挂着，60 s 兜底。
- 报得出百分比的（下载更新、转 GIF、压缩）多一条 56 × 4 的细进度条，详情里照样写百分比。

**其他**：不接鼠标（现在已经是）；出现时发 UIA 通知（`RaiseNotificationEvent`）让读屏软件播报。
