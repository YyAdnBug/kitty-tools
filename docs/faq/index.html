常见问题

装的时候、用的时候最常遇到的问题。没找到答案的，在 GitHub 上问。

安装

第一次打开提示「未打开」，怎么办？

Kitty Tools 签了名，但没有经过苹果的公证，所以第一次打开会被系统拦下。提示是「未打开」而不是「已损坏」，说明签名是好的。

打开「系统设置 › 隐私与安全性」，往下拉到「安全性」，点 Kitty Tools 旁边的「仍要打开」，输入登录密码即可（尝试打开后约 1 小时内有效）。也可以在「终端」里执行：

xattr -dr com.apple.quarantine "/Applications/Kitty Tools.app"

只有第一次需要。之后在 App 里更新，不用再放行。看带图的安装步骤

提示「已损坏，无法打开」？

多半是下载不完整。删掉这个 App 和 DMG，重新下载一次再装。还不行的话，用上一条里的终端命令。

我的 Mac 是 Intel 芯片，能用吗？

不能。Mac 版只支持 Apple 芯片（M1 及以后）。不确定的话，点屏幕左上角的苹果菜单 › 关于本机，「芯片」一行写着 Apple M 开头的就可以。

支持哪些 macOS 版本？

macOS 15 及以上。启动台只在 macOS 26 起出现，macOS 15 上用系统自带的。

macOS 15.0 和 15.1 不允许只带 ⌥ 的快捷键，在这两个版本上请到 设置 › 快捷键 里改成带 ⌘ 或 ⌃ 的组合，那一页会提示。

下载很慢，或者下不动？

安装包放在 GitHub 上，在国内有时会慢。Mac 版的 DMG 只有十来兆，多试几次或换个网络一般都能下完。之后的更新在 App 里下载，用的也是 GitHub。

收费吗？代码在哪？

免费，没有广告，也没有内购。代码公开在 GitHub：Mac 版在 macos 分支，Windows 版在 windows 分支。

使用

为什么要「辅助功能」和「屏幕录制」权限？

辅助功能用来把选好的内容粘贴回原来的 App、划词翻译、替换原文、长截图自动滚动、录屏时显示按键和程序坞预览；屏幕录制用来截图、识字、截图翻译、录屏和显示程序坞预览的缩略图。不给也能用其余功能。每项权限的用途

快捷键没反应，或者和别的 App 撞了？

先看 设置 › 快捷键：注册不上的快捷键那里会标出来，换一个组合就行。再看 设置 › 通用 › 功能，这个功能是不是被关掉了。粘贴回原来的 App 要辅助功能权限，刚授权完没生效的，重新打开一次 App。

翻译要自己填密钥吗？

不用。内置的翻译服务开箱即用。想用别的服务（百度、有道、DeepL、各家大模型……），到 设置 › 翻译 里填上你自己的密钥。密钥存在系统钥匙串里，不会同步；导出设置时可以选择加密带上。

有些功能用不上，能关掉吗？

能。设置 › 通用 › 功能 里每个功能一个开关，关掉的功能入口、快捷键和后台工作一起停，数据和设置都留着，打开立刻回来。

能在几台电脑之间同步吗？

能。在 设置 › 通用「同步」里选一个同步盘的文件夹（比如 iCloud 云盘），设置与快捷键、片段和收藏、生词本、网页搜索、翻译服务、便签等就会在几台 Mac 之间同步，每类一个开关。Mac 和 Windows 之间也能互通片段、收藏、生词本、网页搜索和翻译服务。密钥不同步。

怎么更新？

有新版本时菜单栏里会出现「更新到 x.y.z…」，或者在 设置 › 关于 里点「更新并重新打开」，一键更新。

怎么卸载、清掉数据？

退出 App，把「应用程序」里的 Kitty Tools 拖进废纸篓。要连数据一起清，删掉 ~/Library/Application Support/com.yy.kitty-tools.native 和 ~/Library/Preferences/com.yy.kitty-tools.native.plist；翻译服务的密钥在「钥匙串访问」里，名称是 com.yy.kitty-tools.native。Windows 版在 设置 › 应用 里卸载。

Windows 版和 Mac 版有什么不同？

Windows 版有剪贴板历史、翻译、启动器、截图（含长截图和截图历史）、录屏与录音和主界面；便签、启动台、状态屏、程序坞预览和刘海岛目前只有 Mac 版有。两边分别发版，样子和用法尽量对齐，默认快捷键略有不同，见功能页的快捷键表。

怎么反馈问题、提建议？

在 GitHub 上新建一个问题（要有 GitHub 账号）。写上版本号（设置 › 关于）、系统版本和怎么重现，最好附一张截图。

隐私

Kitty Tools 不收集任何使用数据：没有统计，没有广告，不需要账号。

留在本机的

  • 剪贴板历史、便签、截图历史、翻译历史都存在你自己的电脑上。
  • 图片里的文字识别、语种检测、敏感内容识别，都用系统自带的能力在本机完成。
  • 翻译服务的密钥存在系统钥匙串里。

会联网的，只在你用到时

  • 翻译：把要翻译的原文发给你选的翻译服务（默认是内置的那一家），各家按自己的隐私政策处理。
  • 剪贴板里的链接：在面板里预览时，去取这个网页的标题和头图。
  • 检查更新和下载更新：读 GitHub 上的发布列表，从 GitHub 下载更新包。
  • 启动器的 ip 命令：问一个公开服务你的公网地址；网页搜索和书签在你的浏览器里打开。
  • 设置里显示翻译服务的图标时，到它的官网取一次图标。

同步

同步只往你自己选的文件夹里写文件，Kitty Tools 没有自己的服务器。文件会不会上传、传到哪里，由那个同步盘决定。
