FAQ

Frequently asked questions

The questions that come up most when installing and using it. Didn’t find your answer? Ask on GitHub.

Installing

macOS says the app was “Not Opened”. What do I do?

Kitty Tools is signed but not notarized by Apple, so macOS blocks it the first time you open it. The message says “Not Opened” rather than “damaged”, which means the signature is fine.

Open System Settings › Privacy & Security, scroll down to Security, click “Open Anyway” next to Kitty Tools and enter your login password (the button stays available for about an hour after you tried to open the app). Or run this in Terminal:

xattr -dr com.apple.quarantine "/Applications/Kitty Tools.app"

You only need to do this once. After that the app updates itself, with no need to allow it again. Installation steps with pictures

It says the app “is damaged and can’t be opened”?

Most likely the download didn’t finish. Delete the app and the DMG, download it again and reinstall. If that doesn’t help, use the Terminal command from the question above.

Does it work on a Mac with an Intel processor?

Yes, there’s an Intel version from 0.10.0 on: click “Intel version” under the Mac card on the Download page, or download the file ending in _x86_64.dmg from the GitHub releases page. Later in-app updates pick the Intel package automatically.

If you’re not sure which you have, choose Apple menu › About This Mac: a Chip line starting with Apple M means Apple silicon, and a Processor line mentioning Intel means Intel.

Which versions of macOS are supported?

macOS 15 and later. Launchpad only appears on macOS 26 and later; on macOS 15, use the system’s own.

macOS 15.0 and 15.1 don’t allow shortcuts with only ⌥. On those versions, change them in Settings › Shortcuts to combinations with ⌘ or ⌃; that page tells you.

The download is slow or won’t finish?

The installer is hosted on GitHub, which can be slow in some regions. The Mac DMG is only about a dozen megabytes, so trying again or switching networks usually gets it through. In-app updates download from GitHub too.

Does it cost anything? Where’s the code?

It’s free, with no ads and no in-app purchases. The code is on GitHub: the Mac version on the macos branch and the Windows version on the windows branch.

Using it

Why does it need Accessibility and Screen Recording access?

Accessibility is used to paste what you picked back into your app, for Translate Selection, replacing the original text, auto-scrolling in Scrolling Capture, showing keys while recording, and Dock Preview. Screen Recording is used for screenshots, Capture Text, Translate Screenshot, Record Screen and Dock Preview thumbnails. Everything else works without them. What each permission is for

A shortcut does nothing, or clashes with another app?

First check Settings › Shortcuts: shortcuts that couldn’t be registered are marked there, and choosing another combination fixes it. Then check Settings › General › Features to see whether that feature is turned off. Pasting back into your app needs Accessibility access; if you just granted it and it isn’t working yet, reopen the app.

Only failing while you type a password? When another app’s password field has focus (macOS turns on Secure Input), shortcuts on the Mac that use only ⌥ with a letter, number or symbol (like ⌥C or ⌥A) can’t fire, and the keystroke goes into that field. macOS does this to keep passwords from being watched, and no app can get around it. The menu bar icon then shows a small orange lock; hover over it to see which app has Secure Input on and how to turn it off (in Terminal and iTerm2, turn off Secure Keyboard Entry in its menu; in a browser, click another text field or reopen it). To use a shortcut even in password fields, give it ⌃ or ⌘ in Settings › Shortcuts, or make it a double press of a modifier; ⌥Space isn’t affected.

Do I need my own key to translate?

No. The built-in translation service works out of the box. To use other services (Baidu, Youdao, DeepL, language models…), add your own key in Settings › Translate. Keys are stored in the system keychain and don’t sync; when you export your settings you can choose to include them, encrypted.

Can I turn off features I don’t use?

Yes. Settings › General › Features has a switch for each feature. Turning one off stops its entry points, shortcuts and background work together while keeping its data and settings, and turning it back on brings everything back right away.

On the Mac, Notes, Reminders, Status Screen, Launchpad, Dock Preview, Finder Menu, the Notch, Keep Awake, Bluetooth Sleep, Smooth Scrolling and App Shortcuts are plugins: add them in Settings › All Plugins, and until then they don’t appear or run. New installs start with none added; Macs updating from an earlier version keep the ones that were on.

Is the interface available in English?

The Mac version is. Choose System Language, 简体中文 or English in Settings › General › Language; the change takes effect after the app relaunches. New installs follow the system language, and Macs updating from an earlier version stay in Chinese. Search in the Launcher and in Settings understands both languages. The Windows version is in Chinese only for now.

Can it sync between computers?

Yes. In Settings › General › Sync, choose a folder on a synced drive (iCloud Drive, for example) or connect straight to a WebDAV server (from a cloud storage provider, or your own NAS), and settings and shortcuts, snippets and favorites, the Word List, web searches, translation services, notes and more sync between Macs, each kind with its own switch. Snippets, favorites, the Word List, web searches, translation services, notes and reminders also sync between Mac and Windows. Keys don’t sync.

How do I update?

When a new version is out, the menu bar shows “Update to x.y.z…”, or click “Update and Relaunch” in Settings › About. It updates in one click. On the Mac, new versions download in the background and install when you quit (you can turn this off in Settings › About), and you can skip a version you don’t want.

How do I uninstall it and remove its data?

Quit the app and drag Kitty Tools from Applications to the Trash. To remove its data too, delete ~/Library/Application Support/com.yy.kitty-tools.native and ~/Library/Preferences/com.yy.kitty-tools.native.plist; translation service keys are in Keychain Access under the name com.yy.kitty-tools.native. On Windows, uninstall it from Settings › Apps.

How is the Windows version different from the Mac version?

The Windows version has Clipboard History, Translate, Launcher, Screenshot (with Scrolling Capture and Screenshot History), screen and audio recording, Notes, Reminders, Status Screen, Keep Awake and Home; Launchpad, Dock Preview, Finder Menu, the Notch, Smooth Scrolling, App Shortcuts and Bluetooth Sleep are Mac only for now, and its interface is in Chinese for now. The two are released separately and look and work as much alike as they can, though the default shortcuts differ a little; see the shortcut table on the Features page.

How do I report a problem or suggest something?

Open a new issue on GitHub (you’ll need a GitHub account). Include the version (Settings › About), your system version and how to reproduce it, ideally with a screenshot. Writing in English is fine. On the Mac, “Report a Problem” in Settings › About opens the page with the version and system version already filled in.

Privacy

Kitty Tools doesn’t collect any usage data: no analytics, no ads, no account needed.

What stays on your computer

  • Clipboard History, notes, Screenshot History and translation history are all stored on your own computer.
  • Recognizing text in images, detecting languages and detecting sensitive content all happen on your device, using what the system provides.
  • Translation service keys are stored in the system keychain.
  • What’s playing and your next calendar event are read for the Notch and shown only on your Mac.

What goes online, and only when you use it

  • Translation: the text you translate is sent to the service you chose (the built-in one by default), and each service handles it under its own privacy policy.
  • Links on the clipboard: when you preview one in the panel, the page’s title and image are fetched.
  • Checking for and downloading updates: the list of releases is read from GitHub, and updates are downloaded from GitHub.
  • The Launcher’s ip command asks a public service for your public address; web searches and bookmarks open in your browser.
  • To show a translation service’s icon in Settings, the icon is fetched once from its website.

Sync

Sync only writes files to a folder you chose or a WebDAV server you entered; Kitty Tools has no servers of its own. Whether those files are uploaded, and where, is up to that synced drive or server. The WebDAV password is stored in the keychain.

This website

No cookies, no analytics. The download buttons and release notes read GitHub’s public API directly from your browser (so GitHub sees that visit), and what they read is kept in your browser for 10 minutes.
