# mac-overlay-panel

动手前先读同目录 `rule.mdc` 全文（正文唯一数据源：`.cursor/rules/mac-overlay-panel.mdc`）。

红线速查：
- 浮层只用 `OverlayPanel`；显示只走 `present()`，永远不对浮层 `NSApp.activate`。（例外六个：截图框选遮罩 `SelectionOverlay` 见 rule §8、钉图 `PinPanel` 见 §9、长截图面板 `ScrollCapturePanel` 见 §10、状态屏的全屏面板 `StatusScreenPanel` 见 §11、便签屏幕边缘那叠的面板 `NoteDeckPanel` 和浮动便签的面板 `NoteFloatPanel` 见 §12）
- macOS 27：**窗口自己排版的半路不改它的帧**（rule §1）——order / displayIfNeeded 里 SwiftUI 当场要改高度时，改了 contentView 和窗口就差一截、内容被裁；`OverlayPanel` 的改帧入口都先过 `deferredUntilLaidOut`，排完再改。
- 便签的边缘那叠（rule §12）：两块窗口——边上的药丸是装饰（普通 `NSPanel` 实例、状态栏层级、只用 CALayer 画，截图和录屏都不收），那叠 `NoteDeckPanel` 是内容（浮动层级、用时再建、收起 2 秒后放掉，冻结帧里留着、录屏白名单里有）；两块都**不设 `ignoresMouseEvents`**（透明处靠系统点穿）。静置时没有定时器、没有轮询；永不 `NSApp.activate`，扇出不当 key、打开便签才 `makeKey`；Esc 走 `doCommandBy` / `cancelOperation`，不装按键监听；截图框选 / 长截图 / 录屏选区和倒数 / 状态屏开始的地方**显式** `NoteEdge.suspend`，鼠标进药丸再问 `canFan`，不靠「被盖住就收不到鼠标」；状态机在 `NoteDeckState`（纯、有单测），改行为先改它和单测。写标题 / 正文按输入框所属便签的编号落（不按「现在开着哪条」）；只有新打开 / 换一条才当 key（悬停打开的不当、改设置不许当），关掉便签当场把键盘还回去（键盘关的直接回静置）；输入法组字时的点别处不收；让位只收没固定的。测试里不走「打开便签」（会抢键盘）。
- 浮动便签（rule §12「浮动便签」）：一次一张（`NoteFloatState`，纯、有单测）；面板 `NoteFloatPanel` 无边框 + `.resizable`、系统窗口阴影，**一律浮动层级**（`.floating`，固定不固定都一样——固定只管重启后回不回到原处；手测反馈第 6 批：没固定的原来是 `.normal`，本 App 不激活，点别的 App 就沉到底下），永不 `NSApp.activate`；从那叠里拖出来时**那叠里的那一份留到松手才拆**（只是看不见：拆了拖着的手势就断），把手的手势用全局坐标、位置取鼠标在屏幕上的位置；收回要当场 `orderOut`（键盘马上回原来的 App），退场的动画由替身 `PanelStandIn` 做；放面板照 `releasePanel` 的写法（先置空再拆）；帧动画没放完时别读 `panel.frame`（按 `rest`）；只有固定着的记位置、重启后恢复且不当 key；`NoteEdge.suspend` 不收它，长截图时压在选区上的让开；里面的界面和状态与那叠里打开的便签是同一份（`NoteSheet` / `NoteSheetModel`），别另写。单测里面板在屏外、不当 key、不做动画。
- 便签那叠放掉窗口**不许直接把属性置空**（`panel = nil`）：面板在写入过程中被释放，它的视图拆掉时回调回来读同一个属性，独占访问检查直接终止进程（2026-10-13 真机崩溃）。走 `NoteDeck.releasePanel()` / `releasePill()`：先拿到局部变量、属性置空，再收走、拆视图；被视图回调进来的入口面板没了就直接返回。焦点进正文两道：正文框自己拿（`NoteSheetModel.focus`（`NoteDeckModel` / `NoteFloatModel` 继承）→ `takesFocusOnAppear` / `focusRequest`）+ `NoteDeck.focusBody` 晚一拍按编号找、找不到再试两次；单测里的面板不当 key（`takesKeyboard: false`）。
- 便签正文的行距和代码块（rule §3，手测反馈第 4 批）：行高是段落样式定死的，字和插入点怎么居中由布局管理器的代理定（`usedRect` 收成字那么高，空着的最后一行由 `NoteLayoutManager` 收），别回到字上的 `baselineOffset`；代码块是唯一跨行的语法，编辑后重排「改过的行 + 角色变了的行（`roleChanges`）」再各带上下一行，改了排法先跑随机探针 `NoteEditorFuzzTests`（`TEST_RUNNER_KITTY_NOTES_FUZZ=<步数>`，每步和整篇排一遍逐字比；命令在 AGENTS.md）。画代码块的底、引用的竖线时块的头尾不在要画的字里就不问行片段（不然要把版排到块尾）。⌘B 这几个键、粘贴成链接都走 `perform`（`shouldChangeText` → 改 → `didChangeText`）；单测里不碰系统剪贴板（`NoteTextView.pasteboard` 换成自己建的）。
- 状态屏（rule §11）会把键盘鼠标拦住：**任何自动化都不许真的进入**（不调 `StatusScreen.enter`、不启动 App 去点），验证靠单测和单独的截图自检 `SnapshotProbeTests/statusScreen()`；事件拦截只许在 `StatusScreen/InputBlock.swift`，只有 `invalidate()` 能撤；安全输入开着时拦截看不到按键，所以面板必须当 key；不是安全措施，文案不写「锁」。可选的退出密码（`Passcode.swift`）只收数字、按键位认，钥匙串读不到就当没设，解锁即结束不许改（忘了密码的出路）。
- 截图 / 截图翻译先截后选（冻结帧），截屏前先查屏幕录制授权；识字不给语言提示；遮罩画面走图层，不在 draw 里重画整张冻结帧；窗口吸附只读冻结时的 Z 序快照。
- 钉图出现时不 makeKey（不抢键盘），原位置出现；按键同截图出图（⌘S 快速保存、⇧⌘S 另存为、O 识字，体检 C9 D17），按键、右键菜单和 VoiceOver 动作查同一份 `commands`；长截图时和选区相交的钉图让开（B40）。
- 录屏（rule §10 开头）：框选同截图（`SelectionView` 的 `.record` 模式），交回选区后在实时画面上录；`isCapturing` 只占框选阶段，录制状态在 `ScreenRecorder`；录制委托 nonisolated（mac-native §3）；本 App 的窗口按白名单列进过滤器例外（`ScreenCapture.recordedOwnWindows`）；边框、停止项、录制 HUD 是普通实例（HUD 状态栏层级、永不当 key，倒数的 Esc 是 `HotKeyCenter.registerEscape` 临时热键、只挂那几秒，rule §1 §4）；截图调整时按 R 切成录屏（有标注不切）；停止后最后一帧（`Result.poster`，按视频轨的结束取）按 S1 飞入、交给常驻缩略图的视频卡（`ShelfCard.Kind.video`，不另写卡片；拷贝经 `Paster.write(files:)`）；录制条的声音 / 点按开关记偏好、开录读一次（录什么挂什么空输出），麦克风授权在遮罩收起后、倒数前问（rule §8）；点按圈自己画（`InputOverlay`：层级 popUpMenu + 2 的普通 NSPanel，不用系统的 `showMouseClicks` / BGRA；窗口号由 `ScreenRecorder.exceptedOwnWindows` 并进过滤器例外，`recordedOwnWindows` 不改；本 App 窗口上的点按只画一次轻点，录不进画面的自家窗口上不画，rule §10「点按圈」）；按键提示也在 `InputOverlay`（录制条第四个开关「显示按键」，rule §10「按键提示」）：global + local 的 keyDown 监听（global 要辅助功能授权，不用 CGEventTap），键名复用 `HotKey.display`，内容和停手清空是纯状态 `InputOverlay.Keys`，本 App 的全局快捷键被 Carbon 吃掉、由 AppDelegate 的热键处理补给 `showKey`（停止录屏那一下不补），本 App 自己的密码框拿着键盘时不显示，本进程自己发的合成按键（粘贴的 ⌘V、`{cursor}` 的 ←、划词的 ⌘C）按事件源进程号滤掉（`isSynthesized`）；没有辅助功能授权时照样开录、不显示、开关弹回，系统设置放到收尾才打开（rule §8，同麦克风；两项授权都没有时警告岛并成一条、系统设置只开麦克风页）。
- 录音（rule §10「录音」）：`AudioRecorder` 分两个阶段（手测反馈第 3 批）——`open()` 待录只出控制条（不写「进行中」偏好、不建文件、不问授权、没有停止项；控制条的来源开关照写 `Prefs.audioRecordSource`），`start()` 才读来源、问 `allowsStart`、开录；待录不算在录（菜单标题、互斥、更新只看 `isStarted`，要录屏 / 退出时 `close()` 当场收掉）；设置 › 录制「按快捷键后立即开始录音」开着时直接 `start()`。AVAudioRecorder 主线程直接用、不挂委托，HUD 是 `RecordingHUD` 的 `.audio` 形态（窗口四周留 24 pt 透明边，位置按 `screenFrame` 算），录音卡是 `ShelfCard.Kind.audio`；收尾挪文件、闪退恢复、结果岛、停止项和录屏共用 `ScreenRecorder`（`Medium`），不另写一份；录屏和录音互斥（截图里按 R 那一刻就拦，`AppDelegate.recordingBlocker` 一处判断）；锁屏 / 显示器睡眠照录，系统睡眠 / 输入设备断开 / 磁盘不足停。来源是系统声音 / 两者时（第 6 批）复用录屏管线：`ScreenRecorder(…, audioOnly:)` 当引擎（左上角 64 × 64 点、1 fps、不出录屏 chrome，`onStarted` / `onHalted` / `onLevel` 交回），不能暂停（⏸ 置灰）、锁屏会停，收尾 `extractAudio` 导出 m4a（asset 留到导出完）；样本回调里只算 dB 投出来。
- 转成 GIF（rule §8 末尾，录屏录音第 7 批）：只有视频卡有「转成 GIF」，卡片持有转换 `Task`、被关掉就取消；`VideoExport.gif` 是 `@concurrent`，`CGImageDestination` 必须关全局调色板（`kCGImagePropertyGIFHasGlobalColorMap = false`），否则 Finalize 时整段帧一起量化、几百 MB；GIF 卡是 `ShelfCard.Kind.gif`。
- 录屏文件的大小（rule §8 末尾，第二轮体检第 5 批）：系统录制输出没有码率开关，只能靠清晰度 / 编码（`ScreenRecorder.Sharpness` / `Codec`，等比缩的上限跟着真用的编码走）和录完「压缩」（`VideoExport.compress`：最高画质预设 + `fileLengthLimit`，另存不动原文件）；别去找码率参数，也别把 H.264 的 4096 上限套给 HEVC。
- 长截图：框完收起遮罩在实时画面上截（`captureImage(contentFilter:configuration:)` + `sourceRect`，filter 滤掉本 App）；拼接只用逐行哈希投票，不换 Vision 配准；页脚宁大勿小；自动滚动先把光标挪进选区、移出即停。
- 标注显示与导出共用 `Annotation.drawAll`；输出一律用合成图（打码后的内容识别不出来）；文字输入用 NSTextView + `doCommandBy`。
- 剪贴板面板、启动器点外关（鼠标监听成对装卸，兄弟浮层豁免）；启动器没有固定，没执行就收起的 60 秒内再呼出保留查询（体检 A27）；两者同一位置（顶部 20%、宽 720），只开一个；翻译浮窗失焦关；固定只管点别处 / 失焦不收起，Esc、⌘W（OverlayPanel 统一处理）、再按热键一律收起（体检 A9）。
- 两张 ⌘Y 大卡由 `TransientPanel` 拿着（rule §1）：用时再建、收起 2 秒后放掉；要显示走 `open()`，对开着的那块做事读 `.panel`（nil = 没开着，别为了问一句去建）。三块主面板和设置窗一直留着，不照这个改。
- 浮层里的输入框只用 `CommandTextField` / `SourceTextView`（doCommandBy），不用 `.onKeyPress` 抢方向键和回车。
- 便签的正文是专用的编辑器 `NoteTextView`（rule §3）：显式搭的 TextKit 1（别改回 `NSTextView(frame:)`）；样式只改属性、不进撤销栈、不动选区；输入法组字期间不重排、不往外写，**撤掉组字之后系统不再报 `didChangeText`、要在 `setMarkedText` 之后自己 `settle`**（另有下一轮的兜底 `settleLeftover`）；⌃↩ 弹正文的右键菜单（任务状态 / 文字颜色；原来当普通换行）；「外面换了正文」认的是和上次交出去的不一样，不拿仓库里那份去盖正在打的字；光标被浮在上面的菜单盖住时设箭头。
- 便签正文里的 Markdown（rule §3「Markdown 边打边变样」）：认标记是纯函数、不用正则（`NoteMarkdown`），所有语法不跨行（一行一行排 = 整篇排）；藏标记是「零宽的控制字符」（布局管理器的两个代理方法，`nonisolated`），**不用空字形 `.null`**（行首的会被排进上一行，↑↓ 跳行）、不涂透明；标记只在「选区碰到的行 + 正文拿着焦点 + 窗口是 key」露出来，露着的行记在字上（`shownKey`）；动属性都走 `syncMarkers` 那道闸——**组字期间不动、有没处理完的编辑时不动（留给 `settle`）、鼠标拖选和点进来的那一刻不动**；数字中间的 `*`（`2*3*4`）不算标记；链接 ⌘ 点才打开、用自定义属性不用 `.link`，右键菜单另有「打开链接」（点的是不是链接要在调父类 `menu(for:)` 之前看）；单测里不真的当 key（`keyChanged`）、不真的开链接（`onOpenLink`）、不对普通点击调 `mouseDown`。
- 便签正文里的行内图片（rule §3「行内图片」）：正文存的是文字令牌 `![image](kitty-note-image://<大写 UUID>.<小写扩展名>)`（记了宽度时 `![image|240](…)`），**别的写法一律不是令牌、绝不拿令牌碰文件系统**；认 / 拼 / 替换 / 找引用的编号只在 `NoteImages` 一处。编辑器里令牌换成**附件字符 U+FFFC**（`NoteImageAttachment` + 自己的 cell）——样机比过「用 `hiddenKey` 把令牌藏在正文里」那条路（光标会停进令牌内部、点图落到图里、图片后 ⌫ 把令牌弄坏）。**互转只有四个口子**：`replaceAll`、`settle` → `onChange`（`reported` 记的是存的形式）、`maxBytes` / `canFit`（**一个附件按它的令牌那么长**算字节）、复制 / 粘贴。尺寸由 **cell 的 `cellFrame(for:proposedLineFragment:glyphPosition:characterIndex:)`** 报（2026-10-16 评审后改的：默认实现只看 `cellSize()`、比正文宽的图会压住上一行；这里按「行片段宽 − 两边的 `lineFragmentPadding` − 这一行的 head / tail indent − 字形横位置」算可用宽，返回的 origin 取 `position.y − 上留白`，画出来的图正好落在布局代理设的 `usedRect` 上；描边、把手、命中按 `boundingRect(forGlyphRange:in:)`）；图片那一行的段落样式**只放开 `maximumLineHeight`**，`centerLine` 只把含附件的那一个行片段撑到「段前 + 图高 + 上下各 4」（同一段折出来的别的行是正文行高）；正文框变宽时 `setFrameSize` 不当场重排、下一轮或组字确认后补（`widthRestyle`）。**最小 40 pt 只管令牌里记了宽度的和拖把手**。**`NoteStyles.apply` 整行铺回基础样式会把 `.attachment` 抹掉，铺完要放回去**；附件字符上不许落 `hiddenKey`。插图独占一行、**插完光标落到图下一行的行首**、一步撤销；单击图 = 选中那一个字，拖右下角把手只改显示、松手才写进正文（`mouseDragged` / `mouseUp`，**不进系统的鼠标跟踪循环**）；存文件在 `@concurrent`，回主线程插按「是哪个编辑器、哪条便签」落。拖把手松手先清 cell 上临时的宽度（不然撤销回不到原来的宽度）。**剪贴板里同时有字和图时进来的是字**（可读 / 可拖类型：自家类型最前，图片类型和 `.fileURL` 追加在 `.string` 后面；粘贴第 ③ 步显式按 `.string` 读）。拒收的话**标题 + 说明分开**经 model 手里的 `island` 说（不许用 `@Environment(Island.self)`）。单测里图片都用临时目录（`NoteStore.images` 传进去，没有进程里的单例）、剪贴板自己建。
- 撤销 / 重做（rule §3）：⌘Z / ⇧⌘Z 直接动焦点所在输入框的撤销栈（`NSWindow.undoFocusedText`），不发 `undo:` 动作；便签正文的栈由 `NoteTextView.noteUndo` 明说；**窗口子类不许靠重写 `undoManager` 给输入框换栈**（`NSWindow` 的 `undo:` 不看重写的，⌘Z 会「处理了」但字不变）；TextKit 2 的输入框撤完要补发一次「文字变了」。
- 热键非独占，跨进程冲突检测不到。
- 粘贴：hide → `Paster.write` → `pasteToFrontmost`，不加等待，⌘V 显式 `.maskCommand`。
- 划词：复制完成前禁止显示翻译浮窗。
