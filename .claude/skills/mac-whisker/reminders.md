## 6. 各界面规范 · 提醒

- **家族色**：自定义琥珀 `Style.Family.reminders`（浅 #E69914 / 深 #F5AD38；系统色用完了、红是危险色，拍板 A5）。只用在设置页头、侧栏、种类色块、启动器行、速查表、菜单栏「提醒」那一项；提醒本身的光、按钮一律是强调色（§1.2）。功能图标是自画的闹钟 `kitty.reminders`（`icons/feature/kitty.reminders.svg`：实心表盘 + 镂空的 L 形指针、两只铃铛和两只脚是 2.2 的线），新建提醒那个动作共用它。
- **轻提醒**（C2）：刘海岛上「挂着直到处理」（`Island.pin`，核心 S2 那一段）：语气 info（强调色圆底 + `alarm.fill`）、标题是几条提醒的标题用「 · 」连起来、只有一条时详情是它的说明，错过的写在详情里（「还错过了：A、B」；只有错过的时标题「错过了提醒：A」/「错过了 3 个提醒」）。按钮：「知道了」是主按钮（收着时露在行尾，展开后在最右），「稍后 N 分钟」第二个；只有错过的只有「知道了」。× 和双指上滑 = 知道了。催促（C10）时整座岛左右抖一下（同出错的抖，`Island.nudge`）再播报一遍。
- **边框**（C3，`Reminders/ReminderGlow.swift`）：每屏四条贴边的窄窗口（深 28 pt），强调色渐变从屏幕边上 0.85 淡到 0；透明度 1 ↔ 0.35 呼吸（ambient「呼吸 1.2 s 往返」，图层动画，同一表面只有它一个循环），出现先 `fadeIn`；减弱动态效果时只亮不呼吸。不开整屏透明窗（§8）。刘海岛同时挂着那条提醒。
- **全屏**（C4–C8，`Reminders/ReminderScreen.swift`）：HUD 皮肤、永远深色（窗口外观也是深色）。整屏透出底色（`StatusScreenPanel.backdrop(.dim)`）+ 中间一块 `hudSkin` 底板（面板圆角）；字号跟状态屏的告示走（`StatusScreenView.titleSize` × 0.8）：表情（会动，同状态屏的解帧；减弱动态效果时静止画面）、标题 Rounded Bold、说明 × 0.36、小字「14:30 · 18 秒后自己收起」（倒数用 `Ticker`，§8：每秒在变的读数不用 numericText）、进不去状态屏的原因（橙字）+「去授权」（brandInk 文字按钮）、一排按钮：「稍后」+ 几个 HUD 胶囊（white 0.16、白字、高 30，按下 0.24、缩到 0.96——不用系统带边框按钮，它跟着窗口外观画底）+ 隔开的「知道了」（`BrandButtonStyle`，large）。按钮出现后 1 秒才淡入（`fadeIn`，C7），换了内容重新等。进出：窗口淡入 `fadeIn`、收起交给系统淡出（同状态屏的面板，键盘当场还回去）。只统一用透出样式（不给每条选告示 / 透出）。
- **设置 › 提醒**（`Settings/RemindersTab.swift`、`ReminderDetail.swift`，排在状态屏后面）：同 设置 › 状态屏 的列表 + 详情（`OrderedList`：拖动排序、「+ −」、右键菜单、点一行推进）。每行 = 表情的静止画面（没选的是家族色块里的闹钟）+ 标题 + 一行摘要（「工作日 9:00–18:00 每 60 分钟 · 轻提醒」「明天 10:00 · 全屏 20 秒」「每月 31 号 9:00 · 进入「午休」」）+ 迷你开关 + ›。空列表一行 secondary「还没有提醒，点下面的「+」加一条」。「+」里「新提醒」「恢复示例提醒」；删除同状态屏（和示例一样的直接删、自己的先确认，危险色）。详情页：标题、说明、图标格子（同状态屏的 `SymbolGrid`）；时间一组（重复：一次 / 每天 / 工作日 / 每周 / 每月 / 每隔一阵，各自的日期时间、星期一排按钮（toggle 的 button 样式，至少留一天）、几号、间隔和时段 + 「全天」）；提醒方式（分段四种 + 一句说明；全屏时「多久自己收起」，进入状态屏时选哪个状态；状态屏这个功能关着时没有那一格）；声音和催促（分段：无 / 提示音 / 朗读标题；选提示音时试听一声）；删除。有问题时页头摘要换成橙字（没标题、超长、时间已经过了、时段比间隔短）。
- **启动器**（D2 D4）：「提醒 …」的行是种类色块（家族色 + 闹钟）或表情的静止画面，右侧类型「提醒」；「建一条」那一行标题「提醒我：喝水」、副标题解析出的时间（「今天 21:00」），↩ 主动作「建好提醒」；已有的那几行副标题是摘要（暂停的接「· 已暂停」），↩「暂停」/「打开」、⌘↩「在设置里编辑」；认不出、已经过了、写的是重复的（「每天…」：去设置里建）是一行提示（同 open / find 的提示行，主动作「改一下再建」、↩ 只响提示音），排在已有的提醒后面。单输关键词是「新建提醒…」补全提示，排在本地结果后面（输「提醒」想开系统「提醒事项」的照旧 ↩ 打开它）；三个关键词不能当网页搜索的关键词。建好后刘海岛「提醒建好了」+ 打开类的「编辑」。
- **菜单栏**（D6）：「提醒」一项带子菜单（同状态屏那一节的画法，不画节标题）：新建提醒…（带全局快捷键）、下一个：标题（时间）、5 / 10 / 25 分钟 / 1 小时后提醒我、暂停全部提醒 1 小时 / 暂停到明天（暂停着时一行「恢复提醒（暂停到 15:30）」）、管理提醒…。主界面里是「新建提醒」一格（和菜单同一份分节）。
- **无障碍**：岛上的提醒、全屏出现时主动播报（全屏多一句「回车表示知道了」）；全屏的「稍后」按钮读「稍后 15 分钟」，「知道了」带提示「回车或 Esc 也是知道了」；表情不进旁白。
- **截图自检**：`SnapshotProbeTests/reminders()`（几秒，图以 `reminders-` 开头）：设置页浅深 / 空 / 最小窗口、六种详情页 + 橙字、岛上五种（一条 / 展开 / 合成 / 错过 / 错过展开）、全屏五种（带倒数 / 合成点了才收 / 橙字去授权 / 那 1 秒还没出按钮 / 小屏长标题）。边框是图层窗口，屏外拍不到，看手测。
